符号表

全课程统一使用这套记号，主要遵循 Sutton & Barto 的约定。 公式看不懂时先回来这里对符号。

← 回到课程 · 另见 术语表 · 算法速查表

环境与过程

符号读法含义
s ∈ Sstate状态；S 是状态集合
a ∈ Aaction动作；A 是动作集合（可依赖 s，记 A(s)）
r ∈ Rreward奖励；R 是实数集上的奖励取值
ttime step时间步下标，如 st
γgamma折扣因子，0 ≤ γ < 1（连续任务）或 γ = 1（回合任务）
p(s′, r | s, a)—转移概率：在 s 做 a 后到 s′ 并得 r 的概率
Pass′—状态转移矩阵的简写，= Σr p(s′, r | s, a)
Ras—从 s 做 a 的期望即时奖励

回报与价值

符号读法含义
Gtreturn从 t 时刻起的折扣回报 = rt+1 + γrt+2 + γ²rt+3 + …
Gt(n)n-step return只用前 n 步奖励、末尾接 bootstrap 的回报
vπ(s)V of s在策略 π 下状态 s 的状态价值 = 𝔼π[Gt | St=s]
qπ(s, a)Q of s,a在策略 π 下 动作价值 = 𝔼π[Gt | St=s, At=a]
v*, q*—最优价值函数，对所有策略取最大
V(s), Q(s,a)—估计值（带帽子之前），算法实际维护的量
δtTD error时序差分误差 = rt+1 + γV(St+1) − V(St)
Aπ(s,a)advantage优势函数 = qπ(s,a) − vπ(s)

策略与算法超参

符号读法含义
π(a | s)pi随机策略：在 s 选 a 的概率
π(s)pi确定性策略：在 s 选的那个动作
πθ, μθ(s)—参数化策略；μ 专指确定性策略
θtheta策略参数（如神经网络权重）
w, φw / phi价值函数的参数
αalpha学习率 / 步长
εepsilonε-greedy 的探索概率；PPO 里也用作裁剪半径
λlambdaTD(λ) 与 GAE 的迹衰减参数，0 ≤ λ ≤ 1
βbetaKL 惩罚系数；PER 里也用作重要性采样退火指数
τtau目标网络的软更新系数（Polyak）
αent, η— 熵正则系数 / 温度系数。SAC 原文把它写作 α，PPO 实现里常叫 ent_coef； 为了不与"学习率 α"混淆，本课程需要区分时写作 αent 或 η
αCQL— 离线 RL 中 CQL 的保守惩罚权重（原文亦写作 α）
ωomega PER 的优先级指数：采样概率正比于 piω（原文写作 α）
ρtrho重要性采样比；PPO 里 rt(θ) 是同类的概率比
H(π(·|s))entropy策略熵，衡量随机性；SAC 用它做探索
ℋ—同上（手写体 H）

算符与集合记号

符号含义
𝔼π[·]在策略 π 诱导的分布下求期望
∇θ对参数 θ 求梯度
arg maxa使后面的量最大的那个 a
x ← y赋值 / 更新（伪代码里的写法）
≐定义为（Sutton & Barto 用来区分定义与推导）
(s, a, r, s′)一条转移样本，经验回放里的基本单位
D经验回放缓冲区 / 离线数据集
B一个 mini-batch

一手来源
