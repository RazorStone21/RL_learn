动态规划：策略迭代 / 价值迭代（Dynamic Programming, DP）

已知模型时的精确解法，也是理解后面所有算法的参照物。策略迭代 = 反复「评估 → 贪心改进」；价值迭代 = 直接迭代最优方程、最后再取一次贪心。

V(s) ← Σa π(a|s) Σs′,r p(s′, r | s, a) [ r + γV(s′) ] (A.1)
π′(s) ← arg maxa Σs′,r p(s′, r | s, a) [ r + γV(s′) ] (A.2)
V(s) ← maxa Σs′,r p(s′, r | s, a) [ r + γV(s′) ] (A.3)
策略类型都不是「跑起来就能用」的在线算法：策略迭代交替做预测与控制，价值迭代先算 v* 再取贪心。两者都属于广义策略迭代。
动作空间离散（要对 a 求期望或 max）；连续动作需要积分近似或离散化。
环境模型必须完整已知 p(s′, r | s, a)。这是它唯一但硬性的门槛。
何时选它转移表和奖励都能显式写出来、状态数在几千到几百万以内、需要精确解或纯离线规划时；也用来验证其他算法的实现是否正确。
主要坑一次备份要遍历全部动作与后继状态，状态一大就爆炸；已知模型却仍去用无模型方法硬试，是纯粹的样本浪费；价值迭代的 max 有轻微过估计倾向。
详见见第 5 课

蒙特卡洛控制（MC control，ε-soft）

用完整回合的实际回报做平均来估计 Q，再让策略朝贪心方向移动一点点。不需要模型，是最容易理解的控制算法。

Q(St, At) ← Q(St, At) + α [ Gt − Q(St, At) ]，且 π(a|s) 保持 ε-soft (A.4)
策略类型on-policy（同一条轨迹既产生数据又更新自己）；off-policy 版本需要重要性采样 ρt，方差会爆炸。
动作空间离散（表格）；需要每个 (s, a) 都被访问到（探索起点或 ε-soft）。
环境模型不需要。
何时选它回合很短、仿真便宜、想要无偏的价值估计，或需要给 TD 方法做对照基线。
主要坑必须等回合结束才能更新，长回合与不终止任务不可用；方差大、收敛慢；ε-soft 的策略永远带随机性，不衰减 ε 就拿不到最优确定性策略。
详见见第 7 课

SARSA（on-policy 时序差分控制）

把 TD 预测直接改成控制：目标里用「下一步实际会采取的动作」At+1，因此学到的价值包含探索的代价。

Q(St, At) ← Q(St, At) + α [ Rt+1 + γQ(St+1, At+1) − Q(St, At) ] (A.5)
策略类型on-policy。目标里的 At+1 来自当前 ε-greedy 策略，所以「探索撞墙」的代价会被学进价值里。
动作空间离散（表格；也可配函数逼近）。
环境模型不需要。
何时选它安全性优先、探索有真实代价的场景（悬崖行走里它学会绕开悬崖）；需要每步在线更新，并对当前实际执行的策略给出诚实的价值估计。
主要坑ε 不衰减就学不到最优贪心策略；比 Q-learning 收敛慢；若你的目标是「部署时用贪心策略」，on-policy 的价值估计会偏保守。
详见见第 9 课

Q-Learning（off-policy 时序差分控制）

目标里用 max 而不是实际动作，于是行为策略可以随便（只要覆盖够用），学到的始终是最优贪心策略的价值。

Q(St, At) ← Q(St, At) + α [ Rt+1 + γ maxa′ Q(St+1, a′) − Q(St, At) ] (A.6)
策略类型off-policy：行为策略（如 ε-greedy）与目标策略（贪心）分离，因此可以复用旧数据。
动作空间离散。
环境模型不需要。
何时选它离散动作、样本便宜、想要简单可靠的第一版；或想拿历史/他人产生的数据去学贪心策略。
主要坑max 导致的过估计（最大化偏差），奖励噪声大时尤其明显；配函数逼近 + 回放会撞上致命三元组；行为策略覆盖不到的 (s, a) 永远学不到。
详见见第 10 课

n-step 回报与 SARSA(λ)

在「等得久但准」（蒙特卡洛）与「更新快但偏」（单步 TD）之间连续调档：n=1 是 TD，n=∞ 是 MC，λ-回报用资格迹一次在线实现所有 n 的加权平均。

Gt(n) = Rt+1 + γRt+2 + ⋯ + γn−1Rt+n + γnV(St+n) (A.7)
Et(s, a) = γλEt−1(s, a) + 1(St = s, At = a)，Q ← Q + αδtEt (A.8)
策略类型SARSA(λ) 是 on-policy；n-step 的 Q-learning 变体（用 max 目标）是 off-policy，但要额外处理重要性采样。
动作空间离散（表格）；这套思想后来被搬进 DQN（多步回报）与 PPO（GAE）。
环境模型不需要。
何时选它你想手工权衡偏差与方差、或单步 TD 学得太慢而 MC 方差太大时。实践起点：λ≈0.9、n 取 3–5、λ 与 n 只需调一个。
主要坑n 或 λ 太大则方差上升且要求更长回合；资格迹有累积式与替换式两种，行为不同、实现容易写错；off-policy 加资格迹加函数逼近，三者叠加就是致命三元组，最容易发散。
详见见第 11 课

DQN（Deep Q-Network）

用神经网络替代表格 Q，靠经验回放和目标网络把「自举 + off-policy + 函数逼近」这套组合稳住。高维状态 + 离散动作的默认起点。

L(φ) = 𝔼(s,a,r,s′)~D [ ( r + γ maxa′ Q(s′, a′; φ−) − Q(s, a; φ) )² ] (A.9)
策略类型off-policy（必须 off-policy 才能用回放缓冲区里的旧数据）。
动作空间离散：网络输出维度 = 动作个数，取 arg max 即可。
环境模型不需要。
何时选它状态是图像或高维向量、动作离散且不多、能大量采样（有仿真器）时。
主要坑损失只对「实际执行的那个动作」算 TD 误差，写成对全部动作做回归就错了；终止状态的 s′ 不能带自举项；奖励尺度不归一化会训不动；ε 衰减与目标网络同步频率都要调；回放让样本相关性问题缓解，但不解决分布偏移。
详见见第 13 课

Double DQN

不改网络结构，只改目标：用在线网络选动作、用目标网络评估这个动作，把 max 的过估计拆开。

y = r + γ Q( s′, arg maxa′ Q(s′, a′; φ) ; φ− ) (A.10)
策略类型off-policy（与 DQN 完全相同，只换目标）。
动作空间离散。
环境模型不需要。
何时选它DQN 学出的 Q 明显偏大，或在随机环境、奖励有噪声时策略变差；这是几乎零成本的替换，值得默认打开。
主要坑只缓解而不消除过估计；在线网络本身还没学好时收益有限；不要同时改三处组件，否则无法判断是哪一处起了作用。
详见见第 14 课

Dueling DQN

改网络结构：拆成状态价值 V(s) 与优势 A(s, a) 两路，再合并回 Q。让「很多动作都差不多」的状态学得更快。

Q(s, a) = V(s) + A(s, a) − (1 / |A(s)|) Σa′ A(s, a′) (A.11)
策略类型off-policy（网络结构改动，可与 DQN / Double / PER / 分布式任意组合）。
动作空间离散。
环境模型不需要。
何时选它价值主要由状态决定、动作选择影响不大时（例如大多数状态下多个动作都安全）；也适合动作数较多、需要更快学到状态价值的场景。
主要坑不做中心化（那一步减均值）会让 V 与 A 不可辨识、互相抵消；它不解决探索与过估计；小状态空间里收益有限。
详见见第 14 课

优先经验回放（Prioritized Experience Replay, PER）

按 TD 误差大小给样本排优先级，误差大的更常被抽到；同时用重要性采样权重把被改变的采样分布修正回来。

P(i) ∝ piω，比例优先取 pi = |δi| + 小的正常数 (A.12)
ρi = ( 1 / (N · P(i)) )β，β 从 0.4 退火到 1 (A.13)
策略类型off-policy（必须能重复采样历史数据，否则谈不上优先级）。
动作空间离散；同一套回放思想也用于连续控制的 critic 回放。
环境模型不需要。
何时选它奖励稀疏、少数关键转移（罕见成功/失败）很重要、缓冲区很大以致均匀采样浪费时。
主要坑改了采样分布就有偏，不加 ρi、不调优先级指数 ω 或不退火 β 会不稳；只按 |δ| 排序会让噪声大的样本被反复抽（加常数或改 rank 优先）；sum-tree 的精度与索引极易出 bug。
详见见第 15 课

Rainbow 与分布式 RL

把 Double、Dueling、PER、n-step、分布式价值（C51）、Noisy Net 六个组件合到一个 DQN 上；其中分布式价值学的是回报的分布而不只是期望。

Z(s, a) ≐ r + γZ(s′, a′)（分布式贝尔曼目标，等式两边都是随机变量） (A.14)
L(φ) = 𝔼 [ d( (TZ)(s, a; φ−), Z(s, a; φ) ) ]（T 是贝尔曼算子，d 是两个分布之间的距离），C51 用类别投影 + 交叉熵，QR-DQN 用分位数回归（pinball loss） (A.15)
策略类型off-policy。
动作空间离散。
环境模型不需要。
何时选它你要一个「离散动作 + 高维状态」的强基线，愿意用 2–3 倍计算量换样本效率与稳定性；也常作为论文复现的默认对照。
主要坑组件多、互相掩盖错误，必须逐个做消融（Rainbow 的经验：PER 与多步回报贡献最大，分布式价值稳定有用，Noisy Net 收益最不稳定）；C51 的原子格点、QR-DQN 的分位数回归都极易写错；分布式目标的方差信息只有在真正关心风险时才有用。
详见见第 16 课

REINFORCE（带基线的策略梯度）

直接参数化策略，用「实际回报 × 动作的对数概率梯度」把好动作的概率调大。最纯粹的策略梯度，也是方差最大的那个。

∇θJ(θ) ≈ ( Gt − b(St) ) ∇θ log πθ(At|St) (A.16)
策略类型on-policy：必须用当前策略采样出来的完整回合，数据用一次就丢。
动作空间离散或连续，只要能算出 log πθ(a|s)，这是它相对 Q-learning 的最大优势。
环境模型不需要。
何时选它教学与原型（Spinning Up 里叫 VPG，即 vanilla policy gradient）；策略参数少（线性 softmax / 小网络）、回合短、想要最小实现依赖、或动作连续无法做 max 时。
主要坑方差极大、样本效率极低；必须等回合结束；不加基线几乎学不动，基线用 V(s) 时要注意它不能依赖动作；学习率稍大就把策略推崩，一步坏更新也无法回滚。
详见见第 17 课

A2C / A3C（Actor-Critic）

用 critic 的 TD 误差替代整条回报，把 REINFORCE 的高方差换成自举的偏差：actor 每步都能更新。

∇θJ(θ) ≈ δt ∇θ log πθ(At|St) + η ∇θH(πθ(·|St))，δt = Rt+1 + γVφ(St+1) − Vφ(St) (A.17)
策略类型on-policy。A3C 是异步多线程，A2C 是同步批量化版本。
动作空间离散或连续（连续输出高斯分布的 μ、σ）。
环境模型不需要。
何时选它能开很多并行环境、想快速迭代一个策略梯度基线；教学与中小任务优先用 A2C（易复现、好调试）。
主要坑on-policy 意味着数据只用一次，样本效率低；critic（价值网络 φ）与 actor 的学习率、损失权重不平衡会让优势估计失真；异步 A3C 结果不稳定、难复现，且不能用过期梯度；熵系数 η 太大会让策略一直很随机。
详见见第 18 课

GAE + TRPO（优势估计 + 信赖域策略优化）

GAE 解决「优势怎么估得又准又稳」，TRPO 解决「一步更新多大才安全」。两者合起来是 PPO 的直接前身。

AtGAE(γ,λ) = Σl=0∞ (γλ)l δt+l，反向递推：At = δt + γλAt+1 (A.18)
maxθ 𝔼 [ ( πθ(a|s) / πold(a|s) ) At ]   s.t.   𝔼 [ KL( πold ‖ πθ ) ] ≤ δKL (A.19)
策略类型on-policy：surrogate 目标只在旧策略附近有效，数据不能反复用太多轮。
动作空间离散或连续。
环境模型不需要。
何时选它你需要「每次更新都不会把策略搞崩」的强保证、且不在意实现复杂度（Fisher 向量积 + 共轭梯度 + 线搜索）时；GAE 本身几乎总值得单独拿来用，即使你最后用 PPO。
主要坑TRPO 工程成本高、每批数据要够大、与 dropout/参数共享等实现细节冲突；δKL 设太小过度保守、太大失去约束；AtGAE 里 λ 与 γ 共同决定偏差-方差，只调一个容易白调。
详见见第 19 课

PPO（Proximal Policy Optimization，裁剪目标）

用「概率比 + clip + min」代替 TRPO 的二阶约束，把信赖域换成一个几乎不用调的损失函数。通用性最好、实现最短，也是 RLHF 的默认优化器。

LCLIP(θ) = 𝔼 [ min( rt(θ)At, clip(rt(θ), 1−ε, 1+ε) At ) ]，rt(θ) = πθ(a|s) / πold(a|s) (A.20)
Ltotal = LCLIP − cv ( Vφ(s) − Vtarget )² + η H(πθ(·|s)) (A.21)
策略类型on-policy：同一批数据可以跑多个 epoch（多跑几个 epoch 是裁剪目标 LCLIP 带来的好处），但之后必须重新采样。
动作空间离散或连续（连续输出高斯分布的 μ 与 σ）。
环境模型不需要。
何时选它通用首选：能开并行仿真、动作空间大或连续、需要策略直接输出动作（含大模型 RLHF 微调）；对奖励尺度比 DQN 一族宽容，公开实现最多。
主要坑超参敏感：ε、学习率、epoch 数、batch 大小、优势是否归一化都要动；多 epoch 训练时必须用 KL 或裁剪比例做早停；优势不标准化最容易崩；样本效率不高，样本极贵时别硬用。
详见见第 20 课

DDPG（Deep Deterministic Policy Gradient）

连续动作无法做 max，于是学一个确定性策略 μθ(s)，用 critic 的 ∇aQ 当「裁判」告诉 actor 该往哪调动作。是连续控制 DQN 化的第一代方案。

∇θJ ≈ 𝔼 [ ∇aQ(s, a; φ) |a = μθ(s) · ∇θμθ(s) ] (A.22)
L(φ) = 𝔼 [ ( r + γQ(s′, μθ−(s′); φ−) − Q(s, a; φ) )² ]，软更新 φ− ← τφ + (1−τ)φ− (A.23)
策略类型off-policy（配经验回放，样本可复用）。
动作空间连续（输出一个实数向量）；离散动作请用 DQN 一族。
环境模型不需要。
何时选它历史与教学用途，或你确实需要确定性策略（推理时无采样开销）并愿意精细调参。新项目建议直接用 TD3 或 SAC。
主要坑对学习率、批量大小、探索噪声尺度、软更新系数 τ 极其敏感；Q 的过估计会被 actor 直接利用（往 Q 的误差方向调动作）；探索完全靠外部噪声（高斯/OU），噪声尺度没有原则性做法；早期很容易收敛到坏解。
详见见第 21 课

TD3（Twin Delayed DDPG）

对 DDPG 的三处外科手术式修正：截断双 Q、延迟策略更新、目标动作平滑。连续控制里比 DDPG 稳得多。

y = r + γ mini=1,2 Qφ−i( s′, clip( μθ−(s′) + ξ, −c, c ) )，ξ ~ N(0, σ) (A.24)
actor：∇θJ ≈ 𝔼 [ ∇aQφ1(s, a) |a=μθ(s) ∇θμθ(s) ]，每 d 次 critic 更新才做一次 (A.25)
策略类型off-policy。
动作空间连续。
环境模型不需要。
何时选它连续控制、接受确定性策略（推理便宜、部署友好）、又不想付出 SAC 的随机策略与温度调参成本时；也是 DDPG 调不动时的直接替代。
主要坑双 Q 与延迟更新都不能省，省掉就退回 DDPG；目标平滑噪声 ξ（标准差 σ）与截断 c 需要调；探索仍靠外部噪声，不像 SAC 把随机性写进目标，容易探索不足。
详见见第 22 课

SAC（Soft Actor-Critic，最大熵）

最大化「回报 + 熵」的 off-policy actor-critic：策略保持随机即是探索，因此样本效率高、对超参相对鲁棒。连续控制的首选。

y = r + γ ( mini=1,2 Qφ−i(s′, a′) − αent log πθ(a′|s′) )，a′ ~ πθ(·|s′) (A.26)
∇θJ = 𝔼 [ ∇θ ( αent log πθ(a|s) − Qφ(s, a) ) ]，a = tanh( μθ(s) + σθ(s) ⊙ ξ ) (A.27)
J(αent) = 𝔼 [ −αent ( log πθ(a|s) + Ĥ ) ]，目标熵 Ĥ 常取 −dim(A) (A.28)
策略类型off-policy（配经验回放）。
动作空间连续（也有离散动作版本）。
环境模型不需要。
何时选它连续控制第一选择：样本效率高、对学习率与奖励尺度相对鲁棒、探索自动；真机实验或仿真昂贵时尤其合适。
主要坑目标熵设错会让策略过随机或过早确定；tanh 变换后的对数概率必须加雅可比修正，写错会静默学坏；仍是自举 + off-policy，别因此放松对致命三元组的警惕（大网络 + 大学习率照样发散）；对稀疏奖励并不比别的算法更神奇。
详见见第 23 课

Dyna-Q（基于模型 + 规划）

每走一步真实交互，就用同一份经验做两件事：更新价值、更新模型；然后再从模型里「回放」若干次做额外的价值更新。样本贵时的第一选择。

Q(S, A) ← Q(S, A) + α [ R + γ maxa′ Q(S′, a′) − Q(S, A) ]，( R, S′ ) 来自真实一步或模型预测；每步真实交互后再做 n 次模型回放 (A.29)
策略类型off-policy（Q-learning 内核 + 学到的模型），真实数据与想象数据共用一个 Q。
动作空间离散（表格型模型最直接；连续动作需要模型与规划都用另一套方法）。
环境模型需要：可以已知，也可以在线学（确定性一步模型最简单）。
何时选它每次真实交互都很贵、状态动作空间不大、环境近似确定性时；也是理解「规划 = 用模型做备份」的最短路径。
主要坑模型学偏了会累积出误差，策略就在「想象里最优」；探索不足时模型只覆盖走过的区域（可用 Dyna-Q+ 给久未访问的动作加奖励）；n 越大越省真实样本，但越容易被模型误差带偏。
详见见第 24 课

MCTS / AlphaZero（蒙特卡洛树搜索与规划）

不学价值函数，而是用仿真器把决策时的计算预算集中到有希望的分支上：选择 → 扩展 → 模拟 → 回传。AlphaZero 再把策略/价值网络塞进这个循环。

UCT 选择：a* = arg maxa [ Q(s, a) + c √( ln N(s) / N(s, a) ) ] (A.30)
AlphaZero 选择：a* = arg maxa [ Q(s, a) + c P(s, a) √N(s) / (1 + N(s, a)) ]，P 来自策略网络 (A.31)
策略类型MCTS 是纯规划器，本身不学策略，选择阶段用 UCT（树上的置信上界）；AlphaZero 用自对弈生成数据、用搜索的访问分布监督策略网络，是「on-policy 采样 + 监督式训练」的混合体。
动作空间离散且分支可控；连续动作要么离散化，要么改用连续版本的规划方法。
环境模型需要：仿真器或规则（棋类直接用规则，不必学模型）。
何时选它有可靠仿真器、回合制、分支多但可剪枝、决策质量比训练速度更重要时（棋类、调度、组合优化）。
主要坑每次决策要成百上千次模拟，推理成本高；仿真器不真实则全部白搭；模拟次数不足时搜索结果可能还不如直接策略；自对弈需要大量算力与稳定的评估流程，且很难判断是网络还是搜索在起作用。
详见见第 24 课

行为克隆（Behavior Cloning, BC）

把日志里的 (状态, 动作) 当监督学习样本直接拟合策略。没有价值函数、没有自举、没有探索。这也是它稳的原因。

minθ −𝔼(s,a)~D [ log πθ(a|s) ]（连续动作退化为均方误差） (A.32)
策略类型与 on/off-policy 无关：它不做价值估计、不做自举，只是监督学习。
动作空间离散（softmax + 交叉熵）或连续（高斯 / 直接回归）。
环境模型不需要。
何时选它第一件该跑的事：有专家演示或历史日志、能拿到 (s, a) 对、只想复现既有水平。训练稳、便宜、易解释，也是所有离线 RL 的对照基线。
主要坑复合误差：一旦偏离数据分布就会持续犯错（最坏 O(εT²)），所以数据的状态覆盖比模型容量更重要；只会模仿、无法超过数据；日志里看不到「如果当时选别的动作会怎样」，因此很难评估；类别不均衡时会只学会最常见动作。
详见见第 25 课

CQL（Conservative Q-Learning，保守离线 RL）

在 Bellman 误差之外加一项惩罚：压低「策略偏好但数据里没见过」的动作的 Q 值，让策略不敢离开数据分布。

L(φ) = αCQL 𝔼s~D [ log Σa exp Qφ(s, a) − 𝔼a~πβ(·|s) Qφ(s, a) ] + ½ 𝔼(s,a,r,s′)~D [ ( Qφ(s, a) − ( r + γ maxa′ Qφ−(s′, a′) ) )² ] (A.33)
策略类型off-policy，但只在固定数据集 D 上更新，不与环境交互（πβ 是产生日志的行为策略）。
动作空间离散或连续。
环境模型不需要。
何时选它只有固定日志、完全不能探索，且 BC 明显不够（数据里混有次优行为、或需要把已有行为组合得更好）时。实践顺序是：先 BC 基线 → 再 CQL；预算少时可以看更简单的 IQL 或 TD3+BC。
主要坑αCQL 太小学不到保守、太大把 Q 压平导致策略退化成「数据平均」；只靠日志评估不可靠（分布偏移），上线必须有 shadow 模式、A/B 与护栏指标；数据覆盖差时任何离线算法都救不回来。
详见见第 25 课
