确定性 Actor-Critic 与 DPG 定理

前面所有策略梯度（算出参数往哪调能让总分更高）算法都在对动作求期望，这在高维连续控制里代价很高。 这一课把策略（看到什么状态就选什么动作的规则）改成确定性策略（每个状态只输出一个动作）$a=\mu(s,\theta)$，期望就只剩对状态的一层。 由此得到的确定性策略梯度定理（DPG，deterministic policy gradient）是 DDPG（deep deterministic policy gradient，深度确定性策略梯度）一类算法的理论基础。 代价也要说清楚：确定性策略自己不探索，必须从外面补噪声。

学完这一课你会

  • 说出确定性策略相对随机策略省下了什么计算，又失去了什么
  • 写出 DPG 定理，并指出它与随机策略梯度定理的差别
  • 说明定理右端两项各自的作用
  • 复述 DPG 定理证明的主要思路
  • 说清为什么确定性 Actor-Critic 必须外接探索噪声

1. 为什么要用确定性策略

回顾随机策略（同一个状态按概率选不同动作）的梯度。无论用哪一套度量，梯度最后都写成

$$\nabla J(\theta)=\E\Big[\nabla\log\pi(A|S,\theta)\,q_\pi(S,A)\Big],$$ (31.1)

式 (31.1) 里的期望要对动作取。这意味着每算一次梯度，都要按 $\pi$ 采一批动作。 在连续控制里（机械臂的 7 个关节力矩、无人机的 12 维推力）， 动作空间是高维连续的，采样估计这一层期望就成了一项可观的开销。

定义 1.1（确定性策略）

确定性策略（每个状态只输出一个确定的动作，而不是一个分布）记作 $$a=\mu(s,\theta),\qquad \mu:\mathcal{S}\to\mathcal{A}.$$ 它的特别之处在于：给定 $s$，动作是唯一确定的，没有"按概率抽"这一步。 于是价值函数（给每个状态打一个"值多少分"的分数的函数）里对动作的期望也消失了： $v_\mu(s)=q_\mu\big(s,\mu(s,\theta)\big)$。

注记 1.2（省了什么，又失去了什么）

省下的是"对动作求期望"这一层采样，梯度估计的方差也随之小很多。 失去的是内建的探索：随机策略靠采样天然会试到不同动作， 而确定性策略永远选同一个，不试新动作就没有新数据。 所以后面必须从外部加噪声，这一点在算法一节会讲。

2. 确定性策略梯度定理

定理 2.1（DPG：确定性策略梯度定理）

设策略为 $a=\mu(s,\theta)$，目标为 $J(\theta)= \E_{s\sim d_\mu}\big[q_\mu(s,\mu(s,\theta))\big]$，其中 $d_\mu$ 是确定性策略下的状态访问分布。则 $$\nabla_\theta J(\theta)=\E_{s\sim d_\mu}\Big[ \nabla_\theta\mu(s,\theta)^\top\,\nabla_a q_\mu(s,a)\big|_{a=\mu(s,\theta)}\Big].$$

右端是两项的乘积：$\nabla_\theta\mu(s,\theta)$ 是动作对参数的敏感度， $\nabla_a q_\mu(s,a)|_{a=\mu(s,\theta)}$ 是价值对动作的敏感度。

注记 2.2（怎么读这两个因子）

把它想成一条传递链：$q$ 告诉我们要往哪个动作方向改， $\nabla_\theta\mu$ 告诉我们参数往哪调能让动作往那个方向动。 两者相乘，就是"参数该怎么调"。 注意定理里没有 $\log\pi$，也没有对动作的期望，这是它与式 (31.1) 最直观的差别。

3. 与随机策略梯度定理的对比

随机策略梯度（第 0027 课）确定性策略梯度（本课）
策略形式$\pi(a|s,\theta)$，输出分布$\mu(s,\theta)$，输出一个动作
梯度里的求导项$\nabla_\theta\log\pi(a|s,\theta)$$\nabla_\theta\mu(s,\theta)$
权重$q_\pi(s,a)$$\nabla_a q_\mu(s,a)$
要不要对动作取期望要，决定了采样开销不要，只对状态取期望
探索策略自带必须外部加噪声
注记 3.1（更深一层的差别）

权重从"价值本身"换成"价值的梯度"，这不是随手改的。 随机策略里，权重要表达"这个动作比平均好多少"，所以用 $q$； 确定性策略里没有"平均"可言，要让价值变大只有一个办法： 把动作朝着 $q$ 上升的方向挪，于是出现 $\nabla_a q$。 另外注意确定性策略梯度的期望是对状态取的，所以它比随机版本少一层采样， 这也是它方差更小的来源。

4. DPG 定理的证明思路

下面给出证明的骨架。完整推导见原书 10.4.1 节。

证明（思路：从随机策略出发，让方差趋于零）

第一步，把确定性策略写成随机策略的极限。 取一族随机策略 $\pi_\sigma(a|s,\theta)=\mathcal{N}\big(\mu(s,\theta),\sigma^2\big)$， 即均值是确定性策略、标准差是 $\sigma$ 的高斯策略。 当 $\sigma\to0$ 时这族策略趋于 $\mu$。

第二步，对高斯策略用随机策略梯度定理。 高斯密度的对数梯度有一个干净的形式： $\nabla_\theta\log\pi_\sigma(a|s,\theta) =\frac{1}{\sigma^2}\big(a-\mu(s,\theta)\big)^\top\nabla_\theta\mu(s,\theta)$。 代入式 (31.1) 得到 $$\nabla J_\sigma(\theta)=\E\Big[\tfrac{1}{\sigma^2}(A-\mu(S,\theta))^\top\nabla_\theta\mu(S,\theta)\,q_\pi(S,A)\Big].$$

第三步，令 $\sigma\to0$。 记 $A=\mu(S,\theta)+\sigma\xi$（$\xi$ 是标准正态），则 $\frac{1}{\sigma}(A-\mu)=\xi$， 而 $q_\pi$ 在 $A$ 处作一阶展开： $$q_\pi(S,A)\approx q_\mu(S,\mu)+\sigma\,\xi^\top\nabla_a q_\mu(S,a)\big|_{a=\mu}+\cdots$$ 代回并利用 $\E[\xi]=0$、$\E[\xi\xi^\top]=I$， $\sigma\to0$ 时含 $\sigma$ 的项消失，剩下 $$\nabla J_\mu(\theta)=\E_{s\sim d_\mu}\Big[\nabla_\theta\mu(s,\theta)^\top \nabla_a q_\mu(s,a)\big|_{a=\mu(s,\theta)}\Big].$$

最后一步说明状态分布：$\sigma\to0$ 时 $d_{\pi_\sigma}\to d_\mu$， 即随机策略下的状态访问分布收敛（一轮轮算下去，数值稳定到不再变化）到确定性策略下的那一个， 因此外层期望可以从 $d_{\pi_\sigma}$ 换成 $d_\mu$。 这一步的严格处理（以及可微性交换的合法条件）属于测度论范围，本课按引用处理。

∎
注记 4.1（这个证明告诉我们的方法）

"把新对象写成旧对象的极限"是推导里很常用的一招。它的好处是不必从零建立理论， 而是直接复用已经证过的结论，再取极限。 代价是极限过程需要额外的合法性检查（交换极限与期望、状态分布的收敛）， 这些正是本课标为引用的部分。

5. 算法：确定性 Actor-Critic

算法 5.1（确定性 Actor-Critic）

维护两个网络：actor（演员，负责做决定的那一方）即确定性策略 $a=\mu(s,\theta)$，以及 critic（评论家，负责打分的那一方）即动作值 $q(s,a,w)$。

① 与环境交互时加噪声：实际执行的动作是 $$a_t=\mu(s_t,\theta)+\eta_t,$$ 其中 $\eta_t$ 是探索噪声（常见做法是高斯噪声或时间相关的 OU 噪声）。 这一步是必须的，否则永远采不到新动作。

② critic 更新：用时序差分（一步的即时奖励加上下一步的估计，不必等整局结束）学 $q$，目标为 $y_t=r_{t+1}+\gamma\,q\big(s_{t+1},\mu(s_{t+1},\theta),w\big)$。

③ actor 更新：沿价值上升方向调参数， $$\theta\leftarrow\theta+\alpha_\theta\, \nabla_\theta\mu(s_t,\theta)^\top\nabla_a q(s_t,a,w)\big|_{a=\mu(s_t,\theta)}.$$

注记 5.2（把探索放在外面带来的新问题）

噪声尺度的调参变得很敏感：太小则探索不足，学不到更好的动作； 太大则采到的动作与策略想执行的动作差太远，critic 的估计会对不上， actor 反而被带偏。随机策略里这个权衡由策略自己的标准差承担， 而确定性策略把它变成了一个外部量：超参（训练前要你自己设定的量）。

注记 5.3（这一课在全书里的位置）

到这里，本书的算法主线走完了：从价值迭代（反复用同一个更新式把价值表算到不动）出发，经由蒙特卡洛（把一整局走完，用真实拿到的总分来估计价值）与随机近似， 到时序差分、函数逼近（用函数代替表格存价值）、策略梯度，最后到 Actor-Critic（一边出招、一边打分）的三种形态： QAC（Q Actor-Critic，最基础的那种）与 A2C（Advantage Actor-Critic，用"比平均好多少"当权重）、 off-policy（可以拿别人或自己以前的数据来学）与确定性策略。 DPG 定理就是现代连续控制算法（DDPG 及其后继）的理论出处。 想继续往工程实现走，可以读进阶篇里的相应课程。

小结

  • 确定性策略 $a=\mu(s,\theta)$ 省掉了对动作求期望的那一层采样（定义 1.1）。
  • DPG 定理：$\nabla_\theta J=\E[\nabla_\theta\mu^\top\nabla_a q]$，只对状态取期望（定理 2.1）。
  • 它与随机策略梯度定理的差别在于求导项与权重，也在于少了一层动作期望（第 3 节对照表）。
  • 证明思路是把确定性策略看成方差趋于零的高斯策略，再取极限（第 4 节）。
  • 确定性策略不探索，训练时必须外接噪声，噪声尺度成了一个敏感的超参数（算法 5.1）。

全书的主线到此结束。回头看，所有算法都围绕同一件事： 把"价值满足某个方程"翻译成"用样本去逼近那个方程的解"。 价值迭代用完整模型逼近，蒙特卡洛用整局的回报（从某一步往后拿到的奖励加起来）逼近， 时序差分用单步样本逼近，函数逼近把表格换成网络， 策略梯度则干脆绕开价值、直接对策略求导。理解了这条主线，具体算法的差异就都成了细节。

课后练习

1. 确定性策略相比随机策略，最主要省下的是什么？

  1. 省下了价值网络的训练，因为不再需要 critic
  2. 省下了对动作求期望的那一层采样，梯度方差也更小
  3. 省下了与环境的交互，可以用别人跑好的数据训练
  4. 省下了"给未来奖励打折"的那个系数，不再需要折扣

为什么：随机策略梯度的期望要对动作取，高维连续动作下采样开销大； 确定性策略只输出一个动作，只剩对状态的一层期望。

A 错在确定性 Actor-Critic 仍然需要 critic。 C 错在它照样要交互（还要额外加噪声）。 D 错在"给未来奖励打折"这件事与策略是随机还是确定无关。

2. DPG 定理右端的两项分别是什么？

  1. 策略的概率与价值本身，与随机策略梯度一样
  2. 与第 0029 课 QAC 相同的那两项
  3. 两套分布的概率之比，以及概率取对数后的梯度
  4. 动作对参数的敏感度，与价值对动作的敏感度

为什么：$\nabla_\theta\mu(s,\theta)$ 说明参数怎么影响动作， $\nabla_a q_\mu(s,a)$ 说明动作怎么影响价值，两者相乘即参数的更新方向。

A 错在 DPG 里没有 $\log\pi$。B 描述的是 A2C。 C 描述的是 off-policy 策略梯度（第 0030 课）。

3. DPG 定理里为什么权重是 $\nabla_a q$ 而不是 $q$ 本身？

  1. 确定性策略没有"平均动作"这个概念，要让价值变大只能把动作往 $q$ 上升的方向挪
  2. 因为 $\nabla_a q$ 的数值总是比 $q$ 小，能让更新更稳定
  3. 因为 $q$ 无法计算，只能算它的梯度
  4. 因为 $\nabla_a q$ 的期望恰好等于 $q$ 的期望

为什么：随机策略里权重要表达"这个动作比平均好多少"，所以用 $q$； 确定性策略里没有分布可谈平均，改进的方式就是沿 $q$ 的上升方向调整动作。

B 错在数值大小不是理由。C 错在 $q$ 和它的梯度都能算。 D 错在两者期望一般不相等。

4. DPG 定理证明的第一步做了什么？

  1. 把确定性策略直接对参数求导，得到链式法则的展开
  2. 对价值用"最优时Bellman方程"，消掉动作维度
  3. 把确定性策略写成一族方差趋于零的高斯策略
  4. 把策略梯度定理中的期望换成"用另一套分布的数据来估计"的形式

为什么：这样就能对随机策略用已经证过的策略梯度定理， 再让对方差趋于零，从而得到确定性情形。这是"把新对象写成旧对象的极限"这一招。

A 是最终要得到的结果，不是证明的起点。 B 走的是价值方法的路子，与策略梯度不同。 D 是第 0030 课处理 off-policy 的手段。

5. 在证明的第三步里，为什么 $\E[\xi]=0$ 与 $\E[\xi\xi^\top]=I$ 这两条性质很关键？

  1. 它们保证了高斯分布的密度在实数轴上处处为正
  2. 它们说明了策略参数 $\theta$ 一定存在而且是唯一的
  3. 它们让价值在动作上是凸的，于是有唯一的最大值
  4. 它们让带 $\xi$ 的线性项消失、二次项留下，极限后只剩 $\nabla_a q$

为什么：$\E[\xi]=0$ 消掉了零阶与一阶的交错项， $\E[\xi\xi^\top]=I$ 把噪声的二次项收成单位矩阵， 于是 $\sigma\to0$ 后恰好剩下 $\nabla_\theta\mu^\top\nabla_a q$ 这个形式。

A 与这两条矩性质无关。B 错在定理不涉及参数存在性。 C 错在 DPG 定理并不要求 $q$ 对动作是凸的。

6. 确定性策略最大的代价是什么？

  1. 梯度无法计算，只能靠有限差分近似
  2. 策略自己不探索，必须从外部注入噪声，噪声尺度又很难调
  3. 只能用于离散动作空间，无法处理连续控制
  4. 必须知道环境模型才能算 $\nabla_a q$

为什么：同一个状态永远输出同一个动作，不试新动作就没有新数据。 加噪声能解决探索，但把"探索多少"变成了一个外部超参数，调参更敏感。

A 错在 DPG 定理给出了可计算的梯度。 C 说反了，连续控制正是它的主场。 D 错在 $\nabla_a q$ 由 critic 网络反向传播得到，不需要模型。

7. 在算法 5.1 里，critic 的更新目标 $y_t$ 用的是哪个动作？

  1. 带噪声实际执行的那个动作 $a_t$，也就是真正发生的
  2. 从策略分布中重新采样得到的一个动作，每次都不同
  3. 由当前确定性策略在下一状态输出的 $\mu(s_{t+1},\theta)$
  4. 在下一状态使 $q$ 最大的动作，即 $\arg\max_a q$

为什么：确定性 Actor-Critic 的目标里用的是目标策略自己的动作， 即 $q(s_{t+1},\mu(s_{t+1},\theta),w)$。这也是它属于 on-policy 一类的原因。

A 错在噪声只用于与环境交互，不进入目标。 B 错在确定性策略没有分布可采样。 D 是 Q-learning 风格的做法，与策略梯度路线不同。

8. 与式 (31.1) 相比，DPG 定理的期望只对状态取。这一差别带来什么后果？

  1. 梯度估计的方差更小，但也就失去了策略自带的探索
  2. 梯度不再是无偏的，因此收敛性没有保证
  3. 目标函数变成了平均奖励，不再是被打折的累积回报
  4. 定理只在状态取值离散的情形下成立

为什么：少了一层对动作的采样，估计自然更稳； 但同时策略永远输出同一个动作，探索必须靠外部噪声补回来。

B 错在 DPG 定理本身仍是等式，无偏性与这一层期望无关。 C 错在度量的选择是另一件事，与策略是否随机无关。 D 错在定理对连续状态同样成立（要求可微）。

9. 证明最后一步要把外层期望的状态分布从 $d_{\pi_\sigma}$ 换成 $d_\mu$，这一步依赖什么？

  1. 价值函数对动作可微，从而可以作一阶泰勒展开
  2. 噪声 $\xi$ 服从标准正态，因此各阶矩都已知
  3. 策略参数空间是有限维的，因此极限一定存在
  4. 当 $\sigma\to0$ 时随机策略下的状态访问分布收敛到确定性策略下的那个分布

为什么：外层期望是对状态取的，要把它从随机策略的分布换成确定性策略的分布， 必须先有"这两个分布确实趋于一致"这一结论。

A 与 B 是前两步用到的性质，不是这一步的依据。 C 错在有限维参数空间并不保证分布收敛。

10. 把本书的算法主线连起来看，它们的共同点是什么？

  1. 都要求环境模型已知，只是求解的数值方法不同
  2. 都在把"价值满足某个方程"翻译成"用样本去逼近那个方程的解"
  3. 都从同一个初始策略出发，因此收敛路径完全相同
  4. 都保证收敛到全局最优，区别只在收敛速度

为什么：价值迭代用完整模型逼近，蒙特卡洛用整局回报逼近， 时序差分用单步样本逼近，策略梯度则绕开价值直接对策略求导。 手段不同，目标都是把方程的解找出来。

A 错在无模型方法（蒙特卡洛、时序差分）恰恰不需要模型。 C 错在初始策略与路径都可以不同。 D 错在只有动态规划那类方法在状态动作都有限的问题里有全局最优保证， 策略梯度一般只到局部最优。
