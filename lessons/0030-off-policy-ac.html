Off-policy Actor-Critic 与重要性采样

上一课的 A2C（Advantage Actor-Critic，用"比平均好多少"当权重的 Actor-Critic） 有个浪费的地方：数据用完就得扔。这一课解决它。 办法是让"负责探索的策略（看到什么状态就选什么动作的规则）"和"想学好的策略"分开， 再用一个比值把两边的期望对齐。这个比值叫重要性采样权重， 它能把旧数据救回来，但也会带来新麻烦：方差可能爆炸。

学完这一课你会

  • 写出重要性采样的恒等式，并说明它为什么能把期望从一套分布搬到另一套
  • 说明重要性采样比值的方差在什么情况下会失控
  • 写出 off-policy 策略梯度定理，并说清行为策略与目标策略的分工
  • 实现 off-policy Actor-Critic 的两条更新式
  • 说清裁剪与折扣这两个缓解手段分别在治什么病

1. On-policy 的限制

上一课末尾提到，A2C 是 on-policy（只用自己的数据学，学完这批就不能再用）的： 它的梯度期望是对当前策略取的。 这意味着每一批数据只能用一次，用完就过期了，因为策略已经变了。

这个代价很大。如果环境的交互很贵（真机实验、临床试验、昂贵的仿真）， 我们希望能把数据反复利用。要做到这一点，就得允许"产生数据的策略"和"我们想评估的策略"不是同一个。

定义 1.1（行为策略与目标策略）

行为策略（behavior policy）记作 $\beta(a|s)$，它是实际与环境交互、 负责产生数据的策略，通常带较强的探索（比如 $\varepsilon$-greedy）。 目标策略（target policy）记作 $\pi(a|s,\theta)$，它是我们真正想学好的那个。 两者不同时，这样的方法叫 off-policy（可以拿别人或自己以前的数据来学）。 后面还会反复用到两个英文词：actor（演员，负责做决定的那一方）与 critic（评论家，负责打分的那一方）。

2. 重要性采样

问题可以精确地表述成：我想算 $f(X)$ 在分布 $p$ 下的期望， 但手上只有从分布 $q$ 采来的样本。能不能换算？能，只要 $q$ 在 $p$ 不为零的地方也不为零。

定理 2.1（重要性采样恒等式）

设 $p,q$ 是两个概率分布，且 $q(x)>0$ 时必有 $p(x)>0$。则对任意可积函数 $f$， $$\E_{X\sim p}\big[f(X)\big]=\E_{X\sim q}\Big[\frac{p(X)}{q(X)}f(X)\Big].$$ 比值 $\frac{p(x)}{q(x)}$ 叫重要性采样权重（importance sampling weight）。

证明（离散情形）

右边按定义展开： $$\E_{X\sim q}\Big[\frac{p(X)}{q(X)}f(X)\Big]=\sum_x q(x)\cdot\frac{p(x)}{q(x)}\cdot f(x).$$ 当 $q(x)>0$ 时可以直接约掉 $q(x)$；当 $q(x)=0$ 时该样本不会被采到， 按前提此时 $p(x)=0$，这一项在左边的求和里也是零。于是 $$=\sum_x p(x)f(x)=\E_{X\sim p}\big[f(X)\big].$$

∎
注记 2.2（这只是期望的搬运，不是分布的搬运）

定理说的是"期望相等"，并没有说两个分布变成一样了。 这个区别在下一节会变成实际麻烦：期望对了，但方差可能完全失控。

例 2.3（一个能心算的例子）

设 $p=(0.5,0.5)$、$q=(0.9,0.1)$，$f(x)=(1,10)$。 在 $p$ 下：$\E_p[f]=0.5\times1+0.5\times10=5.5$。 用 $q$ 的样本算：权重是 $(0.5/0.9,\ 0.5/0.1)=(0.556,\ 5)$， 所以 $\E_q[\text{权重}\cdot f]=(0.9)(0.556)(1)+(0.1)(5)(10)=0.5+5=5.5$，两者一致。

但注意那个权重 5：第二个样本一旦被采到，它对估计的贡献是第一项的五倍。 而它被采到的概率只有 0.1。这种"小概率、大权重"的组合，正是方差问题的来源。

3. 方差的麻烦

定理 2.1 只保证期望。要谈方差，得看二阶矩：

$$\E_{X\sim q}\Big[\Big(\frac{p(X)}{q(X)}\Big)^2\Big]=\sum_x\frac{p(x)^2}{q(x)}.$$ (30.1)

这个求和对 $q$ 很敏感。若某个 $x$ 在 $p$ 下概率不小（$p(x)$ 明显大于零）而在 $q$ 下几乎不出现 （$q(x)\to0$），那么 $\frac{p(x)^2}{q(x)}\to\infty$，二阶矩发散，方差也就发散了。

命题 3.1（方差有限的条件）

当 $f$ 有界时，$\E_q\big[(\frac{p}{q}f)^2\big]$ 有限的一个充分条件是： 存在常数 $M$，使得对一切 $x$ 都有 $\frac{p(x)}{q(x)}\le M$。 若 $q$ 在 $p$ 的支撑集上取下界 $c>0$，这个条件就成立。

证明

设 $|f(x)|\le F$。则 $$\E_q\Big[\Big(\frac{p}{q}f\Big)^2\Big]=\sum_x q(x)\frac{p(x)^2}{q(x)^2}f(x)^2 =\sum_x\frac{p(x)^2}{q(x)}f(x)^2\le F^2M\sum_x p(x)=F^2M,$$ 其中第一个不等号用了 $\frac{p(x)}{q(x)}\le M$（于是 $\frac{p(x)^2}{q(x)}=\frac{p(x)}{q(x)}p(x)\le Mp(x)$） 与 $f^2\le F^2$，最后用 $\sum_x p(x)=1$。

∎

4. Off-policy 策略梯度定理

把重要性采样搬到策略梯度（算出参数往哪调能让总分更高）上，得到本课的主定理。

定理 4.1（off-policy 策略梯度定理）

设行为策略 $\beta$ 产生的数据，且 $\beta(a|s)>0$ 时必有 $\pi(a|s,\theta)>0$。则 $$\nabla J(\theta)=\E_{\substack{S\sim d_\beta\\ A\sim\beta}} \Big[\frac{\pi(A|S,\theta)}{\beta(A|S)}\,\nabla\log\pi(A|S,\theta)\,q_\pi(S,A)\Big],$$ 其中 $d_\beta$ 是行为策略下的折扣状态访问分布。

证明（思路）

从上一课的 on-policy 形式 $\nabla J=\E_{S\sim d_\pi,\,A\sim\pi} [\nabla\log\pi(A|S,\theta)q_\pi(S,A)]$ 出发，要把"按 $\pi$ 抽动作"换成"按 $\beta$ 抽动作"。 对固定的 $s$，把对 $A$ 的期望写成求和并乘除同一个 $\beta$： $$\sum_a\pi(a|s)\nabla\log\pi(a|s)q_\pi(s,a) =\sum_a\beta(a|s)\cdot\frac{\pi(a|s)}{\beta(a|s)}\cdot\nabla\log\pi(a|s)q_\pi(s,a),$$ 这正是定理 2.1 的搬运，比值就是重要性采样权重。 外层对状态的期望同理从 $d_\pi$ 换成 $d_\beta$（这一步要额外假设两个状态分布覆盖关系良好， 严格处理见原书 10.3.2 节）。合并即得结论。

∎
注记 4.2（比值乘在哪儿很关键）

注意比值 $\frac{\pi}{\beta}$ 只乘在动作那一层，它修正的是"这个动作被采到的概率不对"。 如果把比值直接乘在整条轨迹的回报（从某一步往后拿到的奖励加起来）上，就会变成"连乘"： 一条长度 $T$ 的轨迹要乘 $T$ 个比值，方差会随 $T$ 指数级恶化。 这正是逐动作修正（本定理）优于逐轨迹修正的原因。

5. 算法与两个缓解手段

算法 5.1（Off-policy Actor-Critic）

维护 actor 参数 $\theta$ 与 critic 参数 $w$，另有一个行为策略 $\beta$（常用 $\varepsilon$-greedy 的 $\pi$）。

① 用 $\beta$ 与环境交互，把经验存进缓冲区；

② critic 更新（学 $q_\pi$ 或 $v_\pi$），目标用当前目标策略算；

③ actor 更新，权重里带上比值： $$\theta\leftarrow\theta+\alpha_\theta\,\frac{\pi(a_t|s_t,\theta)}{\beta(a_t|s_t)}\, \hat A_t\,\nabla_\theta\log\pi(a_t|s_t,\theta).$$

由于 $\beta$ 与 $\pi$ 常常只差一个探索项，实践中常把比值整体略去或做弱化， 这在工程上是可行的近似，但会引入偏差。

手段 5.2（裁剪比值）

给比值设上限：$\bar\rho_t=\min\big(\rho_t,\,c\big)$，$c$ 常取 1 到 10 之间。 它压住了极端权重，代价是引入偏差。这是"用偏差换方差稳定"的典型做法。

手段 5.3（给比值加折扣）

把比值改成 $\big(\frac{\pi}{\beta}\big)^{\lambda}$（$\lambda\in(0,1]$）， 或者对历史比值做指数衰减。它让久远之前的概率偏差快速失去影响， 对应"越旧的数据越不可信"这一直觉。

注记 5.4（这条路通向哪里）

把上面的裁剪思路推到底，就得到近端策略优化（PPO）那一类算法： 它不直接乘比值，而是限制新策略不能离旧策略太远。 本课讲的是它的理论出处。再下一课换一个方向：把策略从随机改成确定性策略（每一步都选同一个动作）， 得到 DPG（deterministic policy gradient，确定性策略梯度）定理。

小结

  • off-policy 把行为策略 $\beta$ 与目标策略 $\pi$ 分开，让旧数据可以复用（定义 1.1）。
  • 重要性采样恒等式 $\E_p[f]=\E_q[\frac{p}{q}f]$ 是搬运期望的工具（定理 2.1）。
  • 它的方差取决于 $\sum_x\frac{p(x)^2}{q(x)}$；两套分布错开时方差会发散（式 (30.1)、命题 3.1）。
  • off-policy 策略梯度定理把比值乘在动作那一层，而不是整条轨迹上（定理 4.1）。
  • 裁剪比值与给比值加折扣是两个主要的缓解手段（手段 5.2、5.3）。

下一课是本书的最后一课：把策略从随机改成确定性策略（每一步都选同一个动作） $a=\mu(s,\theta)$，得到确定性策略梯度定理。 会看到它比随机策略（同一个状态按概率选不同动作）的梯度少了一层对动作的期望， 因此在连续控制里更省算力，但也就此失去了内建的探索。

课后练习

1. off-policy 方法与 on-policy 方法的核心区别是什么？

  1. off-policy 不需要价值网络，只靠策略网络就能学
  2. off-policy 只能用于离散动作，on-policy 可用于连续动作
  3. 产生数据的策略与想学好的策略可以不是同一个
  4. off-policy 不需要与环境交互，只用别人跑好的现成数据

为什么：on-policy 的梯度期望是对当前策略取的，数据必须由它自己产生； off-policy 把行为策略与目标策略分开，于是旧数据、别人的数据都能用。

A 错在 off-policy 通常也要 critic。B 说反了，两类方法都可用于连续动作。 D 错在"只用现成数据、不与环境交互"是 off-policy 的一个特例，不是它的定义。

2. 重要性采样恒等式成立需要什么前提？

  1. 两个分布必须完全相同，否则恒等式不成立
  2. 目标分布不为零的地方，行为分布也不能为零
  3. 被求期望的函数 $f$ 必须是有界的连续函数
  4. 两个分布必须都是离散分布，连续情形不适用

为什么：若某个 $x$ 在目标分布下有可能出现、在行为分布下却永远采不到， 那个位置的贡献就无法被任何样本代表。所以需要 $\beta>0$ 覆盖 $\pi$ 的支撑集。

A 错在两者可以不同，恒等式正是为了处理不同的情形。 C 错在可积即可，有界连续是更强且不必要的条件。 D 错在连续情形把求和换成积分，结论同样成立。

3. 在例 2.3 中（$p=(0.5,0.5)$、$q=(0.9,0.1)$、$f=(1,10)$），第二个样本的权重是多少？

  1. $0.1$，等于它在行为分布下的概率
  2. $0.5$，等于它在目标分布下的概率
  3. $0.556$，与第一个样本的权重相同
  4. $5$，等于 $0.5/0.1$

为什么：权重是 $\frac{p(x)}{q(x)}=\frac{0.5}{0.1}=5$。 这个样本被采到的概率只有 0.1，可一旦采到就按 5 倍计，于是它主导了估计。

A 把行为概率当成了权重。B 把目标概率当成了权重，漏了除以 $q$。 C 是第一个样本的权重（$0.5/0.9\approx0.556$）。

4. 式 (30.1) 中的 $\sum_x\frac{p(x)^2}{q(x)}$ 在什么情况下会发散？

  1. 某个 $x$ 处 $p(x)$ 不趋于零，而 $q(x)$ 趋于零
  2. 两个分布都接近均匀分布的时候，权重最稳
  3. 被求期望的那个函数 $f$ 取值都为正数时
  4. 样本量足够大时，按大数定律必然发散

为什么：分母趋于零而分子不趋于零，这一项就趋于无穷。 物理含义是"目标策略关心的区域被行为策略冷落"，那里采不到样本却需要很大权重。

B 恰恰相反，接近均匀时权重最稳。 C 错在式 (30.1) 里根本没有 $f$，它算的是权重的二阶矩。 D 错在大数定律讲的是收敛（样本越多越接近真值），与发散无关。

5. off-policy 策略梯度定理里，比值乘在哪个层级？

  1. 乘在整条轨迹的回报上，即所有时刻的比值连乘
  2. 乘在动作那一层，每个时刻只用当前的一个比值
  3. 乘在学习率（每次更新时往新信息的方向挪多远）上，等价于动态调整步长
  4. 乘在"局面值多少分"的估计上，用来修正 critic 的偏差

为什么：定理 4.1 里比值只出现在对动作求期望的那一层。 逐轨迹连乘会让方差随轨迹长度指数恶化，这是必须避免的。

A 描述的正是要避免的那种做法。C 错在比值是概率修正，不是步长调度。 D 错在比值修正的是动作分布，不作用于 critic。

6. 给重要性采样比值设上限（裁剪）会带来什么代价？

  1. 会让算法退化成 on-policy，失去复用数据的能力
  2. 会让梯度的期望变成零，学习完全停滞
  3. 会让目标策略的概率不再归一化
  4. 会引入偏差，因为被压下去的那些权重本来是有信息的

为什么：裁剪把极端权重拉回有限范围，稳住了方差，但也改变了期望值， 于是估计不再无偏。这是典型的"用偏差换方差"。

A 错在裁剪不改变数据可以复用这件事。B 错在梯度期望一般不为零。 C 错在裁剪的是权重，不是策略本身，策略概率仍然归一。

7. 为什么"给比值加折扣"（手段 5.3）是合理的？

  1. 因为给未来奖励打折的那个系数在回报里也出现，两处必须一致
  2. 因为久远之前的样本数量更多，需要压低它们的总权重
  3. 因为当前目标策略与产生旧数据时的策略差得最远，旧数据的比值最不可信
  4. 因为折扣能保证重要性采样的期望不再变化

为什么：数据越旧，它对应的行为策略与当前目标策略的差距可能越大， 比值也就越不可靠。给它快速衰减的权重，等于承认"太旧的数据别太当真"。

A 错在两个折扣的作用不同，不必一致。 B 错在这不是数量问题而是可信度问题。 D 错在加折扣本身就改变了期望，不是保持不变。

8. 命题 3.1 证明里，把 $\frac{p(x)^2}{q(x)}$ 放缩成 $Mp(x)$ 用到了什么？

  1. 比值有上界 $M$，于是 $\frac{p^2}{q}\le Mp(x)$，二次项降成一次
  2. 概率之和等于 1，于是可以让整个求和化为 1
  3. 函数 $f$ 的有界性，因为恒有 $f^2\le F^2$
  4. 两个分布都是离散的，所以能够一项一项地比较

为什么：关键是先把 $\frac{p^2}{q}$ 重写成 $\frac{p}{q}\cdot p$， 再用比值上界 $M$ 控制第一因子。$f$ 的有界性在下一步才用上。

B 用得比较晚（最后把 $\sum p$ 收成 1），不是这一步。 C 是下一步，不是把二次项化成一次项的依据。D 与放缩无关。

9. 若行为策略 $\beta$ 就是目标策略 $\pi$ 本身，off-policy 策略梯度定理会变成什么？

  1. 梯度的期望变成零，因为分子分母相同
  2. 比值恒为 1，定理退化成上一课的 on-policy 形式
  3. 比值恒为 0，因为两个分布相减得零
  4. 定理不再适用，因为它要求两套策略必须不同

为什么：$\beta=\pi$ 时 $\frac{\pi(a|s)}{\beta(a|s)}=1$，权重消失， 剩下的就是 $\E[\nabla\log\pi\cdot q_\pi]$，即上一课的 A2C 形式。

A 错在比值是 1 不是 0。C 混淆了比值与差值。 D 错在定理并不要求两者不同，相同只是它的一个特例。

10. 以下哪种做法最可能让 off-policy 训练变得不稳定？

  1. 把学习率调小一些，让更新更保守
  2. 用较短的回合，减少轨迹长度的累积
  3. 给 critic 更多训练轮次，让它估值更准
  4. 让目标策略迅速变得很贪，而行为策略仍均匀随机

为什么：目标策略越贪，它关心的动作越集中；行为策略越均匀， 那些被关心的动作在数据里出现的比例就越低。两套分布错开，权重随之爆掉， 正是命题 3.1 所说的方差失控条件。

A、C 都是在降低不稳定，B 能削弱比值沿轨迹的累积影响。 只有 D 会主动制造分布错位，把方差推到极端。
