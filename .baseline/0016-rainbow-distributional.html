第 16 课 · 第三部分 · 深度价值方法

Rainbow 与分布式 RL

回报的期望只有一个数，丢掉的东西不少。这一节说明为什么要学整个分布， 写出 C51（Categorical DQN with 51 atoms，51 个原子的分类 DQN）的类别投影和 QR-DQN 的分位数损失，并判断 Rainbow 六个组件里 哪几个值得花时间。

你会得到

  • 能写出分布式贝尔曼目标，并说清"动作仍然按期望选"的原因
  • 能实现 C51 的投影算子，并解释它为什么能保住概率质量
  • 能说出 Rainbow 消融的结论，知道该按什么顺序给自己的模型加组件

只学期望丢掉了什么

前面所有算法学的都是回报的期望：Q(s,a) 是一个数。同一个期望却对应完全不同的处境：一个动作稳定给 +1，另一个九成概率给 0、 一成概率给 +10，期望都在 1 附近，风险差一个量级。业务上若"一次大亏"比"平均收益"更重要， 只学期望就丢掉了决策信息。

分布式 RL（distributional RL）学的是回报这个随机变量， 记作 Z(s,a)，它满足 分布式贝尔曼方程（distributional Bellman equation）：

Z(s, a) ≐ r + γ Z(s′, a′) (16.1)

式中 γ（折扣因子）给未来的随机回报打折，r 是即时奖励。

等号两边都是随机变量，后果容易被忽略：分布之间没有天然的"更大"， 所以贪心动作只能对期望取 arg max，不能对分布取 max：

a* = arg maxa′ 𝔼[ Z(s′, a′) ]，   (TZ)(s, a) = r + γ Z(s′, a*) (16.2)

它改的是"学什么"，没改"怎么选动作"： 想做风险敏感决策还得换目标（如条件风险价值 CVaR），学出分布不会自动变保守。

C51：把分布钉在固定格点上

分布是连续对象，网络输出不了。C51 最直接：在 [zmin, zmax] 上放 51 个等距原子 zi = zmin + i·Δz（所以叫 C51）， 网络输出每个动作在 51 个原子上的概率， 𝔼[Z] = Σi pi zi 就是 Q 值。

难点在目标侧：r + γzj 常落在两个格点之间， 直接当 51 维标签会错位，所以先做 类别投影（categorical projection），把每个原子的概率按距离分给左右邻居。 设 b = ( clip(r + γzj) − zmin ) / Δz， l = ⌊b⌋、u = min(l+1, N−1)，则

p̂l += pj (1 − (b − l))，   p̂u += pj (b − l) (16.3)

两个权重加起来恒为 1，概率质量守恒。损失把投影后的 p̂ 当固定标签，对网络输出做交叉熵（梯度不流过投影）。 出自 Bellemare 等人的 A Distributional Perspective on RL（arXiv 1707.06887）。

QR-DQN：直接学分位数

C51 要你先猜 zmin 与 zmax：窄了分布被截断，宽了 51 个原子大半浪费。 QR-DQN（quantile regression DQN）换一种参数化： 固定 N 个分位点 τi = (i + 0.5) / N（τ 是分位点）， 让网络输出这些分位数值 ẑτi， 用 pinball 损失（pinball loss，分位数回归损失）训练：

ρτ(δ) = max( τδ, (τ − 1)δ )，  δ = y − ẑτ，   L = (1/N) Σi 𝔼[ ρτi(δi) ] (16.4)

式中 δ（预测误差）是回报目标与分位数预测之差，ρ（分位数损失）是它的惩罚项。

它不对称：τ=0.9 时低估的惩罚是高估的 9 倍，最优解就落在 0.9 分位数上， 这就是"回归分位数"的来历。相比 C51，它不必预先设定取值范围，也不用投影， 代价是要处理 N 个分位数之间的配对。论文见 Distributional RL with Quantile Regression（arXiv 1710.05941）。

Rainbow：六个组件与消融结论

Rainbow 把六个组件合进一个 DQN： Double DQN、 Dueling、 优先回放、 多步（n-step）回报、C51 分布式价值、 Noisy Net：网络权重上加可学习噪声取代 ε-greedy（ε 是探索率）， 省掉手写的 ε 衰减计划。合起来后，Atari 上的中位数表现远超当时任何单项。

有工程价值的是它的消融结论：优先回放与多步回报贡献最大， 分布式价值稳定有用，Noisy Net 最不稳定（去掉它常常只掉一点）。 加组件的顺序就先 PER（prioritized experience replay，优先经验回放）与多步，再分布式价值，最后才是 Noisy Net。完整结果见 Hessel et al., Rainbow（arXiv 1710.02298）； 想扫一遍这族方法，读 Lilian Weng 的综述。

一次只加一个。组件会互相掩护错误：投影 bug 可能被 PER 的高方差掩盖， Noisy Net 又让"策略一直随机"看起来像正常探索。没有逐个消融， 既不知道收益来自哪，也不知道该回退什么。

什么时候值得用它

  • 值得：你要"离散动作 + 高维状态"的强基线，愿意用 2–3 倍计算量 换样本效率，或者除了平均回报还在意波动范围。
  • 不值得：状态空间很小、有现成的表格解，或者目标本身风险敏感， 那得改目标函数，不是加组件。
  • 常见坑：原子格点与投影边界写错；多步回报叠加时折扣与 n 处理出错；开了 Noisy Net 还以为策略该收敛成确定性。

课后练习

1. 分布式 RL 与普通 DQN 在"学什么"上的根本差别是？

  1. 它同时维护多个 Q 网络，最后取这些网络输出值的平均值
  2. 它把折扣因子当成随机变量，训练时不断对 γ 做采样平均
  3. 它用多个目标网络轮流更新，从而降低自举带来的偏差
  4. 它学的是回报的整个分布，而不只是回报的期望值

为什么：普通 DQN 的输出是 Q(s,a) 一个数， 即 𝔼[Z(s,a)]；分布式 RL 的输出是一个分布， 期望只是它的一阶矩。分布的宽度与形状本身就是风险信息。

A 描述的是集成（ensemble），与分布式价值无关。B 不对：γ 是给定的超参， 不是随机变量。C 描述的是多重目标网络，减少的是自举目标漂移， 和"学期望还是学分布"是两件事。

2. 分布式贝尔曼方程 (16.1) 里，动作该怎么选？

  1. 仍然按期望回报选动作，因为分布之间没有天然的序关系
  2. 按分布的上分位数选动作，以追求尽可能高的潜在回报
  3. 对每个原子的价值分别取最大值，再拼回一个新的分布
  4. 随机挑一个动作，让所有动作的分布被同等地更新到

为什么：两个分布无法像实数那样直接比较大小，贪心所需的 arg max 只能作用在期望上，也就是式 (16.2)。 分布式 RL 换掉的是学习目标，不是策略提取方式。

B 是在改目标函数（那才会得到风险偏好的策略），不是标准分布式 RL 的做法。 C 把原子当成独立动作，拼出来的量没有分布含义。 D 会让策略退化，与贪心策略提取矛盾。

3. C51 里的类别投影（式 16.3）在做什么？

  1. 把奖励裁剪到固定区间，避免不同任务的奖励尺度互相干扰
  2. 把网络输出的原子概率重新归一化，防止数值下溢到零
  3. 把 r + γz 落在格点之间的概率按距离分给相邻的两个原子
  4. 把回报分布压缩成一个期望值，从而复用原来的 DQN 损失

为什么：目标 r + γzj 通常不在 [zmin, zmax] 的格点上， 必须把它承载的概率质量搬到最近的格点上。式 (16.3) 用线性插值分配， 两个权重之和恒为 1，所以总质量守恒。

A 是奖励裁剪，属于预处理，与投影无关。B 是数值技巧，不是投影的目的。 D 与分布式 RL 的初衷相反：分布式方法要保住分布，不会压成期望。

4. QR-DQN 的 pinball 损失 (16.4) 学的是什么？

  1. 它直接回归分布的均值，因此等价于普通的均方误差损失
  2. 它回归若干条指定分位数的值，不必预先设定取值上下界
  3. 它把回报离散成固定的原子格点，再用交叉熵逐格回归
  4. 它最小化预测分布与目标分布之间的 Kullback–Leibler 散度（KL）作为训练目标

为什么：pinball 损失不对称，τ=0.9 时低估的代价是高估的 9 倍，其最小点正好是该分布的 0.9 分位数。 于是网络输出的是分位数本身，不需要 zmin / zmax 这些先验设定，也不用做投影。

A 只在 τ=0.5 时成立，那时它才等于绝对误差的一半， 与均方误差仍然不同。C 描述的是 C51 的做法。D 也不是 pinball 损失的性质。

5. Rainbow 的消融实验给出的一条工程启示是？

  1. 六个组件必须同时打开，单独使用其中任何一个都完全没有效果
  2. 分布式价值的贡献最大，其次才是优先回放与多步回报这两项
  3. Noisy Net 的贡献最大，所以最该优先替换 ε-greedy
  4. 各组件贡献不均：优先回放与多步回报最有用，所以要逐个消融

为什么：Rainbow 的消融显示 PER 与多步回报的贡献最大， 分布式价值稳定有用，Noisy Net 的收益最不稳定。因此合理的加组件顺序是 PER/多步 → 分布式 → Dueling → Noisy Net，而且每加一个都要单独验证。

A 与结论相反：单个组件本身大多有效，组合只是叠加。 B 把分布式价值排到了最前，与消融结果不符。 C 高估了 Noisy Net：它是最不稳定的一项。

代码题 1 · 实现 C51 的类别投影

背景C51 的网络输出是每个动作在 n 个固定原子上的概率，目标侧还要按分布式贝尔曼方程把 r + γzj 搬回同一组原子，这件事由类别投影完成（式 16.3）：每个原子的概率按距离分给左右邻居，总质量不变。投影结果被当成训练的固定标签，梯度不流过它。c51_projection 在目标网络对 s′ 输出概率之后调用，输出直接与在线网络的输出做交叉熵。只许用 numpy，不修改输入。

输入

  • rewards：形状 (B,) 的 float 数组，即时奖励。
  • dones：形状 (B,) 的 bool 数组，True 表示该条在 s′ 终止。
  • next_probs：形状 (B, n) 的 float 数组，目标网络在 n 个原子上给出的概率，每行和为 1。
  • support：形状 (n,) 的 float 数组，等距递增的原子格点 z0 < z1 < … < zn−1，相邻间隔记作 Δz。
  • gamma：float，折扣因子 γ。

输出

  • 返回 np.ndarray，形状 (B, n) 的 float：第 i 行是搬移之后的原子概率，第 j 个分量是落在原子 zj 上的概率质量，每行和为 1 且元素非负。

会被检验输出形状为 (B, n)；每行概率和为 1 且非负（200 行 Dirichlet 随机输入下最大偏差不超过 1e-10）；终止样本的目标只剩 r（如 Tz = 0.3 时原子 0、1 拿到 0.7 与 0.3）；Tz 超过 z_max 或低于 z_min 时裁剪到两端且质量不丢；恰好落在格点上时质量全给该格点；多峰分布逐原子搬运后仍然守恒。

卡住了？看提示
  • 形状对齐：把 rewards[:, None] 和 support[None, :] 一起广播成 (B, n)。
  • 终止样本用 (~dones)[:, None] 乘在自举项上，目标就只剩 r。
  • 把质量写回用 np.add.at(proj, (rows, cols), mass)， 同一个格点可能被多个原子命中，用 += 花式索引会丢贡献。

代码题 2 · 实现 pinball 损失与梯度

背景QR-DQN 让网络输出若干个分位数值，用 pinball 损失训练。这个损失对偏差方向不对称：tau = 0.9 时低估的代价是高估的 9 倍，所以最小化它得到的常数就落在 0.9 分位数上。两个函数在训练步里配套使用：pinball_loss 算损失值，pinball_grad 给出它对网络输出 predictions 的梯度，手写的 numpy 反传要用后者。都不修改输入，只许用 numpy。

输入

  • predictions：float 数组，网络输出的分位数值。
  • targets：float 数组，回报目标 y，形状与 predictions 相同或可广播成同一形状。
  • taus：形状 (n,) 的 float 数组，分位点 τ，与最后一维对齐，同一个 τ 作用到那一列。

输出

  • pinball_loss 返回 Python float：先按 δ = targets − predictions 逐元素算 ρτ(δ) = max(τδ, (τ−1)δ)，再对所有元素取平均。
  • pinball_grad 返回 np.ndarray，形状与广播后的结果相同：第 (i, j) 个元素是平均损失对 predictions[i, j] 的偏导，δ > 0 时为 −τ / 总元素数，δ < 0 时为 (1 − τ) / 总元素数，δ = 0 处为 0。

会被检验tau=0.5 时 +2 与 −2 的偏差代价相同；tau=0.9 且偏差为 1 时低估罚 0.9、高估只罚 0.1；四个元素的手算值与逐元素取法一致；解析梯度与中心差分数值梯度在 1e-6 内一致；梯度形状与广播结果一致；在 1 到 10 的样本上扫常数，tau=0.85 时平均损失最小的常数落在 9 附近。

卡住了？看提示
  • max 的两个分支用 np.maximum(tau * d, (tau - 1.0) * d) 一次写完。
  • 求和不要求 Python 循环：np.mean(...) 就够，注意 float(...) 转成 Python 浮点。
  • 梯度除以元素总数后才对应"平均损失"的导数。
