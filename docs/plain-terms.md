# 概念术语白话表（27 课共用，禁止各课自行改写）

零基础读者卡住的不是缩写（DQN），而是**概念**。这份表给每个概念一个**统一的白话解释**与
**一个生活比喻**。各课第一次用到某个词时，**照抄这里的解释**（可以按上下文微调措辞，
但比喻与含义不能变），保证同一个词在 27 课里说法一致。

写法：`术语（白话解释）` 或 `术语，就是……`。**不要**只给英文全称（`折扣因子（discount factor）`
对零基础的人是没用的，要写 `折扣因子（越往后的奖励，权重越小，相当于给它打了个折）`）。

## 一、最基础的世界观（0001–0003）

| 术语 | 白话解释（照抄） | 生活比喻 |
|---|---|---|
| 智能体 | 做决策的那一方，就是你写的程序 | 打游戏的是你 |
| 环境 | 智能体之外的一切，会对你的动作做出反应 | 游戏本身和对手 |
| 状态 | 此刻你能看到的信息，是你做决定的依据 | 现在棋盘长什么样 |
| 动作 | 你这一步能做的选择 | 走哪一步棋 |
| 奖励 | 环境对你刚做的动作打的分数，一个数 | 这一步得了几分 |
| 策略 | 一套"看到什么状态就选什么动作"的规则 | 你的出招习惯 |
| 轨迹 | 从开始到结束，一路上（状态, 动作, 奖励）的记录 | 一整局的棋谱 |
| 回合 | 从开始到结束的一整局 | 一盘棋 |
| 监督学习 | 拿"题目 + 标准答案"来学的机器学习方式 | 有答案的练习册 |
| 信用分配 | 最后的结果该算在哪几步头上 | 团队项目搞砸了，责任怎么分 |
| 数据分布 | 你手头这批数据是什么样的、偏向哪些情况 | 你只见过白天鹅，就以为天鹅都是白的 |

## 二、目标与价值（0003–0005）

| 术语 | 白话解释（照抄） | 生活比喻 |
|---|---|---|
| 回报 | 从现在起一直到结束，把每一步奖励加起来的总分 | 这一局打完的总得分 |
| 折扣因子 | 越往后的奖励，算进总分时权重越小；等于给它打了个折 | 明天的 100 块不如今天的 100 块值钱 |
| 价值函数 | 从某个状态出发，按某套策略走下去，**平均**能拿多少总分 | 站在棋盘某个局面，估计最终能赢多少 |
| 状态价值 | 只看状态、不管具体选哪个动作的那个价值 | "现在这个局面好不好" |
| 动作价值 | 在某个状态下**先选某个具体动作**，之后再好好走，能拿多少总分 | "现在走这一步好不好" |
| 贝尔曼方程 | 把"这一步的价值"和"下一步的价值"连起来的等式：这一步的价值 = 这一步的即时奖励 + 打折后的下一步价值 | 今天的幸福感 = 今天的快乐 + 打八折的明天的幸福感 |
| 状态转移 | 你做完动作之后，环境从当前状态跳到下一个状态 | 走完一步棋，棋盘变了 |
| 转移概率 | 这个跳转不是百分之百确定的，而是一组可能性，各带着自己的概率 | 掷骰子走棋 |
| 马尔可夫性 | 下一个状态只取决于**当前**状态和动作，与更早的历史无关 | 下棋只看现在的棋盘，不必回放全程 |
| 马尔可夫决策过程 | 满足马尔可夫性的那类标准问题设定，简写 MDP | 规则明确、只看当前局面的棋盘游戏 |
| 策略评估 | 给定一套策略，算出它到底值多少分 | 给一套打法打分 |
| 策略改进 | 根据算出的分数，把策略里明显吃亏的选择换掉 | 把打得差的招换成更好的 |
| 策略迭代 | 反复"打分 → 改招"，直到改不动为止 | 反复复盘改进打法 |
| 价值迭代 | 不显式维护策略，直接把价值反复往最优方向推 | 直接估算每个局面的最优价值 |
| 收敛 | 一轮轮算下去，数值不再明显变化，稳定下来了 | 水位不再上涨 |
| 压缩映射 | 每迭代一次，两个估计之间的差距就缩小一点，所以最终必然稳定 | 两块磁铁越靠越近 |
| 不动点 | 再迭代一次也不变的那种解 | 天平平衡的位置 |

## 三、不用模型也能学（0007–0011）

| 术语 | 白话解释（照抄） | 生活比喻 |
|---|---|---|
| 蒙特卡洛 | 把一整局走完，用真实拿到的总分来估计价值 | 打完一整局才复盘 |
| 时序差分 | 不用等到一局结束，用"走一步之后的新估计"来更新"走这一步之前的估计" | 边走边修正判断 |
| 自举 | 用自己当前的估计去更新自己当前的估计，等于自己拽自己的鞋带往上提 | 自己给自己打分，再按这个分改自己的判断 |
| 学习率 | 每次更新时，往新信息的方向挪多远；太大会来回震荡，太小就学得慢 | 调整幅度 |
| 贪心 | 在当前估计里挑看起来最好的那个 | 只挑眼前最好的 |
| 探索 | 故意试试那些现在看起来不是最好的选择 | 换个没吃过的菜 |
| 利用 | 挑现在看起来最好的那个选择 | 点你最爱吃的那道菜 |
| 探索率 | 每次决策时，有多大比例的概率去做"随便试一个" | 十次里有一次乱点 |
| 多臂老虎机 | 只有"选哪个"、没有"局面变化"的最简版问题 | 一排老虎机，不知道哪台吐钱多 |
| 离线 | 不能与真实环境交互，只能用已经攒下来的历史数据学 | 只能看录像，不能上场 |
| 资格迹 | 给最近走过的每个（状态, 动作）记一笔"欠账"，这次的误差按欠账多少摊回去 | 刚做过的事记得最清，越久越淡 |
| n 步回报 | 先往前看 n 步拿真实奖励，剩下的用估计补上 | 先走 n 步再靠经验猜 |
| 重要性采样 | 用另一套策略产生的数据，来估计当前策略的表现，需要按概率比例做修正 | 用别人的购物小票估算你的口味，得按比例折算 |

## 四、用神经网络来记（0012–0016）

| 术语 | 白话解释（照抄） | 生活比喻 |
|---|---|---|
| 函数逼近 | 状态太多记不下整张表，干脆用一个带参数的函数去"猜"价值 | 记不住每个考生的分数，就用一条公式估 |
| 特征 | 把原始状态加工成一组数字，供函数使用 | 把一个人的情况概括成几项指标 |
| 泛化 | 在没见过的状态上也能给出靠谱的估计 | 做过练习册的题，考试遇到新题也会 |
| 梯度 | 往哪个方向调参数能让误差下降最快 | 下山时哪边最陡 |
| 半梯度 | 更新时只对"预测的那部分"求梯度，对"目标那部分"当常数看 | 只调自己的判断，先不管参照物也在动 |
| 经验回放 | 把走过的每一步都存进一个池子，训练时从池子里随机抽一批出来用 | 错题本，反复抽着复习 |
| 目标网络 | 另存一份"稍旧"的网络专门用来算目标，隔一阵才同步一次，避免追着自己跑 | 照着旧照片找目标，别照镜子 |
| 双 Q | 用两套估计分别负责"挑动作"和"打分"，压住总是高估的毛病 | 一个人挑，另一个人评 |
| 过估计 | 因为总是取最大值，估计出来的分数系统性地偏高 | 每次都挑最好听的评价，越听越高 |
| 最大化偏差 | 上一条偏差给学习带来的系统性错误 | 盲目乐观导致判断失准 |
| 优先经验回放 | 抽样时不均匀抽，优先抽那些"误差大、还没学会"的样本 | 错得多的题多刷几遍 |
| 分位数 | 不预测一个平均值，而是预测"有 30% 可能不超过多少、70% 不超过多少" | 不只报平均工资，还报分布 |
| 软更新 | 目标网络的参数不是直接复制，而是每次只往新网络挪一点点 | 慢慢跟上，不要猛跳 |
| 延迟更新 | 让评论家先学一会儿，演员慢几拍再跟 | 先让裁判看清，再让选手改动作 |

## 五、直接学策略（0017–0020）

| 术语 | 白话解释（照抄） | 生活比喻 |
|---|---|---|
| 策略梯度 | 不绕道去估价值，直接算"参数往哪调能让拿到的总分更高" | 直接调出招习惯 |
| 对数概率 | 把概率取对数；概率很小的时候也不会变成 0，方便计算 | 用对数刻度描述"可能性多小" |
| 似然 | 当前这套参数，产生出我们观测到的这些数据的可能性有多大 | 这套说法解释现有证据的能力 |
| 交叉熵 | 衡量两套概率分布差多远的一个常用指标 | 两份预测差多少 |
| 基线 | 从回报里减掉的一个参照值，只用来降波动，不改变平均方向 | 打分时先减去"及格线" |
| 优势函数 | 在某个状态下，选这个动作比"平均水平"好多少 | 你这一步比常规走法强多少 |
| 熵 | 衡量"选择有多随机、多分散"；熵大代表还敢试 | 菜单越丰富越不挑食 |
| 熵正则 | 在目标里加一项鼓励保持随机性，防止过早死磕一个选择 | 强制留一点好奇心 |
| 方差 | 同一个做法重复很多次，结果波动有多大 | 成绩忽高忽低 |
| 偏差 | 估计值系统性地偏离真值 | 秤一直偏重两斤 |
| 剪裁 | 把过大的更新幅度砍掉，不让这一步改得太狠 | 限速 |
| 信赖域 | 规定这一步只允许在"离旧策略不太远"的范围内改 | 每次只许挪一小步 |
| 超参 | 需要你自己设定、而不是训练学出来的参数 | 火候，得自己掌握 |

## 六、离线、模仿与大模型（0025–0027）

| 术语 | 白话解释（照抄） | 生活比喻 |
|---|---|---|
| 模仿学习 | 不去试错，直接学着模仿别人的动作 | 看师傅怎么做就跟着做 |
| 行为克隆 | 最朴素的模仿学习：把"别人看到什么就做什么"当成监督学习来学 | 抄作业 |
| 偏好 | 只告诉你"这两个里我更喜欢哪个"，不给绝对分数 | 二选一比打分容易 |
| 奖励模型 | 用一个学出来的模型给回答打分，代替人去打分 | 训练一个自动评委 |
| 稀疏奖励 | 绝大多数步骤都拿不到奖励，只有极少数关键时刻有分 | 只有通关才得分 |
| 奖励塑形 | 人为加一些中间奖励，让学习有路可走 | 把大目标拆成小目标给小红花 |
| 样本效率 | 拿到同样多的经验能学多好；效率高就是"更省数据" | 同样的练习量谁进步快 |

## 用法与红线

- 第一次出现某个术语时，**照抄上表的白话解释**；第二次起直接用术语即可。
- 若某个概念**本课不打算展开**，就写"这个概念 X 课会讲"，**不要**当作已知词直接使用。
- 比喻可以换，但**含义不能变**（例如"自举"必须体现"用估计更新估计"）。
- 数学记号第一次出现要读出来：`Σ` 写成"Σ（求和号，把后面那串全加起来）"；
  `argmax` 写成"argmax（挑出让后面最大的那个选择）"；`𝔼` 写成"𝔼（期望，长期平均下来是多少）"。
- numpy 概念第一次出现要说明：数组（一排数字的容器）、形状（这个数组几行几列）、
  广播（形状不同也能逐元素运算的自动扩展规则）。

## 七、概率与 numpy 基础（读者完全没学过，第一次出现就要讲）

读者**没学过概率、也没用过 numpy**。下面这些词第一次出现时必须给白话，且 27 课说法一致。

### 概率

| 术语 | 白话解释（照抄） | 生活比喻 |
|---|---|---|
| 概率 | 一件事发生的可能性，用"平均一百次里大约发生几次"来理解；0.3 就是大约一百次里三十次 | 天气预报说 30% 会下雨 |
| 期望 | 同一件事重复很多次之后的平均结果，不是某一次的结果 | 抛 1000 次硬币，正面大约 500 次 |
| 方差 | 结果波动有多大；方差大就是忽高忽低，方差小就是每次差不多 | 成绩忽高忽低 vs 一直稳定 |
| 标准差 | 方差的平方根，单位和原数据一样，读起来更直观；越大说明波动越大 | 同上的"波动幅度" |
| 高斯分布 | 最常见的那种"中间高、两边低"的钟形分布；大部分值落在平均值附近 | 全班身高分布 |
| 采样 | 按概率随机抽一个值出来 | 从抽奖箱里摸一个球 |
| 随机种子 | 一个起始编号；**同一粒种子必然给出同一串随机数**，所以测试才能复现 | 同一个发牌顺序 |
| 均匀分布 | 每个结果出现的可能性一样大 | 掷一枚公平的骰子 |

### numpy

| 术语 | 白话解释（照抄） | 生活比喻 |
|---|---|---|
| 数组 | 一排（或几排）数字的容器；`np.array([1.0, 5.0])` 就装了 2 个数 | 一行格子 |
| 形状 | 这个容器几行几列；`(4,)` 表示一行 4 个数 | 表格的尺寸 |
| 下标 | 第几个元素的位置；**从 0 开始数**，所以 4 个元素的下标是 0、1、2、3 | 门牌号从 0 号开始 |
| 广播 | 两个形状不同的数组做逐项运算时，numpy 自动把小的那个"铺开"对齐 | 一行数字和一个数相乘，每个都乘 |
| `np.zeros(n)` | 造一个长度 n、全是 0 的数组 | 一张空白表格 |
| `np.argmax(a)` | 返回最大值所在的**下标**（不是最大值本身） | 找出第一名是几号选手 |
| `np.max(a)` / `a.max()` | 返回最大值**本身** | 第一名的成绩是多少 |
| `rng.random()` | 返回一个 0 到 1 之间的随机小数 | 随机抽一个百分数 |
| `rng.integers(0, n)` | 返回 0 到 n−1 之间的随机整数；**右端 n 取不到** | 抽一个签号 |
| 原地修改 | 直接在传进来的那个数组上改，不新建一个 | 在原件上改字，而不是抄一份改 |

## 八、小写英文术语（同样必须给白话）

`audit-terms.py` 只查**大写缩写**（DQN、PPO），所以下面这些小写英文词一直没人管——
可它们对零基础读者同样是天书。**第一次出现必须给中文解释**。

| 术语 | 白话解释（照抄） | 生活比喻 |
|---|---|---|
| actor | 出招的那一方，负责决定这一步做什么动作；它本身就是策略，所以也叫"策略网络" | 场上踢球的人 |
| critic | 打分的那一方，负责估计"现在这个局面值多少分"；它估计的是价值，所以也叫"价值网络" | 场边的教练 |
| actor-critic | 一边出招、一边打分，用打出来的分去改出招习惯 | 球员 + 教练 |
| on-policy | 边学的那套策略，**就是**正在用来产生数据的那套 | 边打边改自己的打法 |
| off-policy | 边学的那套策略，**不是**产生数据的那套（数据来自另一套旧策略） | 看别人的录像学自己的打法 |
| rollout | 让智能体跑一遍，把一路上遇到的经历收集起来 | 打一局收集棋谱 |
| batch | 一批样本；训练时一次处理一小批，而不是一条一条来 | 一次批改一叠作业 |
| epoch | 把同一批数据完整过一遍 | 把一本练习册从头到尾做一遍 |
| buffer | 存放经历的池子，需要时从里面抽样 | 错题本 |
| softmax | 把一组原始分数变成一组"加起来等于 1"的概率，分数高的概率大 | 把分数换算成百分比 |
| logits | 神经网络输出的、**还没变成概率**的那组原始分数 | 还没换算成百分比前的原始分 |
| warmup | 开头那一段先随便跑跑、让估计稳定下来的阶段 | 热身 |

**写法示例**（第一次出现时）：
> `actor`（出招的那一方，负责决定动作）与 `critic`（打分的那一方，负责估计局面值多少分）分工不同。

之后可以直接用 `actor` / `critic`，不必每次都解释。

## 用法补充

- **不要写嵌套括号**：`TD（temporal difference，时序差分（用…更新…））` 这种"括号里还有括号"读起来最累。
  改成拆开写：`TD（temporal difference，时序差分）。它的意思是：用"走一步之后的新估计"来更新"走这一步之前的估计"。`
- 可用 `python3 tools/audit-readability.py` 检查「嵌套括号」与「未解释的小写英文词」两列。

## 九、同词不同义：一个中文词在两处指不同概念（务必消歧）

课程跨越 27 课，有些中文词在不同部分指**完全不同的东西**。读到后面时，
必须在词里加一个限定语，让读者知道这不是前面那个意思。

| 中文词 | 出现处 | 指什么 | 该怎么写 |
|---|---|---|---|
| **偏好** | `0002`（老虎机） | **动作偏好值**：每个臂一个可正可负的打分，只表示相对好坏，不是奖励 | `偏好值（每个臂一个可正可负的打分…）` |
| **偏好** | `0024`／`0025`（RLHF／离线） | **人类偏好**：只告诉你"这两个里我更喜欢哪个"，不给绝对分数 | `人类偏好（只告诉你"这两个里我更喜欢哪个"，不给绝对分数）` |
| **策略** | 全部 | 一套"看到什么状态就选什么动作"的规则 | 无需消歧 |
| **优势** | 全部 | 在某个状态下，选这个动作比"平均水平"好多少 | 无需消歧 |

**处理原则**：
- 遇到上面这类词，**在后出现的那一处加上限定语**（如把"偏好"写成"人类偏好"），
  而不是指望读者记得前面那一处。
- 若以后发现新的同词不同义，按同样方式补进这张表，并在两处都加限定语。

**为什么要这样做**：读者是零基础，他记住的是"上次那个词是什么意思"。
同一个词换意思而没有任何提示，会让他以为自己理解错了，比完全没学过更打击人。

## 十、业务与技术外来词（同样要解释）

反馈原话：「**这个 banner 是什么东西？我根本不知道呀，你上来就把这个东西摆到我脸上我又不懂。**」

课程讲的是业务场景（电商、广告、推荐），会用到一些英语借词。这些词在中文技术圈很常见，
**但零基础读者未必认识**，而它们既不是缩写（audit-terms 不管），也不在概念术语表里。
**第一次出现必须给一句中文解释**，之后可以继续用原词。

| 外来词 | 白话解释（照抄） |
|---|---|
| banner | 网页或 App 顶部那条可以点的图片广告 |
| 点率 | 看到它的人里，有多大比例真的点了它 |
| A/B 测试 | 把流量分成几组、每组给不同方案，比一比哪组效果好 |
| shadow 模式 | 新策略只在后台跟着真实流量跑、不真的生效，先看它会怎么决策 |
| 小流量 | 只让一小部分用户看到新方案，出事也只影响这一小部分 |
| 护栏指标 | 用来兜底的安全线，比如"下单成功率不能掉" |
| sum-tree | 求和树：把优先级放在二叉树的叶子上，父节点存两个孩子之和，便于按比例采样 |
| one-hot 向量 | 只有对应的那一格是 1，其余全是 0 |
| logit | 还没变成概率的原始分数 |
| mini-batch | 一小批样本 |
| dropout | 训练时随机"关掉"一部分神经元，防止过拟合 |
| NaN | 不是数（Not a Number），程序算出了非法值 |
| gather | 按给定的下标把对应的元素取出来 |
| GPU / CPU | 显卡 / 处理器 |
| rollout | 让程序跑一遍，把一路上遇到的经历收集起来 |

**判定口径**：外来词首次出现处，其后 30 字内要有中文（括注或"就是/意思是"这类解释）。
可用 `python3 tools/audit-readability.py` 检查（第三列信号）。
