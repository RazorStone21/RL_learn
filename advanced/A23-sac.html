进阶 · 第五部分 · 连续控制与最大熵

SAC：最大熵强化学习

这一节讲 SAC（soft actor-critic，软演员-评论家），连续控制里最常用的算法之一。 连续控制里的算法分两类。一类学确定性策略（deterministic policy）：每个状态只输出一个动作， 这类做法统称策略梯度（policy gradient）：直接算"参数往哪调能让总分更高"， 第 22 课的 TD3（twin delayed deep deterministic policy gradient，双延迟深度确定性策略梯度）就是其中一支。 另一类学的是随机策略（每次给出每个动作的概率，挑一个执行），SAC 属于这一支。 它把随机性直接写进优化目标，读完你能写出它的软 Q 目标， 说清温度（一个决定"随机性值多少分"的旋钮）在调什么， 也能判断什么时候该用 SAC、什么时候该用 TD3。

你会得到

  • 能写出最大熵目标与软贝尔曼方程，解释 αent（温度系数）在权衡什么
  • 能写出高斯策略的对数概率，并检查 tanh 的雅可比项有没有写反
  • 能说出 SAC 样本效率高的两个具体来源，而不只是"它更强"

把随机性写进目标里

先看 TD3 的探索方式：策略（一套"看到什么状态就选什么动作"的规则）本身是确定的，随机性从外面加。 这有个副作用：噪声大小成了纯手调的旋钮，调小了探索不够，调大了学到的东西被噪声冲掉。

SAC 换个思路：把随机性直接写进优化目标。它输出的不再是一个动作， 而是一个概率分布（每个可能的结果各自有多大可能）：每个动作各有一个被选中的概率。 除了回报（从现在起一直到结束，把每一步奖励加起来的总分）， 还要求策略（一套"看到什么状态就选什么动作"的规则）尽量不确定：

J(π) = Σt 𝔼(st,at)~ρπ [ r(st, at) + αent H( π(·|st) ) ] (23.1)

式中 ρ 是状态访问分布，意思是训练时各个状态被访问到的频繁程度。 式子里的 Σ 是求和号，意思是把每一步 t 的括号内容加起来； 𝔼（期望，同一件事重复很多次之后的平均结果）表示对右边的内容取平均。

括号里第二项是 αent 乘上熵（衡量"选择有多随机、多分散"，熵大代表还敢试）。 熵越大，说明策略越愿意把概率摊到多个动作上。

这就是最大熵（maximum entropy）目标。它带来两个实际好处： 几个动作的动作价值（在某个状态下先选某个具体动作，之后再好好走，能拿多少总分）接近时， 策略会把概率摊开，探索自动发生；概率不被压在一个动作上，执行有偏差时行为也不至于完全走样。

本课程按 符号表 的约定把温度记作 αent。 文献里常写成 α，别和学习率（每次更新时往新信息的方向挪多远）搞混。 术语对照见 术语表。

温度 α_ent：探索换收益的汇率

αent 是温度系数（熵那一项前面的系数，决定"一个单位的熵值多少回报"）。 它是一个要你自己设定的数，也就是超参（需要你自己设定、而不是训练学出来的参数）。 它接近 0 时，熵那一项几乎消失，就退回只看回报的目标； 它太大，策略会为了熵而牺牲收益，最后学出一个"平均动作"。

手调它很烦，所以 SAC 的第二个版本让 αent 自动调节： 先设一个目标熵 Ĥ（通常取 −dim(A)，也就是每个动作维度平均保留 e 的随机性水平）， 然后对 αent 本身做梯度下降：

J(αent) = 𝔼 [ −αent ( log πθ(a|s) + Ĥ ) ] (23.2)

式中 θ 是策略参数。

它是个负反馈：实际熵低于目标就增大 αent，鼓励多探索；高于目标就减小。 于是你只要指定"我想要多随机"，不必手调尺度。

软 Q 与软贝尔曼方程

把熵项并进价值里，就得到软 Q 函数（soft Q-function），就是"价值里已经含了熵那一项"的 Q。 它的目标是在 TD3 的双 Q（用两套估计分别负责挑动作和打分，压住总是高估的毛病） 目标上再加一个熵奖励：

y = r + γ ( mini=1,2 Qφ−i(s′, a′) − αent log πθ(a′|s′) ),  a′ ~ πθ(·|s′) (23.3)

式中 φ 是价值网络参数，γ 是折扣因子（越往后的奖励，算进总分时权重越小，等于给它打了个折）， π 是策略。

注意中间那个减号。log π 读作对数概率（把概率取对数；概率很小的时候也不会变成 0，方便计算）： 它越低，说明这个动作越不可能被选中，−αent log π 就越大，目标越高。 这等于给"在 s′ 处选了个冷门动作"发奖励，也就是熵奖励在实现里的样子。

两处容易写错：符号写反（变成惩罚探索，策略会迅速变确定）， 以及用了目标动作采样（按概率抽一个数）却用了当前策略的对数概率。

critic（打分的那一方，负责估计局面值多少分，所以也叫价值网络）的学习还要用到两个老工具：它靠 自举（用自己当前的估计去更新自己当前的估计，等于自己拽自己的鞋带往上提）， 所以需要一份目标网络（另存一份"稍旧"的网络专门用来算目标，隔一阵才同步一次，避免追着自己跑）， 同步时用软更新（每次只把参数往新参数挪一点点，慢慢跟上，不要猛跳）。 自举带来的过估计（因为总是取最大值，估计出来的分数系统性地偏高）由双 Q 压住。

重参数化：让采样可以求导

策略网络也叫 actor（出招的那一方，负责决定这一步做什么动作）。 它要输出一个分布而不是一个动作，具体做法是：网络输出均值和标准差， 再从对应的高斯分布（最常见的那个钟形分布）里采样（按概率抽一个数）。 高斯分布中间高、两边低，大多数取值落在均值附近； 标准差（衡量波动大小）决定它摊得多开。

要对参数 θ 求梯度，就不能把采样当成黑箱。SAC 用 重参数化技巧（reparameterization trick）：把随机性挪到外部噪声上，再对参数求导。

a = tanh( μθ(s) + σθ(s) ⊙ ξ ),  ξ ~ N(0, I) (23.4)

式中 μ 是策略输出的均值，σ 是标准差，ξ 是标准高斯噪声。符号 ⊙ 表示逐元素相乘。

现在 ξ 与 θ 无关，动作 a 对 θ 就逐点可微了。这种梯度叫路径导数， 它比把 ∇θ log π 当权重的那种得分函数估计（score function estimator）低很多， 也就是波动小很多。它加上 off-policy（边学的那套策略不是产生数据的那套，等于看别人的录像学自己的打法） 的经验回放（把走过的每一步都存进一个池子，训练时从池子里随机抽一批出来用）， 就是 SAC 样本效率（拿到同样多的经验能学多好，效率高就是"更省数据"）高的两个具体来源。

tanh 的雅可比：最容易静默写错的一处

动作被 tanh 压到 [−1, 1] 之后，概率密度也变了。 按变量替换公式，对数概率必须补上雅可比项。注意它前面是加号： log(1 − tanh²u) 本身已经带负号，写成相减会得到另一个值。

log π(a|s) = log N(u; μ, σ) + Σj log ( 1 − tanh²(uj) ),  u = 前激活值 (23.5)

式子里的 u 是 tanh 之前的前激活值，uj 是它的第 j 个维度。 漏掉这一项、或者把符号写成减，训练不会报错：损失照降，梯度照走，只是熵的估计整个偏了。 所以这类代码必须像代码题 1 那样逐项数值核对， 不能"跑起来能收敛（一轮轮算下去，数值不再明显变化，稳定下来了）就行"。

SAC 还是 TD3

维度SACTD3
策略随机，熵项内建确定，噪声外挂
样本效率通常更高（低方差的路径梯度加上自动探索）略低，探索不足时更明显
超参敏感度较低，温度可以自动调中，噪声尺度要调
推理成本要采样，动作不可复现一次前向，可复现
典型选择连续控制默认首选要确定性、便宜推理时

一个常见症状：策略训练早期就变得几乎确定，这叫熵塌缩。 先查式 (23.3) 的符号，再看 αent 是不是被自动调节压到接近 0，最后才去动学习率。

顺带说一个容易混的词：策略评估（给定一套策略，算出它到底值多少分）。 SAC 不做精确的策略评估，它靠采样估计，这也是它能省数据的原因之一。

课后练习

1. 最大熵目标（式 23.1）加上的熵项，给训练带来什么？

  1. 它把奖励的尺度统一到固定区间，让不同任务能共用一套学习率
  2. 它让 Q 值的估计变成无偏的，从而消除自举带来的过估计
  3. 它保证策略一定收敛到全局最优，代价是需要更多次环境交互
  4. 它内建了探索与鲁棒性，策略在等价动作之间会主动分摊概率

为什么：熵项奖励"不确定性"。当多个动作的价值接近时， 策略会把概率摊开，于是探索自动发生；同时它不会把全部概率压在一个动作上， 执行偏差或环境噪声不至于让行为完全走样。

A 是奖励归一化的事，与熵项无关。B 说反了因果：软 Q 目标里依然有取较小值和自举， 过估计只是被双 Q 压制，不是被熵项消除。C 是过强的承诺：熵项不保证全局最优， SAC 依然是带函数逼近（状态太多记不下整张表，干脆用一个带参数的函数去猜价值）的 actor-critic，没有这种理论保证。

2. 温度系数 α_ent 太大会出现什么典型症状？

  1. 策略过早变确定，熵迅速塌缩，探索不足而卡在次优解
  2. 策略为了熵而牺牲收益，动作接近噪声，学出一个平均解
  3. critic 的目标值不断变大，Q 值单调发散，训练直接失败
  4. 目标熵会自动上调，温度随即回落，因此没有可观察的影响

为什么：αent 是"熵值多少回报"的汇率。汇率给得太高， 策略宁愿要随机性也不要收益，最后输出一个高熵的平均动作， 看起来"学不动"，实际是目标函数就该这么解。

A 是 αent 太小的症状，方向反了。 C 与熵项没有直接关系，Q 值发散通常来自自举、学习率或奖励尺度。 D 把自动调节的方向说反了：实际熵高于目标时，αent 是被减小的， 而且这个过程有可观察的滞后，不是瞬时的。

3. 式 (23.3) 里为什么是减去 α_ent log π，而不是加上？

  1. log π 越负说明动作越冷门，减去它等价于给冷门动作发熵奖励
  2. 减去是为了让目标值保持在奖励量级内，避免数值溢出与截断
  3. 减去等价于对高概率动作额外奖励，从而加快策略的收敛速度
  4. 正负号只是文献习惯，两种写法训练出来的策略在数学上等价

为什么：对数的取值范围是 (−∞, 0]，动作越"冷门"，log π 越负， −αent log π 就越大。所以减号的效果是：在 s′ 处选了不常见的动作就加分， 这就是熵奖励在贝尔曼目标里的形态。

B 是靠数值手段解决的问题，不是靠翻转符号。 C 说反了：减号奖励的是低概率动作，不是高概率动作。 D 错在"等价"二字：换成加号会把目标改成惩罚探索，策略会迅速变确定，那是另一个算法。

4. 重参数化技巧（式 23.4）在这里解决了什么问题？

  1. 它把连续动作离散化，让 DQN（deep Q-network，深度 Q 网络）一族的算法也能用于连续控制
  2. 它把目标网络的参数更新变成软更新，从而稳定自举的目标
  3. 它把随机性挪到与参数无关的噪声上，使动作对参数可微
  4. 它把策略的熵写成闭式解，从而不需要再采样估计对数概率

为什么：采样本身是随机操作，不可导。 写成 a = tanh(μθ(s) + σθ(s) ⊙ ξ) 之后， 随机性只来自外部噪声 ξ，a 对 θ 逐点可导，于是能得到方差很低的路径导数。

A 与重参数化无关，它属于动作空间（所有可能动作组成的集合）怎么表示的问题。 B 说的是软更新，是目标网络的技巧。 D 不成立：SAC 依然要靠采样估计对数概率， 重参数化改变的是"如何对采样结果求导"，不是"要不要采样"。

5. SAC 样本效率高的两个具体来源是什么？

  1. 它不需要目标网络，并且每一步都用全部数据做一次精确的策略评估
  2. 路径导数方差低，且 off-policy 的经验回放让每条数据被反复利用
  3. 它把动作空间裁剪到 [−1, 1]，并且用 tanh 让梯度不会爆炸或消失
  4. 它用确定性策略省掉采样开销，并且用双 Q 把过估计压到零

为什么：低方差的路径导数让每个梯度步的信息量更大； off-policy 加上经验回放让同一条交互数据被反复使用。 两者叠加，就是"同样的交互预算下通常学得更快"的直接解释。

A 与实现不符：SAC 有目标网络，也不做精确的策略评估，精确评估是动态规划才有的能力。 C 描述的是动作表示与数值技巧，它们让训练更稳，但不是样本效率的来源。 D 把 SAC 说成了确定性策略算法，那是 TD3；双 Q 也只是压制上偏，压不到零。

代码题 1 · 实现高斯策略的对数概率与重参数化（numpy）

背景这是 SAC 策略链路上的三个零件，动作维度是 D，一批的样本数是 B。 策略网络输出高斯分布的均值和对数标准差：sample_action 在收集数据时生成动作， 两个对数概率函数在算熵项与 actor 的损失时被调用。 输入是分布参数与噪声，输出是逐样本的动作或对数概率。

请实现 gaussian_log_prob(x, mu, log_std)、squashed_log_prob(x, mu, log_std) 与 sample_action(mu, log_std, noise)。① 高斯对数概率按维求和：

log N(x; μ, σ²) = −½ Σj [ ( (xj−μj)/σj )² + 2 log σj + log 2π ]

式子里的 Σ 是求和号，意思是把每个动作维度 j 的那一项加起来；log 是自然对数。

输入

  • x：形状 (B, D) 的浮点数组，采样值；在 ② 里是 tanh 之前的前激活值 u。形状就是"几行几列"。
  • mu：形状 (B, D) 的浮点数组，分布的均值。
  • log_std：形状 (B, D) 的浮点数组，对数标准差；对它取 exp 就得到标准差。
  • noise：形状 (B, D) 的浮点数组，由测试传入，不要调用随机数。

输出

  • gaussian_log_prob 返回形状 (B,) 的浮点数组，每个样本一个标量。

② squashed_log_prob 返回形状 (B,)：把上式用在 u 上，再按式 (23.5) 加上 tanh 的雅可比修正，得到压缩后动作的 log π(a|s)：

log π(a|s) = log N(u; μ, σ²) + Σj log ( 1 − tanh²(uj) )

修正项本身已经带负号，方向就是式中的加号，写成相减会得到另一个值。

  • ③ sample_action 返回与 mu 同形状 (B, D) 的动作，按式 (23.4) 得到 tanh(μ + exp(log_std) ⊙ noise)。

会被检验测试用手算值核对两种对数概率（含 u = 0 处两者相等）， 并确认修正量正好是加上去的逐维和，写成减号会得到另一个值； 动作检查形状与 mu 一致、严格落在 (−1, 1)、逐个元素取 tanh，以及 mu 与噪声为 0 时动作也为 0。 噪声用传入的 noise，不要调用随机数；只用标准库和 numpy，不要改写入参。

卡住了？看提示
  • 先算 z = (x - mu) / np.exp(log_std)。np.exp 返回逐元素的 e 的幂， 这里把对数标准差还原成标准差。 再对最后一维求和：-0.5 * np.sum(z**2 + 2*log_std + np.log(2*np.pi), axis=-1)， axis=-1 表示"最后一维"，求和后这一维就没了，所以结果是 (B,)。
  • 雅可比项本身就是 log(1 - tanh(u)**2)，直接加在高斯对数概率上： corr = np.log(1 - np.tanh(u)**2)，再用 np.sum(corr, axis=-1) 加到 base 上。 np.tanh 返回逐元素的 tanh 值。
  • sample_action 里不要调用随机数，噪声由 tests 传进来，这样结果才可复现。
  • 形状对不上时先打印 np.asarray(x).shape 看一眼，别猜。

代码题 2 · 算软 Q 目标并验证温度退化为 0

背景这两个函数用在 SAC 的 critic 更新上。 目标网络给出下一状态两个 critic 的值和策略的对数概率，温度系数 alpha_ent 把对数概率折成熵奖励， 再按贝尔曼备份得到软 Q 目标；soft_value 单独算 q_min 减去 αent 乘 log π， actor 的损失里也用它来估 V。 输入是一个 batch（一批样本）的目标网络输出，输出是逐样本的目标值与软价值。

请实现 soft_q_target(rewards, dones, next_q1, next_q2, log_prob, alpha_ent, gamma) 与 soft_value(q_min, log_prob, alpha_ent)。① 软 Q 目标逐样本按式 (23.3) 计算，第一个 critic 的输出记为 Q1，第二个记为 Q2：

yi = ri + (1 − donei) γ ( min( Q1, Q2 )i − αent · log πi )

输入

  • rewards：长度 B 的浮点数组，即时奖励。
  • dones：长度 B 的布尔数组，表示这条样本是不是一局的最后一步。
  • next_q1、next_q2、log_prob：长度 B 的浮点数组，都在同一个 a′ ~ π(·|s′) 处取好。
  • alpha_ent：Python float，温度系数 αent；gamma 是折扣因子。两个函数共用 alpha_ent。
  • q_min（soft_value）：浮点数组，两个 critic 的逐元素较小值。

输出

  • soft_q_target 返回形状 (B,) 的浮点数组，第 i 项按上面的式子算： 终止样本只留 rewards，不带自举项；alpha_ent = 0 时熵项归零，退化成标准双 Q 目标。
  • soft_value 返回与 q_min 形状相同的浮点数组，元素为 q_min − alpha_ent * log_prob； alpha_ent = 0 时等于 q_min 本身。

会被检验测试检查终止项、alpha_ent = 0 时两个函数的退化结果， 以及 log 概率越低熵奖励越大、目标越高。只用标准库和 numpy，不要改写入参。

卡住了？看提示
  • 先算 q_min = np.minimum(next_q1, next_q2)，它返回逐元素较小值的新数组； 再算熵奖励 -alpha_ent * log_prob，两者相加，最后乘折扣。
  • 注意符号方向：目标是 q_min - alpha_ent * log_prob。 log 概率为负，减去一个负数等于加分，所以越冷门的动作目标越高。
  • (~dones) 是布尔数组，可以直接乘在自举项上，终止样本那一项就变成 0。
  • alpha_ent = 0 时整个熵项归零，目标退化成普通双 Q 目标，测试会专门检查这一点。
