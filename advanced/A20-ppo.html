进阶 · 第四部分 · 策略梯度与 Actor-Critic

PPO：裁剪目标与工程实践

这一课解决一件事：怎么让每次更新都只挪一小步。 学完你能手写 PPO 那个"限速"的目标函数，按固定顺序调参， 并在训练崩掉时从 KL（Kullback–Leibler divergence，KL 散度）与裁剪比例看出病根。

你会得到

  • 能写出并读懂 min(rt(θ)（策略参数）At, clip(·)At)，说清哪一侧梯度会被截断
  • 能列出 PPO 的完整损失与工程细节，并知道每一项漏掉会出什么症状
  • 能按"batch → 学习率 → ε（裁剪半径） → epoch → 系数"的顺序调参，并判断何时不该用 PPO

第一节：用限速代替硬约束

先认两个词。策略（一套"看到什么状态就选什么动作"的规则）就是那个决定动作的网络。 信赖域（规定这一步只允许在"离旧策略不太远"的范围内改，每次只许挪一小步） 是上一课给更新幅度加的那道限速。

0019 课的 TRPO（trust region policy optimization，信赖域策略优化） 靠一个 KL 约束把更新限制在信赖域里，效果可靠，但每步都要 Fisher 向量积与线搜索， 实现和调试都很贵。PPO（proximal policy optimization，近端策略优化） 换了个思路：不用显式约束，而把"更新太远就没有额外好处"直接写进目标函数。

铺垫两个概念。KL 散度（衡量两套概率分布差多远的指标）在这里用来量"策略的行为变了多少"。 另一个是剪裁（把过大的更新幅度砍掉，不让这一步改得太狠，相当于限速）， 它是 PPO 实现限速的手段。

再看它要用的概率比（新策略选中这个动作的概率，除以旧策略选中它的概率）：

rt(θ) = πθ(at|st) / πold(at|st) (20.1)

式中 θ 是策略参数，π 是策略分布，at 是第 t 步实际执行的动作。 比值为 1 表示新旧策略对这个动作的看法一样，大于 1 表示新策略更愿意选它。 φ 是价值网络（负责估计局面值多少分的那一方）的参数。

LCLIP(θ) = 𝔼t[ min( rt(θ)At,   clip( rt(θ), 1−ε, 1+ε ) At ) ] (20.2)

式中 ε 是裁剪半径（概率比允许偏离 1 的范围，和被限制的步长直接相关）， 上标 CLIP（clipped surrogate objective，裁剪代理目标）只是在给这个目标起名字。 注意 ε 在这里是裁剪半径，不是 探索率（每次决策时，有多大比例的概率去做"随便试一个"）， 跟"十次里有一次乱试"没有关系。

实践中常用 ε = 0.1 ~ 0.3。 符号含义见 符号表（那里也提醒了 ε 在 ε-greedy 里是另一个意思）。

第二节：这个 min 怎么读

式子里 At 是优势（在某个状态下，选这个动作比"平均水平"好多少，也就是你这一步比常规走法强多少）。 先看 At > 0 这一侧：这个动作比平均好，我们希望提高它的概率， 于是 L 随 rt 线性上升。但一旦 rt > 1+ε，clip 把它压成常数 (1+ε)At，min 选中这一项，梯度变成 0： 继续推高这个动作的概率不再获得任何奖励。

反过来 At < 0：我们要降低概率， L 随 rt 下降；当 rt < 1−ε 时 min 选中的是那个更悲观的常数项， 梯度同样为 0。所以裁剪只掐掉"已经走太远还在往同方向使劲"的那些样本， 另一侧不管。

注意这只是一个近似做法：它并不是精确的 KL 约束，min 让它偏向悲观，样本量小时约束也不严格。 它买到的是"几乎不用额外代码就能多跑几个 epoch（把同一批数据完整过一遍）"， 代价是对超参（需要你自己设定、而不是训练学出来的参数）更敏感。

第三节：完整损失与工程细节

Ltotal = LCLIP − cv( Vφ(s) − Vtarget )² + η H( πθ(·|s) ) (20.3)

式中 cv 是价值系数， H 就是熵（衡量"选择有多随机、多分散"；熵大代表还敢试）， η 是熵系数，控制熵那一项在目标里占的权重。 这一项的作用是强制留一点好奇心，别让策略过早锁死到一个动作上。

  • 优势归一化：每个 batch（一批样本）内把 At 减均值除标准差。 这一项最容易漏，漏了几乎必崩，优势的尺度直接决定 策略梯度（不绕道去估价值，直接算参数往哪调能让拿到的总分更高）的大小。
  • 多 epoch：同一批数据复用 3 到 10 轮。这是剪裁买来的好处， 但复用过头会跑出信赖域，所以必须配下一项。
  • KL 早停：每个 epoch 结束算一次近似 KL，超过阈值 （常见 0.01–0.02）就提前结束这一批，不等跑满 epoch。
  • 价值系数 cv ≈ 0.5；熵（衡量"选择有多随机、多分散"；熵大代表还敢试） 那一项的系数 η ≈ 0.0–0.01（连续控制常用 0，靠动作分布自身的随机性探索）。
  • 学习率（每次更新时往新信息的方向挪多远）线性衰减到 0； 梯度裁剪（如 0.5）；观测归一化、奖励缩放。
  • 采样规模：并行环境数乘以 rollout（让程序跑一遍，把一路上遇到的经历收集起来）长度，决定每个 batch 有多少样本 （例如 8 × 2048）。样本太少时，同一份代码跑两次结果能差出好几倍。

第四节：调参顺序与诊断

超参多，但有先后：先定每个 batch 的样本量（太小学不动）， 再调学习率，然后 ε，接着是 epoch 数与 KL 早停阈值， 最后才是 cv 与 η。顺序对了，每次只动一个量就看得清效果。

症状先查什么
KL 迅速上升、剪裁比例 > 0.3步子太大：降学习率，或把 epoch 数、早停阈值收紧
熵很快掉到接近 0提高 η，或降低学习率；也可能奖励尺度太大
价值损失不降、优势像噪声cv 太小、观测没归一化，或 batch 太小
回报（从现在起一直到结束，把每一步奖励加起来的总分）曲线整体不涨、剪裁比例接近 0步子太小：提高学习率或放宽 ε
策略迟迟不收敛（数值不再稳定）学习率太小，或 batch 里的样本太少

什么时候别用 PPO

基线（从回报里减掉的一个参照值，只降波动，不改平均方向）是衡量好坏的参照。 PPO 的定位是"通用首选"，不是"永远最好"。它仍然是 on-policy（边学的那套策略，就是正在用来产生数据的那套）：每批数据用完就丢， 样本效率（拿到同样多的经验能学多好；效率高就是"更省数据"）不高。 所以交互很贵时（真实业务、硬件在环）， 0021 课之后的 off-policy（边学的那套策略，不是产生数据的那套）方法更合适； 只需要模仿已有日志时，行为克隆又快又稳；奖励极稀疏时优势几乎全为 0， 应先改奖励而不是换算法。反过来说，动作空间（所有能选的动作组成的集合）大、 连续、需要策略直接输出动作时，PPO 是默认答案。大模型的 RLHF（reinforcement learning from human feedback，基于人类反馈的强化学习）微调就属于这一类。

课后练习

1. 式 (20.2) 里 min 的两个参数分别是什么？

  1. 裁剪后的概率比，以及裁剪前概率比与优势的乘积两项
  2. 新旧两套策略对同一个动作各自输出的对数概率（把概率取对数后的值）的差值
  3. 未裁剪的概率比乘优势，以及裁剪后概率比乘同一个优势
  4. 优势的归一化值与未归一化值，取二者中较小的那一个

为什么：min 比较的是 rt(θ)At 与 clip(rt(θ),1−ε,1+ε)At： 同一个优势 At，区别只在概率比是否被裁剪， 取较悲观者。

A 把两项说混了，两项都乘了优势；B 描述的是计算概率比需要的量，不是 min 的参数； D 与归一化无关，优势归一化是数据预处理，不进目标函数。

2. 当 At > 0 且 rt > 1+ε 时，这个样本对参数的梯度会怎样？

  1. 被截断为 0，因为 min 选中了压成常数的裁剪项
  2. 等于优势本身，因为概率比已被裁剪成常数 1+ε
  3. 被放大到 1+ε 倍，等于奖励超范围的好动作
  4. 符号反转，把该动作的概率往相反方向压下去

为什么：clip 之后那一项与 rt 无关， 是常数 (1+ε)At；它比 rtAt 小，min 选中它， 于是对 θ 的梯度为 0，裁剪这个名字就是这么来的。

B 错在把目标值与梯度混为一谈：目标确实被固定住，梯度才是 0； C 与裁剪的目的相反；D 不成立，PPO 不会把好动作的概率反向压低。

3. 经验回放（把走过的每一步都存进一个池子，训练时从池子里随机抽一批出来用）在 PPO 里怎么用？

  1. 它是 off-policy，能把旧数据存进回放缓冲区反复采样
  2. 它是 on-policy，同一批数据更新一次就必须丢弃
  3. 它靠剪裁稳定自举（用自己当前的估计去更新自己当前的估计）目标，因此不需要再固定目标参数
  4. 它是 on-policy，但同一批数据可以安全地复用几轮

为什么：PPO 的数据仍来自当前策略，所以是 on-policy； 裁剪让代理目标在旧策略附近保持可信，因此同一批数据能跑多个 epoch。 它相对 REINFORCE 的样本效率提升就落在这里。

A 与事实相反，PPO 不用回放缓冲区；B 过于保守，忽略了裁剪带来的复用能力； C 说的是目标网络（另存一份"稍旧"的网络专门用来算目标，隔一阵才同步一次）， PPO 与目标网络是两件独立的事。

4. 训练时观察到 KL 迅速上升且裁剪比例超过 0.3，最该先动什么？

  1. 提高学习率让策略更快收敛到最优解，并放宽裁剪半径
  2. 降低学习率，并收紧 epoch 数或 KL 早停阈值
  3. 把优势归一化关掉，让不同样本的梯度尺度更接近
  4. 增大熵系数，用更多随机性抵消策略分布的快速移动

为什么：KL 大、裁剪比例高说明这一批数据被推得太远， 已经跑出代理目标可信的范围。直接手段是减小每步位移：降学习率、 少跑几个 epoch、把早停阈值收紧。

A 会火上浇油；C 与病因无关，关掉归一化通常让训练更不稳； D 治的是"过早变确定"，不是"步子太大"，而且提高 η 也压不住 KL。

5. 下列哪种情形最不适合选 PPO？

  1. 动作连续、状态维度很高，需要策略直接输出动作向量
  2. 要在一个大语言模型上做奖励驱动的微调与对齐
  3. 每次与环境交互都极其昂贵，样本量被严格限制
  4. 需要一套公开实现多、容易对照复现的通用基线

为什么：PPO 是 on-policy，每批数据用完就丢， 样本效率天然吃亏。交互昂贵时应该优先 off-policy 方法（TD3） 或先用行为克隆拿到基线。

A、B、D 都是 PPO 的主场：连续高维动作、大模型 RLHF 微调、 需要通用可复现基线，公开实现最多。

代码题 1 · 算 PPO 的裁剪目标与梯度

背景这个函数是 PPO 的核心一步：把这一步的更新幅度限制在一个范围内，不让策略被推得太远。训练循环在同一批数据上跑几个 epoch（把同一批数据完整过一遍），每个 minibatch 都调用它一次。返回的 objective 用来记录本轮的代理目标，返回的 grad 直接更新策略输出层的参数。两个对数概率（把概率取对数后的值）来自同一批样本上新旧两个策略，clip_eps 是裁剪半径 ε，限定概率比允许偏离 1 的范围，与探索率无关。

请实现 ppo_clip_objective(new_log_probs, old_log_probs, advantages, clip_eps)，只用标准库加 numpy。

输入

  • new_log_probs：形状 (B,) 的 float 数组（(B,) 表示 B 个数的一维数组，下标从 0 开始），当前策略对这批所选动作的对数概率。
  • old_log_probs：形状 (B,) 的 float 数组，采集这批数据时那个策略对同一批动作的对数概率。
  • advantages：形状 (B,) 的 float 数组，第 i 项是 Ai，也就是"这个动作比平均水平好多少"。
  • clip_eps：Python float 标量 ε，裁剪半径，概率比被限制在 [1−ε, 1+ε] 内，工程上常用 0.1 到 0.3。

输出

  • 返回二元组 (objective, grad)。objective 是 Python float，等于 mean( min( r·A, clip(r, 1−ε, 1+ε)·A ) )，其中 r = exp(new_log_probs − old_log_probs)。
  • grad 是形状 (B,) 的 np.ndarray，逐分量给出 objective 对 new_log_probs 的偏导数。

会被检验测试会检查 r 落在裁剪区间内时梯度等于 A·r 再除以 B；A 为正、r 超过 1+ε 时梯度被截断为 0，同样位置 A 为负时梯度保持 A·r；A 为正、r 低于下界时目标取未裁剪项。还会用数值微分核对每个分量。

卡住了？看提示
  • 先算概率比 r = np.exp(new_log_probs - old_log_probs) （np.exp 返回 e 的那么多次方，用来把对数概率的差还原成比值）。
  • 再算 unclipped = r * adv 与 clipped = np.clip(r, 1-eps, 1+eps) * adv （np.clip 把每个数夹在两个边界之间，超出的直接压到边界上）。 目标就是 np.minimum(unclipped, clipped) 的均值 （np.minimum 逐项取两个数组里较小的那个）。
  • 哪一项被 min 选中，梯度就用哪一项的：未裁剪项对 new_log_probs 的导数是 adv * r，裁剪项是 0。
  • 别忘了最后除以 B，因为目标用的是 mean。

代码题 2 · 用数值轨迹验证梯度被截断

背景这是一个诊断用的小实验，训练循环不会调用它。它把上一题的裁剪目标看成概率比 r 的一元函数，沿梯度上升一步步推 r 并记下轨迹，用来观察 r 走到哪里梯度会变成 0。写实验脚本或核对测试时可以用它验证裁剪的边界行为，ratio0 是初始概率比，advantage 是这批数据上的优势。

请实现 clipped_ascent_trace(ratio0, advantage, clip_eps, lr, steps)，只用标准库加 numpy。

输入

  • ratio0：Python float，初始概率比，通常从 1.0 或某个已经偏离的值开始。
  • advantage：Python float 标量 A，这份数据上的优势。
  • clip_eps：Python float 标量 ε，裁剪半径，有效区间是 [1−ε, 1+ε]。
  • lr：Python float 标量，每步的步长。
  • steps：Python int，更新次数。

输出

  • 返回长度 steps+1 的 Python list，元素都是 Python float：下标 0 是 ratio0，下标 k 是第 k 步更新后的 r。这里没有 batch 平均，不必除以任何数。

会被检验测试会检查返回长度等于 steps+1、首元素等于 ratio0；A 为正时轨迹单调不减，且不会越过 1+ε 一个步长以上；A 为负时单调不增。起点已越出上界且 A 为正、或已越出下界且 A 为负时，梯度为 0，轨迹原地不动。

卡住了？看提示
  • 和上一题一样：先算 unclipped = r*advantage 与 clipped = clip(r)*advantage，比较两者决定梯度。
  • unclipped <= clipped 时用 advantage， 否则用 0。注意这里没有 batch 平均，不用除以任何数。
  • 循环里每步结束后把新的 r 追加进列表。
