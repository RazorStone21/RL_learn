策略梯度与 REINFORCE

读完这一节，你应该能写出策略梯度（不绕道估价值， 直接算参数往哪调能让总分更高）的目标与 REINFORCE 更新式， 说清它凭什么只靠采样就能求梯度，以及从总分里减掉一个参照值 为什么不引入偏差，却能把波动压下来。

你会得到

  • 能写出 ∇J = 𝔼[∇log π(a|s)·G] 并解释它相对 Q-learning 的优势与代价
  • 能说清"减基线不改变期望"的那一步推导依据
  • 能指出 REINFORCE 方差大在哪，并知道下一步该用 actor-critic 修什么

为什么不继续走价值路线

前面十六课都在学价值，再用 arg maxa Q(s,a) 提取动作。 这里的价值指的是"某个局面或某个动作估计能拿多少总分"，也就是回报 （从此刻起一直走到结束，把每一步奖励加起来的总分）； arg max 是挑出让后面那个式子最大的选择。这条路有两处会卡住。

  • 连续动作没法求 max。机械臂的关节力矩是实数、广告出价是连续金额， 要对 a 求最大值，就得每一步都解一个优化问题。
  • 最优做法本身可能是随机的。在信息不完整或对手会观察你的场景里， 最优做法是按概率出招（石头剪刀布就是最直白的例子），这套规则叫随机策略 （同样的局面不固定给同一个动作，而是按概率挑一个）。 而贪心（在当前估计里挑看起来最好的那个）的做法永远是确定性的。

策略梯度（policy gradient）换一条路： 把策略（一套"看到什么状态就选什么动作"的规则，就是出招习惯）直接参数化成 πθ(a|s)，其中 θ（策略参数，决定这套出招习惯的那组数字）决定它， π（策略分布，从它采样动作的那个概率分布）是从它采样动作的分布。 然后对"期望回报"这个目标做梯度上升。探索被写进了策略本身， 推理时也只需要一次前向计算。

目标与似然比技巧

目标是策略的期望回报：

J(θ) = 𝔼τ ∼ πθ[ Σt γt rt+1 ] (17.1)

式中 γ 是折扣因子（越往后的奖励，算进总分时权重越小，等于给它打了个折）， τ 是一条采样轨迹（从开始到结束，把状态、动作、奖励都记下来的那一串，也就是一整局的棋谱）， 𝔼 是期望（同一件事重复很多次之后的平均结果），Σ 是求和号（把后面那串东西全加起来）。 下标 τ ∼ π_θ 表示这些轨迹是按当前策略跑出来的。

先认一个词。似然（当前这套参数，产生出我们观测到的这些数据的可能性有多大）： 放在这里，它问的是"这套出招习惯做出刚才那串动作的可能性有多大"。

难处在于期望所用的分布本身依赖 θ，直接求导要面对状态分布对 θ 的导数。 这时用一个小恒等式： ∇θπθ(a|s) = πθ(a|s) ∇θ log πθ(a|s)。 式子里 ∇ 读作梯度（往哪个方向调参数能让结果降得最快，这里反过来用，让它涨得最快）， log 是对数，可以理解成把很小的数压得不那么小的换算。 这个恒等式就是似然比技巧（likelihood ratio trick）：把"对概率求导"改成 "先取对数概率（把概率取对数，概率很小的时候也不会变成 0，方便计算）， 再对它求导，然后乘回概率"。

这样一来，期望的写法不需要变，状态分布那部分的求导正好绕开了。结果是 策略梯度定理（policy gradient theorem）：

∇θJ(θ) = 𝔼πθ[ Σt ∇θ log πθ(At|St) · Gt ] (17.2)

怎么读它：Gt 是从这一步起真实的折扣回报 （把未来的奖励一步步打折再加起来的总分），它当权重； ∇log π 是方向，指向"让这个动作更可能发生"。 回报高就是正权重，把动作概率往上推；回报低就是负权重，压下去。 整个式子只需要采样出来的 (s, a, G)，不需要环境模型。 推导见 Sutton & Barto 第 13.2 节 [免费 PDF] 与 Stanford CS234 的讲义。

对一个 softmax（把原始分数变成一组加起来等于 1 的概率，分数高的概率大）策略， 这个方向有很干净的形式： ∇z log π(a|s) = ea − π(·|s)， 其中 ea 是动作 a 的 one-hot 向量 （只有对应的那一格是 1，其余全是 0）， 也就是"把被选动作的 logit（还没变成概率的原始分数）抬 1，其余按概率往下压"。

REINFORCE：最朴素的实现

把式 (17.2) 直接变成算法，就是 REINFORCE： 用当前策略跑完一整个回合（从开始到结束的一整局），记下每步的 (st, at) 与折扣回报 Gt，然后按下面的方向更新：

更新规则里的 ← 读作"更新为"，意思是把右边算出来的新值赋给 θ； α 是学习率（每次更新往新信息的方向挪多远，太大会来回震荡、太小就学得慢），也就是步长。 它叫超参，就是需要你自己设定、而不是训练学出来的参数。写成一行就是

θ ← θ + α Σt Gt ∇log πθ(at|st)。

Gt 是从这一步起的折扣回报。数据用一次就丢， 因为式 (17.2) 的期望是在当前策略的分布下求的。这就是它必须 on-policy （边学的那套策略，就是正在用来产生数据的那套）的根本原因， 也是它样本效率（拿到同样多的经验能学多好，效率高就是更省数据）低的根源。

另一个细节是因果性：第 t 步的动作不可能影响它之前就已经发生的奖励， 所以权重只用 Gt（从 t 往后的折扣回报）， 不用整条回合的总回报。数学上两者的期望相同，但前者的波动更小。

基线：减掉一个与动作无关的量

回报 Gt 的绝对大小常常是几百上千， 而"这个动作比平均好多少"可能只有几。用绝对值当权重， 梯度几乎全被这个公共的常数淹没，每次更新的方向就抖得厉害。 办法是减掉一个只依赖状态的基线（从回报里减掉的一个参照值， 只用来降波动，不改变平均方向），像打分时先减去一条及格线：

∇θJ(θ) ≈ Σt ( Gt − b(St) ) ∇θ log πθ(At|St) (17.3)

减去它不会引入偏差。因为对任意 b(s)， 𝔼a∼π[ b(s) ∇log π(a|s) ] = b(s) Σa ∇π(a|s) = b(s) ∇(1) = 0。 意思是：所有动作的概率加起来永远等于 1，1 是常数，对常数求导就是 0， 这一项在长期平均里正好抵消。 注意这个证明要求 b 不能依赖动作：一旦改用 Q(s,a) 当基线，期望不再为零，偏差就进来了。

常用基线就是状态价值（只看状态、不管具体选哪个动作的那个价值， 回答"现在这个局面好不好"），写成 V(s)。 此时权重变成 Gt − V(St)， 也就是优势（在某个状态下，选这个动作比"平均水平"好多少）的一个估计。 估它的办法是蒙特卡洛（把一整局走完，用真实拿到的总分来估计价值）， 所以这个量也叫优势函数（advantage function）。相关定义见 术语表。 "把绝对收益换成相对好坏"是最有效的一次波动削减。

它的问题与下一步

即便加了基线，REINFORCE 仍然要用整条回合的实际回报当权重，随机性直接进了梯度， 波动还是大：同一个任务跑两次，更新方向可能差很远。学得慢、对学习率敏感， 一次坏更新就能把策略推到几乎固定的坏动作上，而且无法回滚。

它保证的是收敛（一轮轮算下去，数值不再明显变化，稳定下来了）到局部最优， 不是全局最优。修法与 0011 课的 TD（temporal difference）思路一致，也就是时序差分 （不用等到一局结束，用"走一步之后的新估计"来更新"走这一步之前的估计"）： 用自举（用自己当前的估计去更新自己当前的估计，等于自己拽自己的鞋带往上提） 算出来的、波动更小的估计，去替代整条回报。

这就是 0018 课的 actor-critic （一边出招、一边打分，用打出来的分去改出招习惯）。那里 actor（出招的那一方，负责决定这一步做什么动作，也叫策略网络）每步都能更新， critic（打分的那一方，负责估计现在这个局面值多少分，也叫价值网络）学 V(s)，用 TD 误差当优势。

策略梯度不需要目标网络（另存一份"稍旧"的网络专门用来算目标，隔一阵才同步一次）。 如果手上只有一份离线（不能与真实环境交互，只能用已经攒下来的历史数据学）日志， 想复用旧数据就得做重要性采样（用另一套策略产生的数据来估计当前策略， 要按概率比例做修正）。REINFORCE 的价值在于它是这套东西最干净的原型： 看懂式 (17.2) 与式 (17.3)，后面所有策略梯度算法都是在这两项上做文章。 它们的名字分别是 A2C（advantage actor-critic，优势演员-评论家）、 TRPO（trust region policy optimization）、PPO（proximal policy optimization，近端策略优化）、 SAC（soft actor-critic，软演员-评论家）。其中 TRPO 给每步改动加了上限， 那叫信赖域（规定这一步只允许在"离旧策略不太远"的范围内改）。

课后练习

1. 相比 DQN（deep Q-network，深度 Q 网络）一族，策略梯度最直接的优势是什么？

  1. 它能反复复用历史数据，样本效率因此比 DQN 高得多
  2. 它能直接处理连续动作，也能学出最优的随机策略
  3. 它不需要与环境交互，只用一份离线日志就能完成训练
  4. 它的梯度估计是无偏的，所以几乎不需要再调学习率

为什么：策略输出的是动作分布，连续动作直接采样即可，不需要 arg max；随机性又是策略本身的一部分， 所以在"最优策略必须随机"的场景里它天然合适。

A 恰好说反了：REINFORCE 是 on-policy（边学的那套策略就是正在产生数据的那套）， 数据用一次就丢，样本效率通常低于 DQN。 C 不对，式 (17.2) 的期望仍然要在策略诱导的分布下采样。 D 混淆了无偏与稳定：梯度无偏不等于方差小，学习率依然是它最敏感的超参。

2. 引入似然比技巧 ∇π = π∇log π 之后，我们得到了什么？

  1. 它把期望回报的梯度化成了对环境模型的求导运算
  2. 它证明了策略梯度一定能收敛到全局最优的那个策略
  3. 它让策略梯度可以像 DQN 那样对动作集合取最大值
  4. 它只用采样就能估计梯度，不必知道状态分布

为什么：技巧的作用是把"对含 θ 的分布求导"改写成 "对 log π 求导、再乘回概率"，于是期望可以直接用采样平均来估， 状态分布对 θ 的依赖不再需要显式计算。

A 与事实相反：它最大的价值就是不需要模型。 B 是过度承诺，策略梯度只保证收敛到局部最优（或稳定点）。 C 说反了：策略梯度面向的，恰好是没法对动作取 max 的场合。

3. 减去基线 b(s) 为什么不会引入偏差？

  1. 因为 Σa ∇π(a|s) = 0，这一项在期望上就等于零
  2. 因为基线只依赖状态，所以它必然等于真实的状态价值 V(s)
  3. 因为回报 G 的期望本来就是零，减去任何量都不改变期望
  4. 因为重要性采样权重会把基线带来的偏差重新修正回来

为什么：基线项在期望里是 b(s) Σa ∇π(a|s)，而概率之和恒为 1， 它的梯度恒为 0。这也解释了基线为什么不能依赖动作：只要 b 与 a 无关， 就能提到求和号外，逐项抵消。

B 不对：基线可以是任何与动作无关的函数，不需要等于 V(s)， 估计得差只会影响方差，不会影响期望。C 与事实不符，回报的期望一般不为零。 D 里没有重要性采样，这与 off-policy 修正无关。

4. REINFORCE 为什么必须是 on-policy 的？

  1. 因为它必须每个时间步都更新，不能等到回合结束再更新
  2. 因为它的损失函数里包含了一份目标网络的参数副本
  3. 因为梯度权重 G 是在当前策略的分布下采样得到的量
  4. 因为它必须用 ε-greedy（ε 是探索率）才能保证所有动作都被访问到

为什么：式 (17.2) 的期望写的是 𝔼πθ：梯度里的 Gt 是当前策略跑出来的回报。 策略一更新，旧数据的分布就对不上，只能丢掉重新采样。

A 说反了：REINFORCE 是必须等回合结束才能算 Gt。B 是 DQN 的装备，策略梯度不需要目标网络。 D 不对：探索由随机策略本身提供，不需要 ε-greedy 机制。

5. 策略梯度方差大的主要来源是什么？

  1. 策略网络的参数太多，导致梯度里混进了大量噪声
  2. 权重用的是整条回合的实际回报 G，随机性直接进了更新
  3. log π 的取值没有上界，很容易造成数值上的溢出
  4. 基线 b(s) 的估计误差会把方差进一步放大

为什么：Gt 是一条采样轨迹的 实际回报，包含后续所有随机性。同一个动作在不同回合里可能拿到差别很大的 Gt，梯度方向因此抖动。 减基线、用因果性权重、乃至换成自举的 critic，都是在压这个抖动。

A 把参数量与梯度方差混为一谈。C 是数值问题，可以用 log-softmax 稳定住， 与统计方差无关。D 说反了：基线的作用是降低方差，估计不准只是让它降得少一点。

代码题 1 · 用 softmax 算对数概率与 ∇log π

背景策略梯度把策略写成 softmax 分布之后， 每一步更新都要用到两个量：所选动作的对数概率 log π(a|s)，以及它对 logits 的梯度。 前者是式 (17.2) 里的权重因子，后者决定参数往哪个方向走。训练循环采集完一个 batch（一批样本）的状态与动作后调用这两个函数，把返回值直接乘进 REINFORCE 的梯度估计。只许用标准库与 numpy，按惯例写 import numpy as np。

请实现 log_softmax(logits) 与 log_prob_grad(logits, actions)。 签名与 starter 保持一致。

补一句 numpy。数组就是一排数字的容器，形状 (B, A) 表示 B 行、每行 A 个数；logits.max(axis=1, keepdims=True) 表示沿每一行取最大值，并且保留成 (B, 1) 的形状， 这样它和 (B, A) 相减时能自动铺开对齐，这个规则叫广播。 下标都从 0 开始。

输入

  • logits（两个函数共有）：形状 (B, A) 的 float 数组，B 是 batch 里的状态数，A 是动作数。每行是策略网络对一个状态输出的原始分数，还没变成概率。
  • actions（log_prob_grad）：形状 (B,) 的整数数组，取值 0 ~ A−1，第 i 个元素是该状态上实际执行的动作。

输出

  • log_softmax 返回形状 (B, A) 的 np.ndarray：第 (i, a) 个元素是 log π(a|si)，每行取 exp 之后沿 a 求和为 1。
  • log_prob_grad 返回形状 (B, A) 的 np.ndarray：第 i 行是 ∇z log π(ai|si)，数值上等于 one-hot(a_i) 减 softmax 概率，整行之和为 0。

会被检验测试会检查 exp(返回值) 每行之和为 1，小 logits 下与朴素写法一致；把 logits 取到 ±1000 时结果仍然有限、最大那一项接近 0；梯度每行之和为 0，并与数值微分逐项一致，数值微分就是给某个输入加一点再减一点、用两次结果之差近似导数；两个动作等概率时被选中的那一项是 +0.5、另一个是 −0.5。

卡住了？看提示
  • 稳定性靠减去每行最大值：先 m = logits.max(axis=1, keepdims=True)， 再算 shifted = logits - m，最后 shifted - np.log(np.sum(np.exp(shifted), axis=1, keepdims=True))。 axis=1 表示沿每一行算，keepdims=True 让结果保持 (B, 1) 的形状，方便广播相减。
  • π 就是 np.exp(log_softmax(logits))，不用另写一遍归一化。
  • 构造 one-hot 可以先用 np.zeros_like(logits) 造一张同形状的 0 表， 再写 g[np.arange(B), actions] = 1.0，其中 B = logits.shape[0]。 最后返回 g - probs。

代码题 2 · 用基线算 REINFORCE 梯度

背景REINFORCE 跑完一整条回合才更新一次。 训练循环拿到奖励序列后，先用 returns_to_go 把奖励折成每一步的折扣回报 Gt 当权重，再用 reinforce_gradient 把权重乘上每步的 ∇log π 并在时间轴上取平均， 得到可以直接交给优化器的梯度估计。奖励来自环境，基线是那个与动作无关、 只用来压波动的参照值。只许用标准库与 numpy，两个函数都不修改输入。

请实现 returns_to_go(rewards, gamma) 与 reinforce_gradient(grad_log_probs, returns, baselines)。 签名与 starter 保持一致。

输入

  • rewards（returns_to_go）：形状 (T,) 的 float 数组，T 是回合长度，第 t 项是 rt。
  • gamma（returns_to_go）：Python float 标量，折扣因子 γ，给未来的奖励打折。
  • grad_log_probs（reinforce_gradient）：形状 (T, A) 的 float 数组，第 t 行是 ∇θ log πθ(at|st)。
  • returns（reinforce_gradient）：形状 (T,) 的 float 数组，第 t 项是 Gt。
  • baselines（reinforce_gradient）：形状 (T,) 的 float 数组或 Python 标量，两种都要支持，第 t 项是 bt。

输出

  • returns_to_go 返回形状 (T,) 的 np.ndarray：第 t 项是从第 t 步起的折扣回报 Gt = Σk≥t γk−t rk。
  • reinforce_gradient 返回形状 (A,) 的 np.ndarray：式 (17.4) 在 T 步上取平均的梯度估计，第 a 个元素对应第 a 个动作。
ĝ = (1 / T) Σt ( Gt − bt ) ∇θ log πθ(at|st) (17.4)

式子里 ĝ 是这一步算出来的梯度估计，Σ 是求和号（把后面那串东西全加起来）， T 是回合长度。

会被检验测试会核对 gamma=0.5 与 gamma=1 两种折扣下的回报值，以及长度为 1 的序列返回奖励本身；基线恰好等于回报时梯度全为 0，基线整体平移一个常数后结果不变，并按动作概率加权核对期望梯度。

  • returns_to_go 从后往前累加最省事：先设 running = 0.0， 再让 t 从 T-1 数到 0，每次做 running = rewards[t] + gamma * running，并把 running 写进 out[t]。
  • 式 (17.4) 里的权重是 weights = returns - baselines，形状 (T,)。 要乘到形状 (T, A) 的 grad_log_probs 上，先把它变成一列： weights[:, None] 得到 (T, 1)，广播之后每一步的每个动作 都用同一个权重。
  • 最后沿时间轴取平均： np.mean(weights[:, None] * grad_log_probs, axis=0)， axis=0 表示沿着第 0 维也就是时间那一维算平均，得到长度为 A 的向量。
