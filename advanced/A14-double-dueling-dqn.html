Double DQN 与 Dueling DQN

0013 课的 DQN 留下两个毛病：估出来的分数总是偏高， 动作差别不大时又在白白浪费样本。这一节给出对应的两个改动。读完你能说清哪个改动修哪个毛病， 在自己的训练里也知道先开哪一个。

你会得到

  • 能写出 Double DQN 的目标，并解释"用 A 选动作、用 B 评估"为什么能缓解过估计
  • 能写出 Dueling 的聚合公式，并说清"减优势均值"那一步在解决什么
  • 能按症状判断该加 Double 还是换 Dueling，并知道它们为什么可以叠加

先看 DQN 留下的两个毛病

上一课学的 DQN（deep Q-network，深度 Q 网络：拿一个神经网络当记忆， 输入当前状态，输出每个动作估计值多少分）能训起来，但它留下两个毛病。

第一个毛病是 Q 值（在这个状态下做这个动作，估计以后能拿多少总分）总是偏高。 这里说的回报，就是从此刻起一直走到结束，把每一步奖励加起来的总分。 随机性强的环境里，学到的 Q 能比真实回报高出好几倍。

这种偏高每次朝同一个方向，属于稳定的错误，而不是偶发的噪声。它叫偏差 （估计值长期朝一个方向偏离真值，像一杆秤一直偏重两斤）。偏高的根源在取最大值那一步，下一节说。 先记住后果：挑动作时只看谁大谁小，这个操作写作 arg max（挑出让后面那个式子最大的选择）。 偏差一旦集中在某几个动作上，照它挑出来的动作就会变差。 这套"看到什么状态就选什么动作"的规则叫策略，换个说法就是你写进程序里的出招习惯。

如果每次都按同一套规则固定挑同一个动作，这叫确定性策略（不掷骰子， 同样的局面永远给出同一个动作）。0017 课会从另一个方向处理这件事。

第二个毛病更隐蔽。网络对每个动作各输出一个 Q，参数全用在"比较动作"上， 没有一条通路回答"这个状态本身值多少分"。可很多状态里动作差别很小， 比如路上没车时往左往右都行。让每个动作的 Q 各自学一遍"这个状态还行"， 是纯粹的样本浪费。同样多的经验能学多好，这件事叫样本效率（拿到同样多的经验能学多好， 效率高就是更省数据），Dueling 修的就是它。

Double DQN：把"选动作"和"评动作"分开

先说这套系统里的两个零件，后面的改动都要和它们配合。一个叫经验回放 （把走过的每一步都存进一个池子，训练时从池子里随机抽一批出来用，相当于错题本反复抽着复习）； 一个叫目标网络（另存一份"稍旧"的网络专门用来算目标，隔一阵才同步一次， 避免追着自己跑）。

过估计（因为总是取最大值，估出来的分数总是偏高）的根源就是 max。 设想所有动作的真实价值都是 0，可我们的估计带着噪声（估计里那部分随机的误差）。 对每个动作取 max 时，被选中的往往是噪声恰好偏正的那一个，未必是最好的那个。 写成数学是 𝔼[ maxa Q(s,a) ] ≥ maxa 𝔼[ Q(s,a) ]。 这里的 𝔼 读作期望（同一件事重复很多次之后的平均结果）。 左边是先对每个动作取最大再求平均，右边是先求平均再取最大，左边总是不小于右边， 多出来的那一截就是过估计。而且这个偏差会被自举（用自己当前的估计去更新自己当前的估计， 等于自己拽自己的鞋带往上提）一次次放大。

标准 DQN 的目标里，挑动作和给价值用的是同一组参数 φ（φ 是网络参数， 也就是网络里那堆要训练的数字）。这份参数在公式里写成 φ−，表示它是那份"稍旧"的副本：

y = r + γ maxa′ Q(s′, a′; φ−) (14.1)

式中 γ 是折扣因子（越往后的奖励，算进总分时权重越小，等于给它打了个折）， r 是即时奖励（刚做完这一步马上拿到的分数），y 是希望网络去逼近的目标值。

Double DQN（double deep Q-network，双深度 Q 网络） 把这两件事拆给两个网络：用在线网络 φ 挑动作（在线网络就是正在训练、 每一步都在更新的那一份），用目标网络 φ− 给这个动作打分。

a* = arg maxa′ Q(s′, a′; φ)，   y = r + γ Q(s′, a*; φ−) (14.2)

直觉是：噪声要同时骗过两个互相独立的估计，难得多。这个方法来自 van Hasselt 等人的 Double Q-learning 论文（arXiv 1509.06461）， 在 DQN 上只改了目标公式，多算一次 arg max，几乎零成本。

别夸大它：Double DQN 只是缓解，不是消除。在线网络自己还没学好时， 挑出的动作本来就不靠谱，收益有限；两个网络都低估时，它也无能为力。 "便宜、通常不亏"这两点加起来，足够让它成为默认配置。

Dueling：把 Q 拆成"状态值多少"加"这一步好多少"

先补一个量。在某个状态下，选这个动作比"平均水平"好多少，这个差值叫优势 （advantage，你这一步比常规走法强多少），记作 A(s,a) = Q(s,a) − V(s)，它也叫优势函数 （advantage function，在某个状态下选这个动作比按策略平均好多少）。

式子里 V(s) 是状态价值（只看状态、不管具体选哪个动作的那个价值， 回答"现在这个局面好不好"）；Q(s,a) 是动作价值 （先选这个具体动作、之后继续好好走，一共能拿多少总分）。 把上式反过来写就是 Q(s,a) = V(s) + A(s,a)。细节见 符号表与 术语表。

Dueling DQN 把这个分解搬进网络结构：共享的特征层之后分出两条支路， 一条输出一个数 V(s)，一条输出一组数 A(s,·) （每个动作一个），再合并成 Q。直接相加有个问题：把 V 和 A 同时加一个常数、 再减同一个常数，Q 完全不变，损失函数分不出这份价值该记在谁头上，这叫不可辨识。 解决办法是强制优势均值为 0：

Q(s, a) = V(s) + A(s, a) − (1 / |A|) Σa′ A(s, a′) (14.3)

式子里 Σ 是求和号（把后面那串东西全加起来），|A| 是动作个数， 所以 (1 / |A|) Σ 就是对所有动作取平均。减掉的是这一行优势的均值， 也就是对每个动作减同一个数。对整行减同一个数，各动作 Q 的大小顺序不变， arg max 自然也不变。从此 V 专门承担状态的基准价值， A 只描述相对好坏。在动作效果差不多的状态里， V 支路一次就能把"这状态不错"学到位，不必等每个动作的 Q 分别收敛 （一轮轮算下去，数值不再明显变化，稳定下来了）。

这个结构出自 Wang 等人的 Dueling Network Architectures（arXiv 1511.06581）。 原文还给了把均值换成最大值的变体，性质类似，实践中用均值更常见。

两者各修什么，怎么组合

改进改的地方解决的问题代价
Double DQN目标 y 的算法 max 带来的过估计每次多一次 arg max，几乎为零
Dueling DQN网络结构与聚合公式 动作差别不大时的样本浪费多一条 V 支路，必须做中心化

两者互不干扰：一个改损失里的目标 y，一个改网络输出的形状， 可以同时打开，也能和经验回放、目标网络任意搭配。 再往上叠优先回放（0015 课）与分布式价值 （0016 课），就是 Rainbow。

动作是连续值的场合（机械臂的关节力矩、广告出价这类）这一族都用不上， 那要走策略梯度（不绕道去估价值，直接算参数往哪个方向调能让拿到的总分更高）， 见 0017 课。

组合时一次只加一个，并且每加一个都单独做一次消融（把改动一个个加上去或者拿掉， 看各自贡献了多少）。同时改三处，出了问题无法归因，也不知道该回退哪一个。

Lilian Weng 的 DQN 变体综述 把这一族改进按"改目标 / 改结构 / 改采样"分了类，可以在决定加哪个组件前先扫一遍。

诊断：该先开哪一个

  • Q 值随训练持续膨胀，或者在奖励带噪声、环境随机的任务里策略越训越差： 先开 Double DQN，这是最便宜的一次尝试。
  • 动作数多（十个以上）、学得慢，很多状态下不同动作效果接近： 试 Dueling。它和探索无关，不会让策略更愿意去尝试新动作。
  • 关键转移很少、奖励极稀疏（绝大多数步骤都拿不到分，只有极少数关键时刻才有奖励）： 这两个改动都帮不上忙。问题在"该学哪些样本"， 去 0015 课的优先经验回放。

课后练习

1. Double DQN 的目标 (14.2) 与 DQN 的目标 (14.1) 差别在哪里？

  1. 用在线网络挑出动作，再用目标网络评估这个动作的价值
  2. 用目标网络挑出动作，再用在线网络评估这个动作的价值
  3. 同时训练两个 Q 网络，最后取两者输出中较小的那个值
  4. 对同一个动作的 Q 值采样两次，最后取两次采样的平均值

为什么：选动作与评估动作必须来自不同的估计，噪声才不容易同时骗过两边。 式 (14.2) 里 arg max 用在线参数 φ， 取值用目标参数 φ−，"Double"的含义就在这里。

B 把两个网络对调了：用目标网络选动作时，在线网络还没学好， 被选中的动作往往是错的，反而更不稳。C 描述的是 TD3（twin delayed deep deterministic policy gradient，双延迟深度确定性策略梯度）那类双评论家取最小值， 目的是保守，不是去掉选择噪声。D 与任何算法都不对应，重复采样不会降低偏差。

2. DQN 里 Q 值系统性偏大的根本原因是什么？

  1. 回放缓冲区里的样本高度相关，让随机梯度的噪声不再独立
  2. max 作用在带噪声的估计上，会系统性地挑到偏高的那个
  3. 目标网络的参数同步得太频繁，导致自举目标来回跳动
  4. 奖励被裁剪到固定区间，让 Q 值的绝对尺度失去意义

为什么：对一组带噪声的估计取 max，被选中的往往是噪声偏正的那一个， 于是 𝔼[maxa Q] ≥ maxa 𝔼[Q]。 这个偏差再经自举沿时间传播，就会累积成明显的过估计。

A 说的是经验回放要解决的样本相关性问题，与偏差无关。 C 会让训练不稳，但目标网络同步频率本身不产生系统性高估。 D 影响的是数值尺度；裁剪奖励反而常常抑制 Q 值膨胀。

3. Dueling 的聚合公式 (14.3) 里减去优势均值这一步是必须的，因为？

  1. 它保证网络输出的 Q 值恒为非负，避免出现负的估计值
  2. 它让优势支路的梯度被整体缩放，从而显著加快收敛速度
  3. 它把动作价值投影到固定区间，避免 Q 值无界地持续膨胀
  4. 它让 V 与 A 可辨识，同时不改变各动作 Q 值的相对大小

为什么：不加中心化时，V 加 c、A 减 c 得到的 Q 完全相同，两条支路无法被损失函数区分开。 把每行优势减去自身均值后，优势的均值被固定为 0，V 就只能承担状态基准价值。 这一步是对整行减同一个常数，所以 arg max 不变。

A 与事实无关：Q 完全可以为负。B 是误传，中心化不改变梯度的整体尺度。 C 也不对，它不限制 Q 的取值范围。

4. 下列哪种情形最值得换成 Dueling 结构？

  1. 动作数很少，并且不同动作带来的收益差距非常大
  2. 奖励非常稀疏，绝大多数状态拿不到任何奖励信号
  3. 动作数较多，并且很多状态下不同动作的效果差不多
  4. 动作是连续的，无法对动作集合逐个求最大值

为什么：Dueling 的价值在于让 V 支路单独学习"这个状态值多少"。 当多数状态下选哪个动作都差不多时，这部分价值占了 Q 的绝大部分， V 一次就能学到，而原本每个动作的 Q 都得重复学一遍。

A 恰好相反：动作差异越大，"比较动作"越重要，优势支路之外收益有限。 B 是探索与采样问题，Dueling 不改变采哪些样本。D 本身就排除了 DQN 一族， 连续动作该走策略梯度或 actor-critic。

5. 关于这两个改进的组合与代价，下列说法正确的是？

  1. 两者可以同时使用：Double 几乎零成本，Dueling 只改结构
  2. 两者互斥，因为 Dueling 的聚合与 Double 的目标相冲突
  3. 两者都要求各自从头训练一份独立的网络，参数量因此要翻一倍
  4. 两者都只是在缓解探索不足，跟过估计偏差与样本效率都没有关系

为什么：Double 只改目标 y 的算法，Dueling 只改网络输出的聚合方式， 一个动损失、一个动结构，互不冲突，叠在一起就是 Rainbow 的做法。

B 是错的：两者作用在不同的位置。C 也不对，Dueling 是共享特征层再分两条支路， 参数增加有限，更不需要两份独立网络。D 把作用完全说反了， 它们治的分别是过估计和样本效率。

代码题 1 · 对比 DQN 与 Double DQN 的目标

背景这两个函数算同一批"转移"的目标值 y，区别在自举那一项怎么取。 "转移"就是环境里的一次跳步，每条记录写着当时的状态、当时选的动作、拿到的奖励、 跳到哪个状态、这一局是否结束。DQN 直接对目标网络在 s′（下一步的状态）上的输出取最大值， 估计里的随机误差会被当成真实优势，算出的目标就系统性偏高； Double DQN 改成让在线网络选动作、目标网络给这个动作打分，两份网络的误差不一样，偏差就小得多。 它们都在训练循环的更新步里被调用，输入是刚算出来的网络输出，输出就是要交给损失函数的 y。 两个函数都不修改输入。

请实现 dqn_targets(rewards, dones, next_q_target, gamma) 与 double_dqn_targets(rewards, dones, next_q_online, next_q_target, gamma)， 只许用标准库与 numpy。签名与 starter 保持一致。

先补两句 numpy。数组就是一排数字的容器，np.array([1.0, 5.0]) 装了 2 个数。 形状 (B,) 表示里面有 B 个数，一维排开；(B, A) 表示 B 行、每行 A 个数。下标从 0 开始。

输入

  • rewards：形状 (B,) 的 float 数组，每条转移的即时奖励，B 是这批样本的条数。
  • dones：形状 (B,) 的 bool 数组，True 表示这一条已经在 s′ 结束，不能再往后看。
  • next_q_target：形状 (B, n_actions) 的 float 数组，目标网络在 s′ 上给每个动作打的分，两个函数都要用。
  • next_q_online：形状 (B, n_actions) 的 float 数组，在线网络在 s′ 上给每个动作打的分，只有 Double 版本用。
  • gamma：float，折扣因子 γ，给未来的分数打折。

输出

  • dqn_targets 返回 np.ndarray，形状 (B,) 的 float：第 i 个元素是 ri + (1 − donei) γ maxa′ Qtarget(s′i, a′)，也就是这一条的即时奖励，加上没结束时打了折的下一步最高分。
  • double_dqn_targets 返回 np.ndarray，形状 (B,) 的 float：先由在线网络挑出 a* = arg maxa′ Qonline(s′i, a′)，第 i 个元素是 ri + (1 − donei) γ Qtarget(s′i, a*)。

会被检验dones 为真时目标只能等于 r，即使 Q(s′,·) 全是 50；非终止样本逐条核对到 1e-12；并列最大值时 np.argmax 取最小下标；4000 条围绕 0 波动的随机 Q 上，DQN 目标均值约 0.93，Double 目标均值绝对值小于 0.15 且低 0.5 以上。

卡住了？看提示
  • 终止的那条不能自举，用 (~dones) 把它乘掉。~ 是取反： True 变 False、False 变 True， 乘上去正好让已结束那条的自举项归零。
  • DQN 版本：np.max(next_q_target, axis=1) 返回每一行的最大值， 形状 (B,)，就是每条样本在 s′ 上的最高分。
  • Double 版本分两步。先 idx = np.argmax(next_q_online, axis=1)， 它返回每一行最大值所在的下标，形状 (B,)。 再用 next_q_target[np.arange(B), idx] 按"第 i 行取第 idx[i] 列"把目标值取出来， 其中 B = next_q_online.shape[0]，np.arange(B) 就是 [0, 1, …, B-1]。
  • np.argmax 在并列时取第一个下标，两个函数都遵守这个约定。

代码题 2 · 实现 Dueling 头部的聚合与中心化

背景Dueling 网络把 Q 拆成两条支路：一条算"这个状态本身值多少"（记作 V(s)）， 一条算"每个动作比平均水平好多少"（记作 A(s,a)），最后要合并成一个 Q 输出。 直接相加有个毛病：V 加一个常数、A 减同一个常数，得到的 Q 完全一样， 训练时这两条支路会漂来漂去，所以合并这一步要减掉优势的均值（或者最大值）把它钉住，这叫中心化。 这两个函数就是合并那一步，在网络最后被调用，输入是两条支路的原始输出， 输出直接当成 Q 用，挑动作和算目标 y 都靠它。两个函数都不修改输入。

请实现 dueling_q(v, adv) 与 dueling_q_max(v, adv)， 只许用标准库与 numpy。签名与 starter 保持一致。

这里再补一句 numpy 的规则：两个数组形状不一样时也能逐项相加相乘， numpy 会自动把小的那个铺开对齐，这个规则叫广播。比如形状 (B, 1) 和 (B, A) 放在一起运算，那一列会被重复 A 次。

输入

  • v：形状 (B,) 或 (B, 1) 的 float 数组，状态价值支路的输出，每个状态一个数。测试两种形状都会传，结果要一致。
  • adv：形状 (B, A) 的 float 数组，优势支路的输出，A 是动作数。

输出

  • dueling_q 返回 np.ndarray，形状 (B, A) 的 float：第 (i, a) 个元素是 vi + adv[i, a] − meana′ adv[i, a′]，均值沿动作轴取，每一行减掉自己那一行的均值。
  • dueling_q_max 返回 np.ndarray，形状 (B, A) 的 float：把上式里的均值换成该行的最大值。

会被检验v 给 (B,) 与 (B, 1) 两种形状时结果一致；中心化后每行 Q 的均值正好等于 v（max 版本是每行最大值等于 v）；每行的 argmax 与 adv 的 argmax 相同；adv 整体加 5 时 Q 不变，v 整体加 2 时 Q 整体加 2；Q 减去 v 之后等于中心化后的优势；(2, 3) 的例子里两个函数的数值逐项核对。

卡住了？看提示
  • 先把输入转成数组：v = np.asarray(v, dtype=float)。 再判断维度：一维时用 v = v.reshape(-1, 1) 变成 (B, 1)， 就能和 (B, A) 按广播规则逐项相加。
  • 均值用 np.mean(adv, axis=1, keepdims=True)， 最大值用 np.max(adv, axis=1, keepdims=True)。 axis=1 表示沿每一行算；keepdims=True 表示算完仍然保留两个维度， 结果形状是 (B, 1)，这样减的时候才能和 (B, A) 对齐。 不加它结果会变成 (B,)，减出来就错了。
  • 中心化是对每一行减同一个常数，所以大小顺序不变，argmax 不会被改变。
