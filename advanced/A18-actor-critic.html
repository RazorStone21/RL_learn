进阶 · 第四部分 · 策略梯度与 Actor-Critic

A2C 与 A3C：Actor-Critic

这一课要走的是策略梯度（不绕道去估价值，直接算参数往哪调能让拿到的总分更高） 这条路。办法是加上一个专门打分的角色，用它给的分去改出招习惯；怎么改，就是这一课要写的更新式。 先认清谁干什么，两个角色的名字到正文里再解释。

你会得到

  • 能写出 actor 与 critic 的两条更新式，并说出 δ（TD 误差）的正负意味着什么
  • 能解释 A2C 与 A3C 的差别，以及为什么教学复现优先选 A2C
  • 能定位"优势尺度失真""策略过早变确定"这两类典型故障

上一课留下的两个问题

策略（一套"看到什么状态就选什么动作"的规则）落到网络上，就是这一课的两个角色。 actor（出招的那一方，负责决定这一步做什么动作，也叫"策略网络"）负责选动作； critic（打分的那一方，负责估计这个局面值多少分，也叫"价值网络"）负责打分。 两者合起来叫 actor-critic，一边出招、一边用打出来的分改出招习惯。

先认一个词。回报（从现在起一直到结束，把每一步奖励加起来的总分） 就是一整局打完之后的总得分，记作 Gt：G 右下角的 t 表示"从第 t 步开始往后的总分"。

0017 课的 REINFORCE 用整条 折扣回报（往后每一笔奖励都乘一个小于 1 的折扣，越远打得越狠）当评分。 折扣因子（越往后的奖励，算进总分时权重越小，等于给它打了个折）记作 γ，是 0 到 1 之间的数。 下面几个符号会反复出现：θ（策略参数）是策略网络的参数， π（策略分布）是策略在每个状态下给出的"每个动作各有多大可能"， δ（TD 误差）是"这一步比预期好多少"，定义在式 (18.2)。

REINFORCE 把这个折扣回报乘上 ∇θ log πθ(At|St)， 据此调整参数 θ。策略（一套"看到什么状态就选什么动作"的规则） 就是参数 θ 所在的那个网络输出的选择规则。这个做法能跑，但留下两个毛病。

  • 波动太大。方差（同一个做法重复很多次，结果波动有多大）极大： 同一套策略跑两局，一局顺、一局背，算出来的 Gt 能差好几倍。
  • 必须等一整局结束。算 Gt 要用到后面的全部奖励，回合不结束就拿不到。 连续任务里这一局永远不会结束。

0017 用基线（从回报里减掉的一个参照值，只降波动，不改平均方向）把回报换成了 优势（在某个状态下，选这个动作比"平均水平"好多少，也就是你这一步比常规走法强多少）， 可是那个基线是人拍出来的常数，写多少全凭试。

这一课把基线也学出来：让一个价值网络 V(s) 去估"从状态 s 出发平均能拿多少分"，它的预测误差就是"这一步比预期好多少"。 这套结构叫 actor-critic，critic 就是这个价值网络。

好处很直接：critic 每一步都能立刻说"你刚才那一步超出预期了"，更新从每局一次变成每步一次。

第一节：这两条更新式在说什么

先看两个会反复出现的符号。

  • ∇θ 读作"对 θ 求梯度"。梯度（往哪个方向调参数能让目标下降最快） 是一个方向，告诉我们参数往哪边挪、目标值变化最快。
  • 𝔼[·] 里的 𝔼 是期望（同一件事重复很多次之后的平均结果）， 读作"长期平均下来是多少"。括号里的东西按各种情况出现的概率加权求平均，不是一次采样的结果。

actor 的更新式长这样：

∇θJ(θ) ≈ 𝔼[ δt ∇θ log πθ(At|St) ] + η ∇θH( πθ(·|St) ) (18.1)

式中 π 是策略分布，H 叫熵（衡量"选择有多随机、多分散"；熵大代表还敢试）， η（熵系数，熵那一项在目标里占的权重）控制它的分量。下标 t 表示"第 t 步"， St 是第 t 步的状态，At 是第 t 步的动作。 πθ(At|St) 读作"在状态 St 下选中动作 At 的概率"。

和 0017 的写法比，只换了一个地方：原来乘的是整条回报 Gt， 现在乘的是 δt。整个式子的意思没变，还是"让拿分高的动作概率变大"。

再看 δt 从哪来：

δt = Rt+1 + γ Vφ(St+1) − Vφ(St) (18.2)

式中 γ 是折扣因子，Rt+1 是这一步真正拿到的奖励， φ 是价值网络（也就是 critic）的参数。

把它读成一句话：δt 就是"这一步的结果，比 critic 事先预期的好多少"。 δt > 0 说明动作 At 超出预期， 梯度上升会提高它的概率；δt < 0 就压低。 所以 δt 就是优势函数（在某个状态下，选这个动作比"平均水平"好多少） 的一个现成估计。

符号记法与 符号表一致， 更细的定义见术语表。

第二节：critic 自己怎么学

critic 是一个价值网络 Vφ(s)，输入状态，输出一个数。 它要学的目标是"从这个状态出发，后面平均能拿多少分"，这个数叫状态价值。 训练它用均方误差：

L(φ) = 𝔼[ ( Rt+1 + γ Vφ−(St+1) − Vφ(St) )² ] (18.3)

"均方误差"就是把预测值和目标的差平方之后取平均，平方是为了让正负误差不互相抵消。

式子里 φ− 是 critic 的目标网络（另存一份"稍旧"的网络专门用来算目标，隔一阵才同步一次，避免追着自己跑）， 做法和 0013 课完全一样：目标参数另存一份，别跟着正在回归的参数一起动。

这里要认清一笔账：Vφ 是人学出来的，一定有误差， 于是 δt 也带着偏差（估计值系统性地偏离真值）。 actor-critic 做的事情，是把 REINFORCE 的高方差，换成了 自举（用自己当前的估计去更新自己当前的估计，等于自己拽自己的鞋带往上提） 带来的偏差。一笔账换一笔账，没有白拿的好处。 (18.2) 和 (18.3) 里那项 γ Vφ(St+1) 就是自举： 它拿网络自己的预测当目标的一部分。

第三节：往前看几步才合适

用 δt 当优势，等于只往前看一步：波动小，但偏差大。 因为它几乎完全依赖 critic 当前的预测，critic 估歪了，优势就跟着歪。

另一个极端是往前看完整局。蒙特卡洛（把一整局走完，用真实拿到的总分来估计价值） 把后面所有真实奖励都加起来，不带任何预测。这样不会因为 critic 的偏差而歪， 但每一步都被后面所有随机事件影响，波动就大了。

中间还有很多档：往前看 2 步、3 步、10 步，每一档的偏差与方差配比都不同。 往前看的步数记作 n。n 越大越接近蒙特卡洛，偏差渐小、方差渐大。

挨个试太笨。0019 课的 GAE（generalized advantage estimation，广义优势估计） 用指数加权把这些档位一次平均掉，读那一课时你会看到它怎么把两端连起来。

实践中 A2C 不会真的"每一步更新一次"。它先跑一段长度为 T 的 rollout（让程序跑一遍，把一路上遇到的经历收集起来）， 常见取值是 T = 5 ~ 20，也就是连续采样出来的一小段轨迹。 对它每个时刻算 n-step 优势，再把这些优势合成一个 batch（一批样本）一起更新。 攒批更新比逐步更新稳定，因为一次更新用的是多步信息的平均。

第四节：A3C 与 A2C 的差别在并行方式

连续任务里等不到回合结束，工程上的解法是同时开很多份环境一起采样。两条路线的差别就在怎么汇总。

第一条是异步。A3C（asynchronous advantage actor-critic） 开多个 worker，也就是多个并行的执行者，每个跑自己的一份环境副本， 各自算完梯度就直接写进共享参数，不打招呼、不等别人。

多份环境同时跑，采到的数据天然不一样，所以它不需要 经验回放（把走过的每一步都存进一个池子，训练时从池子里随机抽一批出来用）。 on-policy（边学的那套策略，就是正在用来产生数据的那套）的方法本来也用不了旧数据。

代价有两笔。一是梯度会过期：某个 worker 算梯度时读到的参数， 很可能已被别的 worker 改过，算出来的方向对不上现在的参数。 二是结果不稳定：更新互相覆盖，同一份代码跑两次结果都不一样，对线程数和调度很敏感。

第二条是同步。A2C（advantage actor-critic） 把那些并行环境改成一个同步的 batch：所有副本各跑 T 步，等齐了一起做一次更新。 丢掉异步之后换来三件事：GPU 可以一次算完、结果可复现、梯度不会过期。 A2C 是 A3C 的同步简化版，没有配一篇新论文。教学和复现都该先写它。

第五节：熵正则、共享网络与常见故障

(18.1) 末尾那一项 η ∇θH 叫 熵正则（entropy regularization）。 这里的 H 叫熵（衡量"选择有多随机、多分散"；熵大代表还敢试）。

加这一项的效果，是给"别太早变确定"发奖金，比喻一下就是强制留一点好奇心。 不加它，策略很容易在训练早期就锁死在一个动作上，后面的好选择再也没机会被抽到。

系数 η 控制这股好奇心有多强。太大，策略一直很随机，回报曲线看着不涨； 太小，早期就坍缩到一个局部最优动作上。它是要盯着调的。

另一个坑是 actor 与 critic 共享网络主干：两条损失的尺度差很多，价值回归会压住策略梯度。 稳妥做法是先分开两个网络，确认两条损失都在正常下降再共享。

症状先查什么
优势几乎恒为正或恒为负奖励没归一化，或 critic 的尺度与回报不匹配
熵迅速掉到接近 0熵系数 η 太小，或 actor 的学习率（每次更新时往新信息的方向挪多远）太大
曲线剧烈震荡、方差很大rollout 太短或副本太少，梯度噪声没被平均掉
critic 损失不降但策略还在变两条损失权重失衡，优势不可信

选型可以压成一句话：需要一套最简单的策略梯度基线，又能开多个并行环境，就选 A2C。 至于"优势往前看几步"这件事，本章后面两课继续往下走： 0019 课的 GAE 把偏差与方差一次调好， 0020 课的 PPO（proximal policy optimization，近端策略优化） 再给更新幅度加上一道限速。

课后练习

1. 在 actor-critic 里，critic 提供的是什么？

  1. 它直接输出动作概率分布，并决定每一步该采取哪个动作
  2. 它估计状态价值，并把 TD 误差当作优势交给 actor 使用
  3. 它保存历史回报的平均值，用常数基线替 actor 降低方差
  4. 它估计环境的转移与奖励，供 actor 在内部做前向规划

为什么：critic 学的是 Vφ(s)， 输出的是价值标量；把它的 TD 误差 δt 交给 actor 当优势， 就把 0017 里那个手工基线换成了可学习的基线，并且每一步都能更新。

A 描述的是 actor 本身；C 退回成了 REINFORCE 的常数基线； D 描述的是模型基方法（model-based），actor-critic 不需要环境模型。

2. A2C 与 A3C 的核心差别是什么？

  1. A2C 要维护经验回放缓冲区，A3C 只使用刚采样到的数据
  2. A2C 学确定性策略（固定选同一个动作），A3C 学随机策略（按概率抽动作）
  3. A2C 不需要 critic，直接用整条折扣回报当作优势来更新
  4. A2C 把并行环境同步成一个批，A3C 让多个 worker 异步更新

为什么：两者的更新式几乎相同，区别只在并行方式： A2C 同步收集、同步更新，因此可以用 GPU 批量化、结果可复现、不会有梯度过期； A3C 让各 worker 异步写共享参数，换来更高的吞吐但失去了可复现性。

A 把两者说反了，on-policy 方法都不能靠回放缓冲区里的旧数据训练； B 与事实无关，两者都用随机策略；C 描述的是 REINFORCE，不是 A2C。

3. 把优势换成 critic 的 TD 误差 δt 之后，梯度发生了什么变化？

  1. 方差下降但引入偏差，因为 δt 依赖 critic 那个可能不准的 V 估计
  2. 方差与偏差同时下降，因为 critic 最终会学到真实的价值函数（从某个状态出发，按某套策略走下去平均能拿多少总分）
  3. 偏差消失，因为 TD 误差本身就是一种无偏的优势估计，与策略参数无关
  4. 方差上升，因为每一步都要重新估计一次当前状态的价值，噪声变大

为什么：δt 只用一个奖励加一次自举， 比整条回报 Gt 的方差小得多；但 Vφ 是人学的， 它的误差会原封不动进入优势，所以梯度变成有偏的。

B 把逼近当成了相等：critic 只能逼近真实价值，训练中永远有误差； C 恰好相反，δt 的自举项依赖 critic 参数，谈不上无偏； D 说反了，逐步估计才是方差下降的来源。

4. 关于一步 actor-critic 与 n-step 版本，下列说法正确的是？

  1. n 越小方差越大，n 越大越接近蒙特卡洛的回报估计
  2. n 越大方差越小，n 越小越接近蒙特卡洛的回报估计
  3. n 越小偏差越大方差越小，n 越大越接近蒙特卡洛
  4. n 越大偏差越大方差越小，n 越小越接近蒙特卡洛

为什么：n=1 就是 δt：只用一次自举，方差最小、 偏差最大；n 增大后自举次数减少、真实奖励增多，估计越来越像蒙特卡洛， 偏差减小、方差上升。GAE 就是在这两端之间做指数加权。

A 与 B 都把方差的方向说反了；D 把偏差方向说反：n 越大偏差是减小而不是增大。

5. 熵正则项的作用与最常见的误用分别是什么？

  1. 它鼓励策略保持随机以维持探索，η 太大会让策略一直随机
  2. 它惩罚价值过高的动作，η 太大会让策略回避高回报动作
  3. 它惩罚 critic 的估计误差，η 太大会让价值函数停止收敛（数值不再趋于稳定）
  4. 它把策略快速推向确定性以加速收敛，η 太大会让熵塌缩

为什么：熵衡量策略的随机程度，把它加进目标等于给"保持不确定"发奖金， 防止早期就锁死在一个动作上。η 过大时策略长期接近均匀随机， 回报曲线看起来像没学到东西。

B 与 C 都改错了项：熵只与策略分布有关，和动作价值（在某个状态下先选某个具体动作，之后再好好走，能拿多少总分）、 critic 误差都无关；D 把符号说反了，熵正则（在目标里加一项鼓励保持随机性，防止过早死磕一个选择） 是往上加熵，不是压低熵。

代码题 1 · 用 TD 误差构造优势

背景actor-critic 里 critic 学一个状态价值 V(s)，训练循环每采集一段轨迹就调用这两个函数，把价值预测变成 actor 能用的优势信号。td_errors 给出每一步的单步 TD 误差，n_step_return 把 n 步真实奖励和一次自举拼起来，是偏差与方差之间的中间档。这些数组都来自同一段轨迹。

请实现两个函数，只用标准库加 numpy：td_errors(rewards, values, next_values, dones, gamma) 与 n_step_return(rewards, values, t, n, gamma)。

输入

  • rewards（两个函数共有）：形状 (T,) 的 float 数组，第 t 项是奖励 rt。
  • values（两个函数共有）：形状 (T,) 的 float 数组，第 t 项是 V(st)。
  • next_values（td_errors）：形状 (T,) 的 float 数组，第 t 项是 V(st+1)。
  • dones（td_errors）：形状 (T,) 的布尔数组，第 t 项为 True 表示这一步是回合的最后一步。
  • gamma（两个函数共有）：Python float 标量，γ（折扣因子）。
  • t（n_step_return）：Python int，起始步下标。
  • n（n_step_return）：Python int，往前看的步数。

输出

  • td_errors 返回形状 (T,) 的 np.ndarray：第 t 项是 rt + γ(1 − donet)V(st+1) − V(st)。
  • n_step_return 返回 Python float：Gt(n) = Σl=0n−1 γl rt+l + γn V(st+n)；当 t+n 越出 values 的范围时，末尾自举项按 0 处理。

会被检验测试会逐项核对 δ 的数值，并把终止步的 next_values 换成 1e9，要求那一步完全不含自举；还会核对 t=2, n=3 越界那一例的自举项为 0，并验证折扣 δ 之和等于 Gt(n) − V(st)。

卡住了？看提示
  • 终止不自举可以写成 (~dones) 乘在自举项上，一行搞定。
  • n_step_return 用一个 for l in range(n) 累加，折扣因子逐项乘。
  • 末尾自举项要判断 t + n < len(values) 再累加。

代码题 2 · 算带熵正则的 actor 损失与梯度

背景这是 actor 的损失函数，训练循环在每个 batch 上调用一次：返回的 loss 用来监控策略项与熵项各占多少，返回的 grad 直接更新策略输出层的 logits，也就是让策略输出一点点变好的那个方向。优势为正的动作会被提高对数概率（把概率取对数后的值；概率越小它越负，用来避免很小的概率在计算里直接变成 0），熵那一项一直把分布往外推，避免策略过早锁死在少数动作上。advantages 一般来自本课 critic 给出的 TD 误差或 GAE。

请实现 actor_critic_loss(logits, actions, advantages, entropy_coef)，只用标准库加 numpy。

输入

  • logits：形状 (B, A) 的 float 数组，B 是 batch 大小，A 是动作数，每行是 softmax 策略的未归一化分数。
  • actions：形状 (B,) 的整数数组，取值 0 ~ A−1，第 i 项是实际执行的动作。
  • advantages：形状 (B,) 的 float 数组，第 i 项是 Ai，衡量该动作比平均好多少。
  • entropy_coef：Python float 标量 η，给式 (18.4) 里的熵正则项定权重，取 0 时熵项消失。

输出

  • 返回二元组 (loss, grad)。loss 是 Python float，等于 −meani[log π(ai|si)·Ai] − η·meani[H(π(·|si))]。
  • grad 是形状 (B, A) 的 np.ndarray，是 loss 对 logits 的梯度，行列位置与 logits 一一对应。
L = − meani[ log πθ(ai|si) · Ai ] − η · meani[ H( πθ(·|si) ) ] (18.4)

会被检验测试会核对 eta=0 与 eta=0.5 时的 loss 数值；grad 形状与 logits 相同、每行之和为 0，并用数值微分逐项核对。优势全为 0 且 eta=0 时 loss 与 grad 都为 0；eta=1 时均匀策略的 loss 等于 −log 3，尖峰分布上升的那一列梯度为正、其余为负。

卡住了？看提示
  • 记 p = softmax(logits)、logp = logits − logsumexp(logits)， 策略项对 logits 的梯度是 A_i · (p − onehot(a_i))。
  • 熵那一项：H = −Σ p log p，它给出的梯度是 η · p · (logp + H)（逐元素乘）。
  • 两个梯度都要再除以 batch 大小 B，因为 loss 用的都是 mean。
