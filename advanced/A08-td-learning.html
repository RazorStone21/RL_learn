进阶 · 第二部分 · 无模型方法

时序差分 TD(0)

上一节的办法要等一整局走完才能学，这一节换一条路：走一步就能学一步。 它会先讲清"用下一步的估计来更新这一步的估计"这件事，再说明这样做换来了什么、代价是什么。

你会得到

  • 能写出 TD(0) 的更新式，并指出每一项在代码里对应什么
  • 能用自己的话解释自举与 TD 误差
  • 能说出它与蒙特卡洛在偏差和波动上的差别，以及为什么它常常学得更快

上一节卡在哪两处

第 0007 课讲过的方法叫蒙特卡洛（把一整局走完，用真实拿到的总分来估价值）， 它有两个硬伤。

第一，它必须等一整局走完，拿到这一局的回报（从现在起一直到结束，把每一步奖励加起来的总分）， 才能更新一次估计。要是这一局有几千步，或者任务永远不结束，它就一步也学不了。

第二，这个回报把一整局里所有的随机性都堆进了一个数，波动很大。 同一个起点跑两次，拿到的回报可能差得远。

这一节的办法换个思路：为什么要等真实的总分？手上已经有一个对下一状态的估计了， 先用它顶上。

TD(0)：用下一步的估计当目标

这个办法叫时序差分（不用等到一局走完，用"走一步之后的新估计"来更新"走这一步之前的估计"）， 简称 TD。它的核心更新只有一行。

V(s) ← V(s) + α [ r + γV(s') − V(s) ] (8.1)

先把这一行"读"一遍。箭头读作"更新为"；V 是价值估计， 括号里放的是状态，也可以是"状态加动作"； s 是刚离开的那个状态，s' 是刚进入的新状态； r 是环境刚给的即时奖励；α 是学习率（每次更新时，往新信息的方向挪多远）； γ 是折扣因子（越往后的奖励，算进总分时权重越小，等于给它打了个折）。 方括号里那一整串叫 TD 误差，下面单独讲。这里先记住这套记号： 给定一套策略（看到什么状态就选什么动作的规则），价值就是指"照着它走下去，平均能拿多少总分"。

这一行在做什么？拿"这一步的即时奖励，加上打折后的下一步估计"当作一个新目标， 然后让 V(s) 朝这个目标挪一小步。挪多远，由 α 决定。

举个例子。假设现在估计"从状态 A 出发能拿 10 分"，也就是 V(A) = 10。 从 A 走一步到了状态 B，拿到了 2 分奖励，而 V(B) = 8， 折扣因子取 1。那么新目标是 2 + 8 = 10，和当前的估计一样，这一行就不改动。 如果 V(B) 是 14，新目标就变成 16，这个更新会把 V(A) 往上抬一点。抬多少，看 α。

方括号里的那个量是整个课程里最重要的中间量，叫 TD 误差（TD 目标减去当前估计，也就是还差多少没补上）：

δt = r + γV(s') − V(s) (8.2)

公式 (8.2) 里 δt 表示"第 t 步的那个 δ"， 其中右下角的 t 就是步数下标。 它等于"新目标"减去"当前估计"，读出来就是"还差多少"。 如果两个数相等，误差是 0，这一步就不用改。

新目标 r + γV(s') 有个名字，叫 TD 目标（用来当靶子的那个数，等于即时奖励加打折后的下一步估计）， 英文是 TD target。到达终止状态时，把 V(s') 当作 0， 目标里就不含"下一步的估计"了，这一行代码天然覆盖了两种情形。

注意 V(s') 本身也是一个估计值，可能还是错的。 拿一个估计去更新另一个估计，这种像拽着自己鞋带往上提的做法叫 自举（用自己当前的估计去更新自己当前的估计）。 上一节的蒙特卡洛从不拿自己的估计当目标，而 TD 每一步都在这么做。

偏差与方差的取舍

先补两个词。方差说的是"同一个做法重复很多次，结果波动有多大"， 像成绩忽高忽低。偏差说的是"估计值总往同一个方向偏，一次又一次地偏同一侧"， 像一杆秤每次都偏重两斤。

蒙特卡洛的目标是真实采样出来的回报，它是实实在在发生的分数， 不会一次又一次地偏向同一个方向。所以它的估计是无偏的，但方差大。

TD 的目标里塞了一个 V(s')，而这个数本身还在学、可能还是错的。 拿它当靶子，估计就会偏向它当前的样子，所以 TD 是有偏的。 好处是它只用了一步的随机性，方差小得多。

量级上可以这样感受。如果 V(s') 有 ±0.5 的误差， TD 目标的误差大致也在这个量级。而一个几十步的蒙特卡洛回报， 误差要把沿途每一步的随机都累加起来，常常是它的好几倍。 一句话：TD 是拿偏差换了方差。

为什么 TD 常常更准

Sutton & Barto 用同一个 5 状态随机游走做了对照实验[第 6.2 节, 图 6.2]： 常数步长的 TD(0) 在早期就把误差压了下来，而常数 α 的蒙特卡洛起步很慢。 这里用的误差是 RMS 误差，意思是"把每个状态的估计误差平方后取平均，再开根号"， 英文全称 root mean square，它衡量的是整体差了多远。

原因不只是"更新得更频繁"。TD 还用上了一条蒙特卡洛用不了的信息： 相邻两个状态的价值必须彼此对得上。当 V(s') 被修正时， 这个修正会顺着 TD 更新一步步往回流到相邻状态；蒙特卡洛只能等这一整条轨迹重新跑出来。 TD 把"这个环境的下一步只取决于现在"这条先验吃进了算法里。

把同一批经验反复扫，这件事看得更清楚。做法是把数据分成一批批地过： 一次处理一小批，而不是一条一条来，这样的一批数据叫 batch（一批样本，像一次批改一叠作业）。 反复扫完之后，用批量的蒙特卡洛会收敛（一轮轮算下去，数值不再明显变化，稳定下来了）到训练集上的最小平方误差解， 而用批量的 TD(0) 会收敛到另一个解：先由这批数据估出一个 MDP （马尔可夫决策过程，就是把"下一步只取决于现在"的问题写成标准格式）， 似然指的是"当前这套说法，解释我们观测到的这批数据的能力有多强"， 再取这个 MDP 的最大似然解。 这就是 TD 在预测任务上常常更准的理论解释。

应用视角：TD 换来了什么，代价是什么

换来的是能在一条长长的流水线上持续学：每交互一步就更新一次， 不需要"这一局到哪儿算结束"，天生适合永不终止的线上系统。 从这一节开始，后面所有算法都建立在 TD 之上。

代价是自举带来的偏差与不稳定。单独用表格 TD 很稳； 但一旦把自举、函数逼近（状态太多记不下整张表，干脆用一个带参数的函数去猜价值）、 off-policy（边学的那套策略，不是产生数据的那套）这三样叠在一起，就可能发散。 这就是第 0012 课要讲的 致命三元组（这三样东西同时出现时，学习可能越跑越偏）， 英文叫 deadly triad。

诊断上也有用。如果价值估计在训练中越来越大，直到溢出， 先查两件事：α 是不是太大，以及状态的表示是不是把该有的信息丢了。 后者回到 0006 课的检查表。

课后练习

1. 下面哪一项是 TD(0) 里的 TD 误差 δt？

  1. 当前状态的估计值与该状态真实价值之间的差值
  2. 整个回合的真实回报与当前价值估计之间的差值
  3. 即时奖励加折扣后的下个状态估计，再减去当前估计
  4. 当前这一步的即时奖励与折扣后即时奖励之间的差

为什么：δt = r + γV(s') − V(s)， 它是"TD 目标减当前估计"的差，也就是这一行更新要消掉的量。

B 描述的是 MC（Monte Carlo，蒙特卡洛）的误差 Gt − V(s)，不是 TD 误差。 A 说"真实价值"，可真实价值你根本不知道，否则就不用学了。 D 把奖励自己减自己，与价值估计无关，凑不出任何有用的信号。

2. 在 TD 里说"自举（bootstrapping）"，指的是什么？

  1. 用对下个状态的估计来构造更新目标，不等真实回报
  2. 从同一批数据反复重采样，以提高样本的利用效率
  3. 用多步回报的平均值来降低单步更新引入的方差
  4. 逐步把学习率衰减到零，以保证价值估计最终收敛

为什么：自举就是"拿自己当前的估计当目标的一部分"。 r + γV(s') 里的 V(s') 是估计值， 整个更新不需要等到回合结束。

B 说的是重采样或经验回放（把走过的每一步存进一个池子，训练时从池子里随机抽一批出来用）， C 说的是 n-step 或平均回报，D 说的是学习率调度： 三者都真实存在，但都不是自举的含义。

3. 关于 TD 与蒙特卡洛在偏差和方差上的特性，哪一项描述正确？

  1. TD 无偏而方差大，MC 有偏而方差小，二者正好互补
  2. 两者都无偏，只是 TD 的方差在实践中通常更小一些
  3. 两者都有偏，只是 MC 的偏差会随回合长度一起增长
  4. TD 有偏而方差小，MC 无偏而方差大，各有各的取舍

为什么：MC 的目标是真实采样的回报，所以无偏；TD 的目标里含估计值 V(s')，所以有偏，但因为只用一步随机性，方差小得多。

A 把两者对调了。B 错在 TD 并非无偏：它只在估计收敛（数值不再明显变化）之后才渐渐不偏。 C 也错：MC 的回报本身无偏，方差才随回合长度增长，不是偏差。

4. 在 5 状态随机游走上，常数步长的 TD(0) 通常比常数 α 的 MC 收敛更快，为什么？

  1. 因为 TD 每次更新的计算量远小于 MC 的一次更新
  2. 因为 TD 会自举，并利用了状态之间的马尔可夫结构
  3. 因为 TD 不需要探索，因此不会把样本浪费在坏动作上
  4. 因为 TD 的更新目标无偏，所以每一步都指向真实价值

为什么：TD 每步都更新，而且价值信息会沿马尔可夫链快速传播； 一个状态估计的改进立刻成为相邻状态的目标，不必等整条轨迹重新采样。

A 是无关的工程细节：计算量差异解释不了误差曲线差那么多。 C 错：预测任务里两者都在给同一套策略（看到什么状态就选什么动作的规则）打分， 谈不上谁不需要探索。 D 恰好说反了：TD 的目标是有偏的，无偏的是 MC。

5. 把同一批经验反复扫给批量的 TD(0)，它会收敛到什么？

  1. 训练数据上的最小平方误差解，与批量蒙特卡洛一致
  2. 这套策略的真实价值（从某个状态出发，平均能拿多少总分），与这批数据的来路无关
  3. 由这批数据估出的那个 MDP，它的最大似然解
  4. 一个依赖学习率 α、会随 α 改变的不动点（再迭代一次也不变的那种解）

为什么：批量 TD(0) 收敛到的是"让每个状态的价值都彼此对得上"的那个解， 也就是用这批数据估出的那个 MDP 的最大似然估计。 它满足的那个等式叫贝尔曼方程（把"这一步的价值"和"下一步的价值"连起来的等式）。

A 恰好是把两者说反了：最小平方误差解是批量蒙特卡洛的极限。 B 错：任何方法都只能逼近数据支持范围内的东西，采样分布当然有影响。 D 错：batch 迭代法的极限与 α 无关，α 只影响收敛速度。

代码题 1 · 实现 TD(0) 预测

背景上一课的办法要等一整局走完才能更新一次，td_prediction 换成走一步就更新一次：每一步只用"即时奖励加上下一步的估计"来改当前这一步的估计， 不用等回合结束。它做的仍然是在给定策略下估计价值，后面和蒙特卡洛做对比时会反复调用它， 也是后面 DQN（深度 Q 网络）算目标时的起点。

环境沿用 Sutton & Barto 的 5 状态随机游走：状态编号 0 到 6，0 和 6 是终止状态， 走到 0 得 0 分、走到 6 得 1 分；每走一步以 0.5 的概率向左一格、0.5 的概率向右一格， 每局都从状态 3 出发。

请实现 td_prediction(n_episodes=20000, alpha=0.05, gamma=1.0, seed=0)。

输入

  • n_episodes：int，回合数，默认 20000；
  • alpha：float，常数步长，默认 0.05；
  • gamma：float，折扣因子，默认 1.0；
  • seed：int，随机种子，默认 0。

输出

  • 返回 np.ndarray，形状 (7,)，float：V[s] 是状态 s 的价值估计；状态 0 与 6 是终止状态，价值保持 0。

会被检验返回值是 numpy 数组且形状为 (7,)；V[0] 与 V[6] 保持 0；V[1..5] 与真值 s/6 的偏差小于 0.12；价值随状态编号严格递增。步长必须是常数 alpha，换成样本平均就不是 TD(0)，上面这条容差也对不上；随机数来自 np.random.default_rng(seed)；只用标准库加 numpy。

卡住了？看提示
  • 第一句先写 rng = np.random.default_rng(seed)， 再写 V = np.zeros(7)。它返回"装了 7 个 0 的一维数组"， 下标从 0 开始，所以状态 s 的估计就存在 V[s] 里。
  • 外层用 for _ in range(n_episodes) 跑每一个回合，回合开始设 s = 3。
  • 内层用 while True 走每一步：先算下一个状态，写法是 s_next = s + (-1 if rng.random() < 0.5 else 1)。 rng.random() 返回 0 到 1 之间的一个随机小数，它小于 0.5 的可能性正好是一半。
  • 再算这一步的奖励：r = 1.0 if s_next == 6 else 0.0， 也就是只有走进状态 6 那一步才给 1 分。
  • 然后按公式 (8.1) 更新：V[s] += alpha * (r + gamma * V[s_next] - V[s])。 注意方括号里用的是更新前的 V[s]，而且 V[s_next] 读的是旧的估计。
  • 最后 s = s_next 往前走一步；如果 s 到了 0 或 6 就 break。 全部回合跑完 return V。终止状态的价值不动，所以一直是 0。

代码题 2 · 用固定种子做 MC 与 TD 的统计对比

背景本课的关键结论是 TD 通常比蒙特卡洛学得快。 这个结论需要一个能复现的对照实验来支撑：mc_td_curves 在同一条随机游走上同时跑两种方法，每个回合两者共用同一条轨迹， 再用固定种子把多次实验的 RMS 误差取平均，返回两条曲线供课上画图和读结论。 它是一个统计实验函数：输入是实验规模和两个步长，输出是"误差随回合数变化"的两条序列。

请实现 mc_td_curves(n_runs=30, n_episodes=2000, alpha_mc=0.02, alpha_td=0.1, seed=7)。第 r 次实验的随机数用 np.random.default_rng(seed + 1000 * r)；每次实验维护长度 7 的 Vmc 与 Vtd（全 0），分别在常数步长 alpha_mc 与 alpha_td 下更新，两处都取 γ = 1；CHECKPOINTS = [10, 50, 100, 500, 2000] 是记录误差的回合数。

输入

  • n_runs：int，重复实验次数，默认 30；
  • n_episodes：int，每次实验的回合数，默认 2000；
  • alpha_mc：float，MC 的常数步长，默认 0.02；alpha_td：float，TD(0) 的常数步长，默认 0.1；
  • seed：int，基础种子，默认 7。

输出

  • 返回二元组 (mc_err, td_err)，两项都是 np.ndarray，形状 (5,)，float；
  • mc_err[i] 与 td_err[i] 是在 CHECKPOINTS[i] 个回合时、对 n_runs 次实验取平均的 RMS 误差，即状态 1–5 的估计与真值 s/6 的均方根差。

会被检验两项都是 numpy 数组且形状为 (5,)；50 个回合与 100 个回合时 TD 的误差都低于 MC；MC 的误差随样本增加而下降，即 mc_err[-1] < mc_err[0]；2000 个回合后两条曲线都降到 0.15 以下；只用标准库加 numpy。

卡住了？看提示
  • 先准备真值数组：true_v = np.array([i / 6.0 for i in range(7)])， 再用 np.zeros(len(CHECKPOINTS)) 建两个长度为 5 的累计误差数组。 np.zeros(n) 返回"装了 n 个 0 的一维数组"。
  • RMS 误差的意思是"把每个状态的误差平方、取平均、再开根号"， 代码是 math.sqrt(np.mean((V[1:6] - true_v[1:6]) ** 2))。 其中 V[1:6] 是切片，取出下标 1 到 5 这五个数，6 取不到。
  • 外层 for r in range(n_runs) 跑每一次实验：开头写 rng = np.random.default_rng(seed + 1000 * r)，再建 Vmc = np.zeros(7) 与 Vtd = np.zeros(7)， 并把检查点下标 ci = 0 归零。
  • 内层 for ep in range(1, n_episodes + 1) 跑回合。先从状态 3 走出一条完整轨迹 （把途经状态按顺序存进一个列表，走到 0 或 6 结束）， 再令 G = 1.0 if 终点 == 6 else 0.0。
  • 然后让两个估计共用这条轨迹。蒙特卡洛用 for st in reversed(path) 从末尾往前遍历，每个非终止状态做 Vmc[st] += alpha_mc * (G - Vmc[st])，并且每退一步把折扣补上。
  • TD 要正向遍历：让 s0 = 3，对轨迹里每个 st 先算 rew = 1.0 if st == 6 else 0.0，再做 Vtd[s0] += alpha_td * (rew + Vtd[st] - Vtd[s0])，然后 s0 = st。 两处都取 γ = 1，所以不用乘 gamma。
  • 每个回合结束时判断 ep == CHECKPOINTS[ci]：成立就把两种方法当前的 RMS 误差累加进各自的数组，再 ci += 1。 全部跑完后返回 mc_err / n_runs, td_err / n_runs，除以次数就是平均值。

想看看 TD 误差在 RL（reinforcement learning，强化学习）工程实现里被怎么用，可以读 OpenAI Spinning Up 的 Key Concepts in RL， 它把 V、Q 与优势函数（在某个状态下，选这个动作比"平均水平"好多少）的关系讲得很直接。

有不清楚的地方，直接追问你的 AI 老师，它是你的私教。可以问： "把 TD 误差和我的业务指标对照一下，哪个量最像 δt？" 或者让它画一张你自己问题的备份图，逐项解释偏差从哪里来。
