进阶 · 第三部分 · 深度价值方法

优先经验回放 PER

这一节把0013 课的"每次等概率随便抽"换成"专挑还没学会的样本抽"。 你会写出采样概率，以及重要性采样（用一套分布抽出来的数据去估计另一个分布的目标， 要按概率比例做修正）的权重 ρ（重要性采样权重）；也会明白 β（重要性采样退火指数，控制修正力度，从 0.4 慢慢升到 1）为什么不能省。

你会得到

  • 能由 TD 误差算出采样概率，并写出对应的重要性采样权重
  • 能说清"优先"为什么带来偏差，以及权重与 β 退火如何把它修回来
  • 能用 sum-tree 的思路解释"采样和更新都是 O(log N)"是怎么做到的

均匀回放浪费在哪

回放缓冲区（把走过的每一步都存进一个池子，训练时从里面抽样本，相当于错题本） 里通常躺着十万到上百万条记录。DQN（deep Q-network，深度 Q 网络：拿一个神经网络当记忆， 输入状态、输出每个动作值多少分）每次等概率地从里面抽一小批来训练。 这一小批叫 batch（一批样本：训练时一次处理一小批，而不是一条一条来）。

等概率抽，等于假设每条记录一样有用。真实情况几乎从不如此。 奖励很稀疏的任务里，绝大多数样本的误差接近 0，对着它们反复训练， 只是在确认"这里没什么可学"（这种情形叫稀疏奖励：绝大多数步骤都拿不到奖励， 只有极少数关键时刻有分，像只有通关才得分）；而少数几条关键记录 （第一次拿到奖励、第一次掉进坑里） 被抽到的概率和其他样本完全一样，平均要等 N 次更新才轮到它一遍。

换个抽样分布就能把这些记录的分量提上去。核心只有一句：让"还学不会的样本"更常出现。 这就是优先经验回放（优先抽那些误差大、还没学会的样本，简称 PER）的出发点。 它靠不均匀抽样实现：哪条记录错得多，就多刷几遍，像错题本里反复抽那道题。

它不单独构成一套算法，只是插在训练循环里的一个环节。DQN 靠目标网络 （另存一份"稍旧"的网络专门用来算目标，隔一阵才同步一次，避免追着自己跑） 算出自举（用自己当前的估计去更新自己当前的估计，等于自己拽自己的鞋带往上提）的目标， PER 则决定这一批样本从哪里来。

用 TD 误差当尺子

一条样本有多值得学，最直接的度量就是它的误差。这个误差有个名字， 叫时序差分（不用等到一局结束，用"走一步之后的新估计"来更新"走这一步之前的估计"）， 它每一步算出的差叫 TD 误差（TD error, δ）， 写法是 δ = y − Q(s,a)，也就是目标与当前估计的差。 误差大，说明这条记录还没被拟合好。于是定义优先级与采样概率：

pi = |δi| + εp，   P(i) = piω / Σk pkω (15.1)

式子里的 |δi| 是第 i 条记录误差的绝对值， 也就是把正负号去掉；Σ 是求和号（把后面那串东西全加起来），分母就是所有记录优先级的和。 两个超参（需要你自己设定、而不是训练学出来的参数，像火候得自己掌握）各有分工。 ω（优先级指数）控制"优先"的强度：ω=0 时退回等概率采样， ω=1 时完全按误差比例，原论文默认 0.6，实践起点也是 0.6。 正常数 εp（ε 是优先级下限）保证每条样本都有非零概率被抽到， 实现里常取 10−5 量级。没有它，误差恰好为 0 的样本就永远不再出现， 而"当前误差为 0"绝不等于"永远没错"。

另一条路叫 rank 优先（rank-based prioritization，按误差的排名给概率）： 只按 |δ| 的排名给概率，P(i) ∝ 1 / rank(i)。 它对极端误差不敏感，尺度也更稳，适合奖励分布重尾的任务。 注意本课程沿用算法速查表的记号： 优先级指数写作 ω，因为 α 是学习率 （每次更新往新信息的方向挪多远，太大会来回震荡、太小就学得慢），这个字母已经被占用了。

这套做法出自 Schaul 等人的 Prioritized Experience Replay（arXiv 1511.05952）。

改了分布，就得把偏差修回来

按优先级采样时，参数更新的期望不再等于原始目标函数的梯度，这是一个有偏估计。 这里的期望，是同一件事重复很多次之后的平均结果；有偏指的是反复做很多次， 平均下来会稳定地偏离正确答案，而不是偶尔偏一点。

修正办法是重要性采样（用一套分布抽出来的数据去估计另一个分布的目标， 要按概率比例做修正）：给每条样本乘一个权重 ρ（重要性采样权重）， 抵消它被多抽或少抽的那部分。

ρi = ( 1 / (N · P(i)) )β，再整体除以 maxj ρj (15.2)

式中 N 是缓冲区当前的条数。β=0 时所有权重都是 1， 等于不管偏差、只图快；β=1 时是完全修正，平均下来不再偏， 但每次结果的波动更大。原论文的做法是让 β 从 0.4 慢慢升到 1： 训练早期参数离最优解远，偏差相对还能忍，优先采样带来的加速更值钱； 后期需要收敛（一轮轮算下去，数值不再明显变化，稳定下来了）到准确的价值， 就把修正补满。除以最大权重只是把梯度尺度归一化，不改变相对比例， 避免整批的损失被一个大权重放大。

L(φ) = (1 / B) Σi ρi ( yi − Q(si, ai; φ) )² (15.3)

式中 φ（网络参数，网络里那堆要训练的数字）就是要训练的那组权重， L 是损失（衡量当前估计离目标差多远的一个数，训练就是把它压小）。

sum-tree：让采样也是 O(log N)

式 (15.1) 的概率由全体优先级决定，而优先级每次更新都会变。 如果每次采样都重新把 N 个优先级从头加一遍，计算量是 O(N)： N 是十万，一次采样就要十万次加法，缓冲区一大这里就成了瓶颈。 O(N) 的意思是"计算量随 N 成正比增长"。

sum-tree（求和树）解决这个问题：把优先级放在一棵二叉树的叶子上， 每个内部节点存两个孩子的和，根节点就是总优先级。采样时先在 [0, total) 里均匀取一个数，再从根往下比较左右子树的累加和决定走哪边， 走到叶子就得到一条样本，一次采样只要 O(log N) 次比较。 更新某条样本的优先级，也只要沿它到根的路径改 O(log N) 个节点。

工程上还有一个约定俗成的细节：新入队的样本一律给当前最大优先级。 否则一条误差很小的新样本可能很久都抽不到，而它来自现在正在用的策略 （一套"看到什么状态就选什么动作"的规则，也就是出招习惯），是最不该被浪费的数据。

最容易踩的坑

症状最可能的原因
训练早期还行，后期开始震荡β 没有退火，一直停在 0.4
少数样本被反复抽、其他样本饿死去掉了 εp，或 ω 设得过大
优先级与真实误差脱节、越训越差更新优先级时用了过期的 TD 误差
loss 尺度随 batch 剧烈跳动权重没有按最大值归一化

PER 与 0014 课的两个改进互不冲突， 可以一起打开；它也是 0016 课 Rainbow 六个组件里公认贡献最大的一个。想先看工程默认值，可以对照 Stable-Baselines3 文档 里 β 的退火区间与 ω 的默认取值。

课后练习

1. 为什么按优先级采样时必须再乘一个重要性采样权重？

  1. 因为高误差样本会被反复更新，权重是为了防止参数数值爆炸
  2. 因为 sum-tree 的采样带有浮点误差，权重是用来校正这些误差
  3. 因为按优先级采样改变了样本分布，权重的作用是把期望修正回来
  4. 因为缓冲区里旧策略产生的数据已经过期，权重是用来重新加权的

为什么：梯度的期望是对采样分布求的。一旦把均匀分布换成 P(i)，得到的就是另一个量的梯度；乘上 ρi ∝ 1/P(i) 才把它拉回原目标。 式 (15.2) 的 β 就是在这件事上留了一个可以调的档位。

A 混淆了偏差修正与数值稳定性，权重确实会缩放梯度，但那是副作用而不是目的。 B 不对：浮点误差不需要重要性采样来校正。D 也不对：数据过期是所有 off-policy 方法共有的问题，与是否用优先级无关。

2. 式 (15.1) 里那个小的正常数 εp 有什么作用？

  1. 保证每条样本都有非零的抽样概率，避免零误差样本饿死
  2. 把 TD 误差的尺度归一化，让不同任务的优先级能互相比较
  3. 让优先级指数可以取到 0，从而在训练早期退化成均匀采样
  4. 防止在线网络与目标网络的参数差过大，避免自举过程发散

为什么：若严格按 |δ| 定优先级， 误差恰为 0 的样本概率为 0，永不再被抽到；而它可能只是当前恰好拟合对了， 换个状态分布就会重新出错。加上 εp 给所有样本留一条底，同时也让优先级对噪声不那么敏感。

B 是误传，εp 不做归一化。 C 混淆了两个超参：能否退化成均匀采样由 ω=0 决定，不由 εp 决定。D 与目标网络的同步策略无关。

3. 把 β 从 0.4 线性退火到 1，这样做的理由是？

  1. 它让优先级指数从 0.4 升到 1，采样会逐渐退回均匀分布
  2. 它让重要性采样权重整体变大，从而在训练后期放大梯度
  3. 它让缓冲区容量从 0.4 倍逐步扩到 1 倍，后期能装更多数据
  4. 它让偏差修正由弱到强：早期容忍偏差换速度，后期趋于无偏

为什么：β 是修正强度的档位，不改变采哪些样本。 早期参数离最优解远、主要矛盾是学得快，偏差可以容忍；后期要收敛到准确价值， 就把重要度修正补满，让更新期望回到无偏。

A 把 β 与 ω 搞混了：决定采样分布的是 ω， 而且 β 变大是修正更强，不是退回均匀。B 只看到权重的尺度， 忽略了它是在纠正分布偏差。C 与缓冲区容量毫无关系。

4. sum-tree 在 PER 里解决的问题是什么？

  1. 它把缓冲区按 TD 误差排序，采样时直接取误差最大的若干条
  2. 它用 O(log N) 支持按优先级采样与更新，不必每次重算前缀和
  3. 它把状态特征组织成一棵树，让网络能处理可变长度的输入
  4. 它保证抽出的样本两两独立，从而满足随机梯度下降的假设

为什么：优先级只在叶子上存一份，内部节点存子树的和， 于是"根节点即总优先级"、"按累积概率定位一条样本"和"改一条样本的优先级" 都能沿树走一条路径完成，代价都是 O(log N)。

A 描述的是"每次都取最大的几条"，那会让样本高度重复、缓冲区其余部分被浪费； 按概率抽样既照顾高误差样本又保留探索。C 是特征工程的另一回事。 D 做不到：PER 改变的是抽样分布，样本之间的相关性仍然存在。

5. 关于 PER 的实践，下列哪一种做法会伤害训练？

  1. 去掉常数 εp 只按 |δ| 排序，让高噪声样本被反复抽中
  2. 每算完一次 TD 误差，就把新的 |δ| 写回该样本的优先级
  3. 新样本一律以当前最大优先级入队，避免它长期抽不到
  4. 用 TD 误差算权重时按最大值归一化，稳定梯度的尺度

为什么：纯粹按 |δ| 排序时， 一个因为目标网络噪声而暂时误差很大的样本会被反复抽到，越抽越强化这个假信号； 加 εp 或改用 rank 优先就是为了压住这类尖峰。

B、C、D 都是正确做法：优先级要用最新算出的 TD 误差刷新；新样本给最大优先级 才不会还没被看过就被埋住；按最大权重归一化只是缩放梯度尺度，不改变相对比例。

代码题 1 · 把 TD 误差换算成采样概率与权重

背景优先回放按 TD 误差决定回放哪条转移：误差越大，采样概率越高， 值得重看的样本被抽中的机会就大。概率一改，梯度的期望就有偏，所以还要给每条样本 配一个重要性采样权重把它拉回来。这两个函数各做一件事：priority_probs 在算完一批 TD 误差之后调用，输出交给采样器；importance_weights 在抽出一批之后调用，权重乘到损失上。两个函数都不修改输入，只许用标准库与 numpy。

请实现 priority_probs(td_errors, eps=1e-5, omega=0.6) 与 importance_weights(probs, beta, normalize=True)。 签名与 starter 保持一致。

先补两句 numpy。数组就是一排数字的容器，"形状 (N,)"表示里面装 N 个数， 一维排开，下标从 0 数到 N-1。td_errors ** omega 这种写法叫逐项运算：对数组里每个数分别取 omega 次方，结果还是一个同形状的数组。

输入

  • td_errors：形状 (N,) 的 float 数组，每条转移最近一次的 TD 误差 δ，可正可负。
  • eps：float，默认 1e-5，式 (15.1) 里的 εp，加在 |δ| 上防止出现零概率。
  • omega：float，默认 0.6，优先级指数 ω，取 0 时退化成等概率采样。
  • probs：形状 (N,) 的 float 数组，和为 1 的采样概率，通常就是 priority_probs 的输出。
  • beta：float，式 (15.2) 里的 β，控制偏差修正的强度，0 表示不修正。
  • normalize：bool，默认 True，为真时把权重整体除以最大值。

输出

  • priority_probs 返回 np.ndarray，形状 (N,) 的 float，元素非负、和为 1：第 i 个元素是 P(i) = piω / Σk pkω，其中 pi = |δi| + eps。
  • importance_weights 返回 np.ndarray，形状 (N,) 的 float：第 i 个元素是 ρi = (1 / (N · P(i)))β；normalize=True 时再整体除以最大权重。

会被检验eps=0、omega=1 时严格按 |δ| 比例（[0, 1, 3, −2] 得到 [0, 1, 3, 2]/6）；omega=0 时退化成等概率；eps>0 时零误差样本也拿到非零概率；beta=0 时权重全为 1；归一化后最大值为 1，且各元素是未归一化结果的等比缩放；概率越大的样本权重越小；未归一化时每个 ρi·P(i) 都相等。

卡住了？看提示
  • eps 要在取幂之前加进去，否则误差为 0 的样本概率就是 0。 第一步先 p = np.abs(td_errors) + float(eps)， np.abs 对每个元素取绝对值。
  • 幂运算直接写 p ** omega，整型输入先转成 float。 归一化就是 powered / powered.sum()：.sum() 返回所有元素的和， 除号会对每个元素分别除一遍。
  • 权重里的 N 用 len(probs) 或 probs.shape[0]； normalize 为真时再除以 w.max()（.max() 返回最大值本身）。

代码题 2 · 用 sum-tree 按优先级采样

背景按优先级采样要从 N 个概率里反复取下标， 每抽一次都重算一遍前缀和是 O(N)：样本一多，这笔开销比一次网络前向还大。 sum-tree 把优先级放在完全二叉树的叶子上，父节点存子树之和， 抽样时从根往下每层比一次就知道该走哪边。这四个方法就是它的接口： __init__ 建空树，update 在 TD 误差更新后写回优先级， total 与 sample 供采样器调用。只许用 numpy， 每个方法都要 O(log N)。

这里说明数组的用法：self.tree 是一维 numpy 数组， tree[i] 取下标为 i 的那个数，tree[i] = x 直接把它改掉。 完全二叉树可以用数组存：根放在下标 1，下标 i 的孩子是 2*i 与 2*i+1。

输入

  • capacity：__init__ 的整数容量，能放多少条优先级，测试用到 4 和 5，不必是 2 的幂。
  • idx：update 的 0 基整数下标，范围 0 ≤ idx < capacity。
  • priority：update 的非负 float，覆盖该条原来的优先级。
  • value：sample 的 float，取自 [0, total()) 的均匀随机数。

输出

  • __init__：无返回值，建出一棵优先级全为 0 的空树。
  • update：原地修改，无返回值。
  • total：返回 Python float，所有优先级之和，空树为 0。
  • sample：返回 0 基 int 下标，指向累积区间包含 value 的那一条；第 i 条的区间是 [Σk<i pk, Σk≤i pk)，左闭右开，意思是左端点算在区间内、右端点不算。

会被检验空树的 total 为 0；容量 4 写入 [1, 0, 0, 3] 后 total 为 4，sample(0.0) 与 sample(0.99) 落在第 0 条，sample(1.0) 与 sample(3.99) 落在第 3 条；update(0, 100) 后 total 是 103 而不是 101（覆盖而不是累加），改回 1 后回到 4；容量 5 时 [1, 2, 3, 4, 0] 的 total 为 10，sample(2.5) 落在第 1 条；4000 个均匀 value 的下标频率与 pi / Σp 相差在 0.05 以内。

卡住了？看提示
  • 先把 self.size 取成不小于 capacity 的最小 2 的幂： 让 size = 1，再写一个 while size < capacity: size *= 2。 树数组长 2 * self.size，用 np.zeros(2 * self.size) 造全 0 数组。 第 idx 条放在 self.size + idx，根在下标 1。
  • update 先把 self.tree[self.size + idx] = float(priority) 写进叶子， 再令 i = (self.size + idx) // 2（// 是整数除法，向下取整）， 循环往上让 tree[i] = tree[2*i] + tree[2*i+1]，直到 i == 0 停下。
  • total 直接返回 float(self.tree[1])，根节点存的就是总和。
  • sample 从 i = 1 开始：只要 i < self.size 就往下一层走， 若 value < tree[2*i] 就往左走，否则先 value -= tree[2*i] 再往右走； 走到叶子时返回 int(i - self.size)，减掉偏移就得到原来的下标。
