进阶 · 第三部分 · 深度价值方法

Rainbow 与分布式 RL

只记一个平均分，丢掉的东西不少。这一节说明为什么要连整条分布一起学， 写出 C51（Categorical DQN with 51 atoms，51 个格点的分类 DQN）的类别投影， 以及用分位数（不预测一个平均值，而是预测"有 30% 可能不超过多少、70% 不超过多少"） 训练的 QR-DQN（quantile regression DQN）的损失，并判断 Rainbow 六个组件里 哪几个值得花时间。

你会得到

  • 能写出分布式贝尔曼目标，并说清"动作仍然按期望选"的原因
  • 能实现 C51 的投影算子，并解释它为什么能保住概率质量
  • 能说出 Rainbow 消融的结论，知道该按什么顺序给自己的模型加组件

只学期望丢掉了什么

前面所有算法学的都是回报（从此刻起一直走到结束，把每一步奖励加起来的总分）的期望。 期望是同一件事重复很多次之后的平均结果，Q(s,a) 就是这样一个数。

可同一个平均分背后，可能是完全不同的处境。举一个具体例子：动作 A 每次都稳定给 +1； 动作 B 九成的时候给 0，一成的时候给 +10。两者的期望都在 1 附近，风险却差一个量级。 业务上如果"一次大亏"比"平均收益"更要紧，只学一个平均分就把做决定需要的信息丢掉了。

要保住这些信息，就得学整条分布（回报可能取哪些值、每个值出现的可能性多大）。 这时候回报要当成随机变量（取值带随机性的量）来看，记作 Z(s,a)。分布式 RL（distributional RL，学整条回报分布的做法） 让它满足分布式贝尔曼方程（把这一步的分布和下一步的分布连起来的等式）， 英文写作 distributional Bellman equation：

Z(s, a) ≐ r + γ Z(s′, a′) (16.1)

式中 γ 是折扣因子（越往后的奖励，算进总分时权重越小，等于给它打了个折）， r 是即时奖励，≐ 读作"定义成"，表示左边就等于右边的意思。 γ 还是一个超参，就是需要你自己设定、而不是靠训练学出来的参数。

等号两边都是随机变量，有个后果容易被忽略：分布之间没有天然的"更大"， 所以贪心（在当前估计里挑看起来最好的那个）动作只能对期望取 arg max， 不能直接对分布取 max：

a* = arg maxa′ 𝔼[ Z(s′, a′) ]，   (TZ)(s, a) = r + γ Z(s′, a*) (16.2)

式中 𝔼 是期望（同一件事重复很多次之后的平均结果）， arg max 是挑出让后面那个式子最大的选择，(TZ) 读作"对 Z 做一次分布式贝尔曼更新"。 它改的是"学什么"，没有改"怎么选动作"（这套从状态挑动作的规则叫策略，就是出招习惯）。 想做风险敏感的决策（比如宁可少赚也不愿大亏），这种取舍叫偏好， 那就还得换目标函数，例如换成条件风险价值 CVaR。学出整条分布不会自动让做法变保守。

C51：把分布钉在固定格点上

分布是连续的对象，网络输出不了。C51 的做法最直接：在 [zmin, zmax] 上放 51 个等距的格点 zi = zmin + i·Δz（所以叫 C51）， 网络输出每个动作在 51 个格点上的概率。 𝔼[Z] = Σi pi zi 就是通常说的 Q 值。

难点在目标那一侧：r + γzj 常常落在两个格点之间， 直接当成 51 维标签会错位，所以先做类别投影（categorical projection， 把每个格点上的概率按距离分给左右相邻的两个格点）。 设 b = ( clip(r + γzj) − zmin ) / Δz， l = ⌊b⌋、u = min(l+1, N−1)，则

p̂l += pj (1 − (b − l))，   p̂u += pj (b − l) (16.3)

式中 ⌊b⌋ 读作"对 b 向下取整"，也就是不超过 b 的最大整数； b − l 是 b 离左邻居有多远，离得越远，分给左边那个格点的就越少。 两个权重加起来恒为 1，所以概率总量守恒，一个都不多、一个都不少。 损失把投影后的 p̂ 当成固定标签，对网络输出做交叉熵 （衡量两套概率分布差多远的一个常用指标），梯度不流过投影。 目标那一侧由目标网络（另存一份"稍旧"的网络专门用来算目标，隔一阵才同步一次） 给出。出自 Bellemare 等人的 A Distributional Perspective on RL（arXiv 1707.06887）。

QR-DQN：直接学分位数

C51 要你先猜 zmin 与 zmax：范围窄了分布被截断，宽了 51 个格点大半浪费。 QR-DQN（quantile regression DQN）换一种参数化： 固定 N 个分位点 τi = (i + 0.5) / N （τ 是分位点，也就是"有百分之多少的值不超过它"的那个位置）， 让网络输出这些分位点上的值 ẑτi， 用 pinball 损失（pinball loss，分位数回归损失）训练：

ρτ(δ) = max( τδ, (τ − 1)δ )，  δ = y − ẑτ，   L = (1/N) Σi 𝔼[ ρτi(δi) ] (16.4)

式中 δ（预测误差）是回报目标与分位数预测之差，ρ（分位数损失）是它的惩罚项， 𝔼 还是期望，Σ 是求和号（把后面那串东西全加起来）。 这个损失不对称：τ=0.9 时低估的惩罚是高估的 9 倍， 所以最小化它得到的那个常数，正好落在这组数据的 0.9 分位数上。 这就是"用回归的办法学分位数"的来历。相比 C51，它不必预先设定取值范围，也不用投影， 代价是要处理 N 个分位数之间的配对。训练目标同样靠自举 （用自己当前的估计去更新自己当前的估计，等于自己拽自己的鞋带往上提）算出来。 论文见 Distributional RL with Quantile Regression（arXiv 1710.05941）。

Rainbow：六个组件与消融结论

Rainbow 把六个组件合进一个 DQN： Double DQN、 Dueling、 优先回放、 多步（n-step）回报、C51 分布式价值，以及 Noisy Net。 网络权重上原本要加噪声，靠 ε-greedy 掷骰子决定要不要乱试一个动作。 ε 是探索率（每次决策有多大概率去随便试一个），Noisy Net 把这套机制换成 权重上的一份可学习噪声，省掉手写的 ε 衰减计划。合起来之后， Atari 上的中位数表现远超当时任何单项。

有工程价值的是它的消融结论（消融就是把组件一个个加上去或者拿掉，看各自贡献了多少）： 优先经验回放（抽样时优先抽误差大的那些，把走过的每一步都存进池子）与多步回报贡献最大， 分布式价值稳定有用，Noisy Net 最不稳定，去掉它常常只掉一点。它在这篇论文里写作 PER（prioritized experience replay）。加组件的顺序也是这个次序：先上优先回放与多步回报， 再上分布式价值，最后才是 Noisy Net。完整结果见 Hessel et al., Rainbow（arXiv 1710.02298）； 想扫一遍这族方法，读 Lilian Weng 的综述。

一次只加一个。组件会互相掩护错误：投影写错，可能被优先回放带来的高方差 （结果忽高忽低、波动很大）掩盖；Noisy Net 又让"策略一直随机"看起来像正常探索。 没有逐个消融，既不知道收益来自哪，也不知道该回退什么。

什么时候值得用它

  • 值得：你要"离散动作 + 高维状态"的强基线（够强够稳、可以拿来当比较标准的做法）， 愿意用 2–3 倍计算量换样本效率（拿到同样多的经验能学多好，效率高就是更省数据）， 或者除了平均回报还在意波动范围。
  • 不值得：状态空间（所有可能状态的集合）很小、有现成的表格解， 或者目标本身风险敏感，那得改目标函数，加组件没用。
  • 常见坑：格点与投影边界写错；多步回报叠加时折扣与 n 的处理出错；开了 Noisy Net 还指望策略最终收敛 （一轮轮算下去，数值不再明显变化，稳定下来了）成固定动作。

课后练习

1. 分布式 RL 与普通 DQN 在"学什么"上的根本差别是？

  1. 它同时维护多个 Q 网络，最后取这些网络输出值的平均值
  2. 它把折扣因子当成随机变量，训练时不断对 γ 做采样平均
  3. 它用多个目标网络轮流更新，从而降低自举带来的偏差
  4. 它学的是回报的整个分布，而不只是回报的期望值

为什么：普通 DQN 的输出是 Q(s,a) 一个数， 即 𝔼[Z(s,a)]；分布式 RL 的输出是一个分布， 期望只是这个分布的一个平均值。分布的宽度与形状本身就是风险信息。

A 描述的是集成（ensemble），与分布式价值无关。B 不对：γ 是给定的超参， 不是随机变量。C 描述的是多重目标网络，减少的是自举目标漂移， 和"学期望还是学分布"是两件事。

2. 分布式贝尔曼方程 (16.1) 里，动作该怎么选？

  1. 仍然按期望回报选动作，因为分布之间没有天然的序关系
  2. 按分布的上分位数选动作，以追求尽可能高的潜在回报
  3. 对每个原子的价值分别取最大值，再拼回一个新的分布
  4. 随机挑一个动作，让所有动作的分布被同等地更新到

为什么：两个分布无法像实数那样直接比较大小，贪心所需的 arg max 只能作用在期望上，也就是式 (16.2)。 分布式 RL 换掉的是学习目标，不是策略提取方式。

B 是在改目标函数（那才会得到风险偏好的策略），不是标准分布式 RL 的做法。 C 把原子当成独立动作，拼出来的量没有分布含义。 D 会让策略退化，与贪心策略提取矛盾。

3. C51 里的类别投影（式 16.3）在做什么？

  1. 把奖励裁剪到固定区间，避免不同任务的奖励尺度互相干扰
  2. 把网络输出的原子概率重新归一化，防止数值下溢到零
  3. 把 r + γz 落在格点之间的概率按距离分给相邻的两个原子
  4. 把回报分布压缩成一个期望值，从而复用原来的 DQN 损失

为什么：目标 r + γzj 通常不在 [zmin, zmax] 的格点上， 必须把它承载的概率质量搬到最近的格点上。式 (16.3) 用线性插值分配， 两个权重之和恒为 1，所以总质量守恒。

A 是奖励裁剪，属于预处理，与投影无关。B 是数值技巧，不是投影的目的。 D 与分布式 RL 的初衷相反：分布式方法要保住分布，不会压成期望。

4. QR-DQN 的 pinball 损失 (16.4) 学的是什么？

  1. 它直接回归分布的均值，因此等价于普通的均方误差损失
  2. 它回归若干条指定分位数的值，不必预先设定取值上下界
  3. 它把回报离散成固定的原子格点，再用交叉熵逐格回归
  4. 它最小化预测分布与目标分布之间的 Kullback–Leibler 散度（KL）作为训练目标

为什么：pinball 损失不对称，τ=0.9 时低估的代价是高估的 9 倍，其最小点正好是该分布的 0.9 分位数。 于是网络输出的是分位数本身，不需要 zmin / zmax 这些先验设定，也不用做投影。

A 只在 τ=0.5 时成立，那时它才等于绝对误差的一半， 与均方误差仍然不同。C 描述的是 C51 的做法。D 也不是 pinball 损失的性质。

5. Rainbow 的消融实验给出的一条工程启示是？

  1. 六个组件必须同时打开，单独使用其中任何一个都完全没有效果
  2. 分布式价值的贡献最大，其次才是优先回放与多步回报这两项
  3. Noisy Net 的贡献最大，所以最该优先替换 ε-greedy
  4. 各组件贡献不均：优先回放与多步回报最有用，所以要逐个消融

为什么：Rainbow 的消融显示 PER 与多步回报的贡献最大， 分布式价值稳定有用，Noisy Net 的收益最不稳定。因此合理的加组件顺序是 PER/多步 → 分布式 → Dueling → Noisy Net，而且每加一个都要单独验证。

A 与结论相反：单个组件本身大多有效，组合只是叠加。 B 把分布式价值排到了最前，与消融结果不符。 C 高估了 Noisy Net：它是最不稳定的一项。

代码题 1 · 实现 C51 的类别投影

背景C51 的网络输出是每个动作在 n 个固定格点上的概率， 每个格点叫一个原子。目标那一侧还要按分布式贝尔曼方程把 r + γzj 搬回同一组格点上，这件事由类别投影完成 （式 16.3）：每个格点上的概率按距离分给左右相邻的两个格点，总概率不变。 投影结果被当成训练的固定标签，梯度不流过它。c51_projection 在目标网络对 s′ 输出概率之后调用，输出直接与在线网络的输出做交叉熵。 只许用 numpy，不修改输入。

请实现 c51_projection(rewards, dones, next_probs, support, gamma)。 签名与 starter 保持一致。

补几句 numpy 与概率。数组就是一排数字的容器，形状 (B, n) 表示 B 行、每行 n 个数。rewards[:, None] 把形状 (B,) 变成 (B, 1)，再和形状 (n,) 的 support[None, :] 一起运算时，numpy 会自动把两边铺开对齐， 这个规则叫广播，结果形状是 (B, n)。np.clip(x, lo, hi) 返回一个新数组，里面每个元素都被压到 [lo, hi] 区间内。 概率分布就是一组非负、加起来等于 1 的数，这里每一行都是一个分布。

输入

  • rewards：形状 (B,) 的 float 数组，即时奖励。
  • dones：形状 (B,) 的 bool 数组，True 表示该条在 s′ 终止，不再往后看。
  • next_probs：形状 (B, n) 的 float 数组，目标网络在 n 个格点上给出的概率，每行和为 1。
  • support：形状 (n,) 的 float 数组，等距递增的格点 z0 < z1 < … < zn−1，相邻间隔记作 Δz。
  • gamma：float，折扣因子 γ。

输出

  • 返回 np.ndarray，形状 (B, n) 的 float：第 i 行是搬移之后的格点概率，第 j 个分量是落在格点 zj 上的概率，每行和为 1 且元素非负。

会被检验输出形状为 (B, n)；每行概率和为 1 且非负（200 行随机输入下最大偏差不超过 1e-10）；终止样本的目标只剩 r（如 Tz = 0.3 时格点 0、1 拿到 0.7 与 0.3）；Tz 超过最大格点或低于最小格点时裁剪到两端且概率不丢；恰好落在格点上时概率全给该格点；多峰分布逐格点搬运后总量仍然守恒。

卡住了？看提示
  • 形状对齐：把 rewards[:, None] 和 support[None, :] 一起广播成 (B, n)，算出 tz = rewards + gamma * (~dones)[:, None] * support。 ~dones 把布尔值取反，[:, None] 再把它变成一列参加广播。
  • 裁剪与定位：先 tz = np.clip(tz, support[0], support[-1])； 格点间距 delta = support[1] - support[0]； 位置 b = (tz - support[0]) / delta； 左格点 l = np.floor(b).astype(np.int64)（np.floor 返回向下取整的结果）； 右格点 u = np.minimum(l + 1, n - 1)。
  • 权重：upper = b - l 是分给右邻居的比例，lower = 1 - upper 分给左邻居。
  • 写回用 np.add.at(proj, (rows, cols), mass)。同一行里可能有多个格点搬到同一个目标格点上， 用 proj[rows, cols] += mass 这种写法会丢掉重复的贡献，np.add.at 才逐条累加。 行号用 rows = np.repeat(np.arange(B), n) 铺成 B*n 个。

代码题 2 · 实现 pinball 损失与梯度

背景QR-DQN 让网络输出若干个分位数值，用 pinball 损失训练。 这个损失对偏差的方向不对称：tau = 0.9 时低估的代价是高估的 9 倍， 所以最小化它得到的那个常数，就落在 0.9 分位数上（分位数就是"有百分之多少的值不超过它" 的那个位置）。两个函数在训练步里配套使用：pinball_loss 算损失值， pinball_grad 给出它对网络输出 predictions 的梯度， 手写的 numpy 反向传播要用后者。都不修改输入，只许用 numpy。

请实现 pinball_loss(predictions, targets, taus) 与 pinball_grad(predictions, targets, taus)。 签名与 starter 保持一致。

输入

  • predictions：float 数组，网络输出的分位数值。
  • targets：float 数组，回报目标 y，形状与 predictions 相同或可广播成同一形状。
  • taus：形状 (n,) 的 float 数组，分位点 τ，与最后一维对齐，同一个 τ 作用到那一列。

输出

  • pinball_loss 返回 Python float：先按 δ = targets − predictions 逐元素算 ρτ(δ) = max(τδ, (τ−1)δ)，再对所有元素取平均。
  • pinball_grad 返回 np.ndarray，形状与广播后的结果相同：第 (i, j) 个元素是平均损失对 predictions[i, j] 的偏导，δ > 0 时为 −τ / 总元素数，δ < 0 时为 (1 − τ) / 总元素数，δ = 0 处为 0。

会被检验tau=0.5 时 +2 与 −2 的偏差代价相同；tau=0.9 且偏差为 1 时低估罚 0.9、高估只罚 0.1；四个元素的手算值与逐元素取法一致；解析梯度与中心差分数值梯度在 1e-6 内一致，中心差分就是给某个输入加一个极小量、再减一个极小量，用两次损失值之差去近似导数；梯度形状与广播结果一致；在 1 到 10 的样本上扫常数，tau=0.85 时平均损失最小的常数落在 9 附近。

卡住了？看提示
  • 先算偏差 d = np.asarray(targets, dtype=float) - np.asarray(predictions, dtype=float)； 形状不一致时先用 np.broadcast_to(..., predictions.shape) 铺成同一个形状。 max 的两个分支可以一次写完：np.maximum(tau * d, (tau - 1.0) * d)， 它逐元素返回两个数组里较大的那个。
  • 损失不必写 Python 循环：float(np.mean(loss)) 就够， np.mean 返回所有元素的平均值。
  • 梯度用 np.where(d > 0.0, -taus, 0.0) + np.where(d < 0.0, 1.0 - taus, 0.0)， np.where(条件, A, B) 逐元素挑选。最后除以元素总数 d.size， 因为损失取的是平均而不是求和。

六组件组合与完整消融表：Hessel et al., Rainbow: Combining Improvements in Deep RL， arXiv 1710.02298（Figure 5 与 Table 1 就是"哪个组件最有用"的直接证据）。综述视角见 Lilian Weng 的 DQN 综述； 速查表条目见 算法速查表 · Rainbow。
