进阶 · 第四部分 · 策略梯度与 Actor-Critic

优势估计 GAE 与 TRPO

这一节有两个落点：用一段倒序循环算出一组优势（在某个状态下，选这个动作比"平均水平"好多少，也就是你这一步比常规走法强多少），再给更新幅度加一道限速。 限速这件事在策略梯度（不绕道去估价值，直接算参数往哪调能让拿到的总分更高）里必须做， 不做就可能一次把整套做法推废。

你会得到

  • 能写出 GAE 的反向递推，并说出 λ（GAE 衰减参数）=0 与 λ=1 各退化成什么
  • 能解释 GAE 的 λ 如何在偏差与方差之间滑动
  • 能说清 TRPO 的代理目标与 KL 约束，以及它为什么昂贵

第一步：把 n-step 的两端一次平均掉

0018 课留下一个选择题。策略（一套"看到什么状态就选什么动作"的规则） 每往前走一步，都想知道"这一步走得好不好"。δ（TD 误差）是只往前看一步的估计， 偏差大。用整条回报（从现在起一直到结束，把每一步奖励加起来的总分）是另一端，方差大。 中间还有 2 步、3 步、10 步，每个 n 都是一组不同的偏差与方差配比。

挨个试太笨。广义优势估计（generalized advantage estimation, GAE） 的办法是把这些档位一次性加权求和：越近的误差权重越大，越远的权重按比例缩小。 写成式子就是：

AtGAE(γ,λ) = Σl=0∞ (γλ)l δt+l,    δt = Rt+1 + γVφ(St+1) − Vφ(St) (19.1)

式中 Vφ 是 critic（打分的那一方，负责估计局面值多少分）给出的价值估计， 也就是状态价值（只看状态、不管具体选哪个动作的那个价值）， 而它是价值函数（从某个状态出发，按某套策略走下去，平均能拿多少总分）本身。 γ 是折扣因子（越往后的奖励，算进总分时权重越小，等于给它打了个折）， λ 是 GAE 的衰减参数，控制"往前看多远"。下标表示"第几步"： δt+l 是第 t+l 步的 TD 误差。

思路不算新：0011 课的 TD(λ)（用同样的加权方式平均各档 n-step 回报） 做的就是这件事，GAE 只是把它搬到优势上。注意两个端点：

  • λ = 0：只剩第一项，At = δt， 低方差、高偏差，就是 0018 的一步 actor-critic。
  • λ = 1：无穷项相加会望远镜式相消，得到 At = Gt − Vφ(St)， 即蒙特卡洛（把一整局走完，用真实拿到的总分来估计价值）优势， 偏差小但方差大。

实践中 λ ≈ 0.95 是常见折中：把远期项压掉大部分方差， 又保留足够的真实奖励信息。λ 和 γ 是乘在一起的，调参时别只动一个。

第二步：用一遍倒序循环算出来

先认一个词。自举（用自己当前的估计去更新自己当前的估计，等于自己拽自己的鞋带往上提） 指的是 TD 误差里那一项 critic 自己的预测。

直接按定义求和，工作量随轨迹长度平方增长，记作 O(T²)（T 是这一段的步数）。 把 (19.1) 写成递推，工作量只随长度线性增长，记作 O(T)：

At = δt + γλ(1 − donet) At+1 (19.2)

从轨迹末尾往前扫一遍即可，这就是"倒序"的来历。两个实现要点：done 为真时要同时 切断 δt 里的自举和 (19.2) 的递推，只切一处是最常见的 bug； 轨迹末尾那一步需要环境的 bootstrap 值 Vφ(ST)， bootstrap 就是刚才说的自举，这里指"拿 critic 的预测把最后一段补齐"。

第三步：为什么一步走太大就废了

策略梯度是 on-policy（边学的那套策略，就是正在用来产生数据的那套）的：数据来自当前策略。 如果一步更新太大，策略可能被推进一个动作分布完全不同、回报极差的区域， 于是接下来采到的全是坏数据，再也爬不回来。

问题不在收敛（一轮轮算下去，数值不再明显变化，稳定下来了）慢。 策略塌缩之后无法自愈，这才是 TRPO 存在的理由。

信赖域（规定这一步只允许在"离旧策略不太远"的范围内改，每次只许挪一小步） 这一类方法把"更新别太大"写成一个约束。 它优化的是一个只在旧策略附近才可信的 代理目标（surrogate objective），那个真实目标只能被它近似：

maxθ 𝔼[ ( πθ(a|s) / πold(a|s) ) At ]   s.t.   𝔼[ KL( πold ‖ πθ ) ] ≤ δKL (19.3)

式中 π 是策略分布，θ 是策略参数。πθ/πold 这一项叫 概率比（新策略选中这个动作的概率，除以旧策略选中它的概率）。 它来自重要性采样（用另一套策略产生的数据，来估计当前策略的表现，需要按概率比例做修正）： 数据是旧策略采的，要拿它估新策略，就得乘上这个比值。 比值离 1 太远时估计就不可信，所以约束必须存在。

为什么要用 KL 散度（Kullback–Leibler divergence, KL） 而不是参数空间的距离？决定行为的本来就是策略输出的分布： 同一个参数步长，在 logits（神经网络输出的、还没变成概率的那组原始分数）很小的时候 几乎不改变动作概率，在 logits 很大的时候能让策略整体换掉。 KL 直接度量"行为变了多少"，比参数范数贴近问题。

TRPO 的代价，以及该不该用它

TRPO（trust region policy optimization）把 (19.3) 的约束做成 二阶近似：用 Fisher 向量积（Fisher-vector product） + 共轭梯度（conjugate gradient）求出更新方向， 再做 线搜索（line search），逐步缩小步长直到约束满足且代理目标真的提升。 正确，但每一步都要多算几次 Fisher 向量积，且和 dropout（训练时随机关掉一部分神经元）、参数共享这类实现细节冲突。

工程上的结论很干脆：GAE 几乎总值得单独拿来用，即使你最后选 0020 课的 PPO（proximal policy optimization，近端策略优化）。而 TRPO 本身只在"你确实需要更新不会变差这个强保证、 并且不在意实现复杂度"时才选。想让每批数据多跑几轮又不想写二阶优化，PPO 用裁剪买到了近似效果。

症状先查什么
优势量级随轨迹长度暴涨λ 太接近 1，或 γ 太接近 1 又没做优势归一化
KL 很快超过上限学习率（每次更新时往新信息的方向挪多远）太大
KL 每轮都超阈值、线搜索几乎总在缩步δKL 设得太小，或学习率本身过大

课后练习

1. GAE 中 λ=0 与 λ=1 分别退化为什么？

  1. 前者退化为蒙特卡洛优势，后者退化为单步 TD 误差
  2. 前者退化为单步 TD 误差，后者退化为回报减去状态价值
  3. 前者与后者都退化为单步 TD 误差，只是相差一个常数倍
  4. 前者与后者都退化为蒙特卡洛优势，只是相差一个常数倍

为什么：λ=0 时 (19.1) 只剩 l=0 一项，就是 δt；λ=1 时无穷级数望远镜相消，得到 Gt − Vφ(St)， 即蒙特卡洛优势。

A 把两端说反了；C 与 D 都错在"只差常数倍"：两端是两种不同的估计量， 不只是尺度不同。

2. 关于 GAE 的 λ 与偏差-方差权衡，下列说法正确的是？

  1. λ 越大越接近蒙特卡洛：偏差更小、方差更大
  2. λ 越大越接近单步 TD：偏差更小、方差更大
  3. λ 越大越接近蒙特卡洛：偏差更大、方差更小
  4. λ 越大越接近单步 TD：偏差更大、方差更小

为什么：λ 越大，远处 TD 误差的权重保留得越多， 自举的成分越少，估出来的优势越像真实回报减价值，偏差下降、方差上升。 常用 λ≈0.95 就是在往方差那一端稍微让一点。

B 与 D 把方向说反：λ 大是远离单步 TD 而不是靠近它。 C 把代价说反：更接近蒙特卡洛意味着方差更大，不是更小。

3. TRPO 用 KL 约束而不是限制参数更新的欧氏距离，主要理由是？

  1. KL 的计算比参数范数便宜，能省下大量反向传播开销
  2. 参数范数在这种情况下根本无法定义，因为参数量太大
  3. KL 直接度量策略行为的改变，同样步长可能改变很多
  4. KL 约束能保证每次更新都精确提升真实目标无需近似

为什么：决定采样分布的是策略输出的概率，不是参数的数值。 同样的参数步长，在输出很尖时会把动作概率整体改写，在输出很平时几乎没变化； KL 度量的就是概率分布移动了多少。

A 说反了，KL 的二阶近似反而更贵；B 不成立，参数范数当然可以定义， 只是它与行为变化不成比例；D 过度承诺，代理目标与 KL 都只是近似， 单调改进只是理论结论而非精确保证。

4. 为什么策略梯度必须关心"一步更新走多大"？

  1. 因为学习率必须严格小于 1，否则梯度上升在数学上不收敛
  2. 因为采样分布随策略变化，坏更新之后很难再采到好数据
  3. 因为价值函数的估计误差会随步长指数增长，最终导致自举发散
  4. 因为概率比在数值上必须始终等于 1，否则重要性采样失效

为什么：on-policy 方法只能从当前策略诱导的分布里采样。 一步过大把策略推进低回报区域后，采到的数据都来自这个坏策略， 梯度里再也没有"好行为"的信号，于是无法自愈。

A 没有依据，学习率小于 1 既非充分也非必要；C 把策略问题说成了价值问题； D 与事实相反：概率比本来就会偏离 1，约束它别偏太远才是重点。

5. 关于 TRPO 的实现成本与选用，下列哪一项符合本课结论？

  1. 它只需要一阶梯度，因此比 PPO 更容易实现和调参
  2. 它完全不需要线搜索，因为 KL 约束已保证目标提升
  3. 它适用于任何情况，包括参数共享与 dropout 的结构
  4. 它需要共轭梯度与线搜索，成本高；多数场景用 GAE 加 PPO

为什么：TRPO 要用 Fisher 向量积与共轭梯度构造二阶方向， 再靠线搜索把步子缩进信赖域；实现复杂、每步都贵。 所以常见组合是"GAE 估优势 + PPO 做更新"。

A 说反了，TRPO 的麻烦之处在于它不止一阶；B 错在线搜索是它的必需品； C 与事实相反，TRPO 与 dropout、参数共享等实现细节冲突。

代码题 1 · 反向递推算 GAE 优势

背景GAE 把每一步的单步 TD 误差按指数权重混合起来，给 actor 一个偏差与方差都能调的优势估计。它接在 critic 算出价值之后、actor 更新之前被调用一次，用一段轨迹上全部的 δ 从末尾往前递推，于是后面几步的信息会以衰减的权重传回前面。返回的 At 就是策略梯度里乘在 ∇log π 上的那个权重。

请实现 compute_gae(rewards, values, next_values, dones, gamma, lam)，只用标准库加 numpy。

输入

  • rewards：形状 (T,) 的 float 数组（形状指这个数组有几行几列，(T,) 就是 T 个数的一维数组，下标从 0 开始），第 t 项是奖励 rt。
  • values：形状 (T,) 的 float 数组，第 t 项是 V(st)。
  • next_values：形状 (T,) 的 float 数组，第 t 项是 V(st+1)。
  • dones：形状 (T,) 的布尔数组，第 t 项为 True 表示回合在 t 结束，递推在这里切断。
  • gamma：Python float 标量，折扣因子 γ（越往后的奖励，算进总分时权重越小，等于给它打了个折）。
  • lam：Python float 标量，GAE 的 λ，取值 0 到 1：取 0 只看一步，取 1 接近看完整局。

输出

  • 返回形状 (T,) 的 np.ndarray：第 t 项是式 (19.4) 的 At = δt + γλ(1 − donet)At+1，递推从最后一步往前，超出末尾的 A 按 0 计。
At = δt + γλ(1 − donet) At+1,    δt = rt + γ(1 − donet) V(st+1) − V(st) (19.4)

会被检验测试会检查 lam=0 时逐项等于 δ、lam=1 时等于蒙特卡洛优势 Gt − V(st)、中间取值等于 Σl(γλ)lδt+l；还会用一段带 done 的短轨迹检查终止步切断递推，优势不跨终止步往后传。

卡住了？看提示
  • 先取 T = len(rewards)，再准备一个长度为 T 的数组 adv = np.zeros(T)（np.zeros(T) 返回一个装了 T 个 0 的数组），以及一个变量 last = 0.0 记 A_{t+1}。
  • 用 for t in range(T - 1, -1, -1) 从最后一步倒着扫到第 0 步。
  • 先算 delta，再写 A[t] = delta + gamma*lam*(1-done)*last。
  • 终止那一步既要让 delta 不含自举，也要让递推不再往回合外延伸。

代码题 2 · 算 TRPO 的代理目标、KL 与线搜索

背景TRPO 每轮更新要在旧策略附近挑一步：代理目标要涨，同时别离旧策略太远。训练循环先用 surrogate_objective 估目标，再用 mean_kl 与 trpo_line_search 挑出可接受的候选。old_probs 是采集这批数据时用的行为策略。

请实现三个函数，只用标准库加 numpy：surrogate_objective(old_probs, new_probs, advantages)、mean_kl(old_probs, new_probs) 与 trpo_line_search(old_probs, candidates, advantages, delta_kl)。

输入

  • old_probs：形状 (N, n_actions) 的 float 数组，每行和为 1，是旧策略 πold。
  • new_probs：形状 (N, n_actions) 的 float 数组，每行和为 1，是待评估的新策略。
  • advantages：形状 (N, n_actions) 的 float 数组，第 (i, a) 项是状态 i 上动作 a 的优势。
  • candidates（trpo_line_search）：形状 (K, N, n_actions) 的 float 数组，每行和为 1，是 K 个按步长递增的候选。
  • delta_kl（trpo_line_search）：Python float 标量，本轮允许的平均 KL 上限。

输出

  • surrogate_objective 返回 Python float：式 (19.3) 的代理目标 meaniΣa(πnew/πold)·A·πold。
  • mean_kl 返回 Python float：meaniΣaπoldlog(πold/πnew)，按 N 取平均。
  • trpo_line_search 返回 Python int：第一个 KL 不超过 delta_kl 且代理目标不下降的候选下标；没有合格候选返回 -1。

会被检验测试会核对旧策略对自身时的代理目标、相同分布的 KL 为 0、交换参数后 KL 不相等，KL 按 N 取平均；线搜索在阈值 0.02 时跳过前两个候选返回 2，阈值 1e-9 或候选目标都更差时返回 -1。

卡住了？看提示
  • ① 里 πold 会被约掉，实现时可以直接算 mean(sum(new_probs * advantages, axis=-1))；但请按比值写一遍，理解它从哪来。
  • 旧策略自身的代理目标就是 mean(sum(old_probs * advantages, axis=-1))。
  • KL 与代理目标都对样本取平均（axis=-1 求和后再 mean）。
