函数逼近与致命三元组

前面几课的算法都假设"每个状态动作对一个格子，记下来就行"。 真实问题的状态太多，这张表根本列不完。这一节说清两件事： 怎么用一套参数去替代表格，以及为什么把"参数化"和前面两个习惯凑在一起会变得不安全。

你会得到

  • 能说出表格法在连续状态与泛化上的两个硬伤
  • 能解释半梯度与"真梯度"的差别，以及线性逼近为什么便宜
  • 能背出致命三元组的三项，并说出 DQN（deep Q-network，深度 Q 网络）的两件装备各修哪一环

表格法的天花板

到第 0010 课为止，所有方法都默认 Q 是一张表： 每个 (s,a) 一个格子。这个假设在三种现实面前立刻塌掉。

  • 状态是连续的。库存水位、价格、温度、用户停留时长，取值有无穷多个，格子列不完。
  • 就算能离散化，维度也是指数级涨的。10 个维度各分 10 档， 就是 1010 个格子（10 后面跟着 10 个 0）。
  • 更麻烦的是表格法不会泛化（在没见过的状态上也能给出靠谱的估计）。 它只更新被访问过的那一个格子，没人去过的格子永远停在初始值； 而真实系统里，绝大多数状态是没见过的。

还有一件事要顺手分清：状态转移（你做完动作之后，环境从当前状态跳到下一个状态） 在现实里往往是随机的，同一个动作可能跳到好几个地方。这一点后面还会用到。

出路是函数逼近（状态太多记不下整张表，干脆用一个带参数的函数去"猜"价值）： 用一套参数 w 和一个特征（把原始状态加工成一组数字，供函数使用）提取器 x(s)，把状态直接映射成一个估计值 v̂(s;w)。

记号读一遍。x(s) 表示"把状态 s 加工成的那组数字"； v̂(s;w) 里那个小尖帽读作"估计"， 整体意思是"用参数 w 算出来的、对状态 s 值多少分的估计"。 这样一来，一个状态上的学习会自动扩散到相似状态上， 这就是"每个状态一个数"换成"一套参数加一组特征"得到的好处。

半梯度 TD：少算了哪一项

把 TD(0) 的更新搬到参数空间之前，先把三个词说清。 梯度（往哪个方向调参数能让误差下降最快）； 自举（用自己当前的估计去更新自己当前的估计，等于自己拽自己的鞋带往上提）； 策略（一套"看到什么状态就选什么动作"的规则）。

有了这三个词，做法就一句话：拿自举带来的误差去乘梯度。

式 (12.1) 里的 ∇w 读作"对参数 w 求梯度"， 也就是"往哪个方向调 w，估计值上升得最快"；← 读作"更新为"。 价值函数（从某个状态出发、按某套策略走下去，平均能拿多少总分）在这里被换成了 v̂(s;w)，一个由参数 w 算出来的近似值。

w ← w + α δt ∇w v̂(St;w),   δt = Rt+1 + γ v̂(St+1;w) − v̂(St;w) (12.1)

式中 α 是学习率（每次更新时往新信息的方向挪多远）， γ 是折扣因子（越往后的奖励，算进总分时权重越小，相当于给它打了个折）， δ 是 TD 误差（这一步的目标减去当前的估计）。

这叫半梯度（更新时只对"预测的那部分"求梯度，对"目标那部分"当常数看）TD， "半"字的来源是它刻意少算了一半： 如果真把 δ2 当损失对 w 求梯度， 目标里那个 v̂(St+1;w) 也含 w， 求导会多出 −γ∇wv̂(St+1;w) 这一项。 半梯度假装目标是常数，只对 v̂(St;w) 求导。

这不是偷懒。真梯度法在自举目标下需要知道转移概率 （这一步动作之后跳到哪，有好几种可能，每种各带着自己的概率）， 而且它优化的并不是我们要的东西；半梯度虽然"不完整"，但时序差分 （不用等到一局结束，用"走一步之后的新估计"来更新"走这一步之前的估计"） 能在无模型条件下工作，靠的就是它（S&B 第 9.3 节）。 线性情形最能看清成本：v̂(s;w) = w · x(s)， 梯度就是 x(s)，更新变成 w ← w + α δ x(St)， 一次向量加法，和表格法一样便宜。

特征怎么造

  • 粗编码（把每个维度切成若干互相重叠的小段，落在同一段里的状态共用同一份权重）， 也叫 tile coding。可以想成给一整条数轴盖上一叠错开的网格：相邻的位置会落在 好几个相同的格子里，于是它们自动共享经验。没访问过的状态只要与访问过的同段， 立刻就有了合理的值。这是实践里最常用的一种。
  • 多项式特征：x(s) = [1, s, s², …]。 它的曲线很光滑，但把同一个公式用到训练区间之外，高阶项会迅速变成很大的数。
  • 傅里叶基（Fourier basis）：适合拟合光滑函数，频率成分可以逐档控制。

关键直觉：泛化是双刃剑。粗编码让没去过的状态也有值（好）， 但把同一套参数用到训练分布之外，输出的值可能毫无意义（坏）。 下一道代码题会让你亲眼看到这件事。

致命三元组

S&B 把下面三件事同时出现的情形称为 致命三元组（deadly triad，三件事凑在一起会出事）：

  1. 函数逼近（用一个带参数的函数替代表格）
  2. 自举（拿估计去更新估计）
  3. 用 off-policy（边学的那套策略不是产生数据的那套，数据来自另一套旧策略）的方式训练

单独看每一件都没问题，凑齐之后就不再有稳定学好的保证。 收敛（一轮轮算下去，数值不再明显变化，稳定下来了）说的就是这件事。 下面这张表列出几种组合，表里有两个词先说清： 蒙特卡洛（把一整局走完，用真实拿到的总分来估计价值）； 回报（从现在起一直到结束，把每一步奖励加起来的总分）。 去掉任意一件都安全：

组合结果
表格法 + 自举 + off-policyQ-learning，收敛（第 0010 课）
函数逼近 + 自举 + on-policy线性 SARSA(λ)，通常可用（第 0011 课）
函数逼近 + off-policy + 不自举蒙特卡洛式的回报回归，也还行

失败长什么样：权重数值一路膨胀到 inf；价值曲面被"扫"成一条完全错误的直线； 策略在训练中期突然锁死。这三种症状在真实项目里都出现过。

为什么会这样，以及 DQN 怎么修

off-policy 意味着训练数据的分布（这批数据偏向哪些情况）跟行为策略实际访问到的状态 跟目标策略将要访问的不是同一批。函数逼近又把这个状态上的更新扩散到整个邻域： 如果你恰好用错误分布上的误差去反复修正目标策略才关心的区域，误差就会被放大； 自举又提供了让误差自我循环的路径。两件事叠加，误差可以越滚越大。

DQN 加的两件工程装备，正好各自对付其中一个环节。 经验回放（把走过的每一步都存进一个池子，训练时从池子里随机抽一批出来用） 把高度相关的在线样本打散成近似独立同分布的批次，削弱"分布漂移 + 样本相关"的放大效应， 同时让每条样本被复用很多次。 目标网络（另存一份"稍旧"的网络专门用来算目标，隔一阵才同步一次，避免追着自己跑） 把自举目标固定一段时间，让"追逐一个同时在动的靶子"变回"回归一个短期不动的靶子"。 这两件事在 0013 课展开。

最后把几个会在练习里露面的词分清。 策略评估（给定一套策略，算出它到底值多少分）； 策略改进（根据算出的分数，把策略里明显吃亏的选择换掉）； 策略迭代（反复"打分 → 改招"，直到改不动为止）。 它们在别的算法里是一整套循环，这里只借名字做对照。

再补三个。随机策略（不挑好坏、纯靠概率乱选动作的规则）； 重要性采样（用另一套策略产生的数据来估计当前策略的表现，需要按概率比例做修正）； 探索率（每次决策时，有多大比例的概率去做"随便试一个"）。

三个诊断信号。权重爆炸成 inf 或 NaN（not a number，非数），先归一化特征、再降学习率； 训练区间内拟合不错但上线后预测离谱，多半是外推，先确认推理时的状态是否落在训练分布内； 训练损失在降而真实回报不涨，说明特征表达力不足，或者你在 off-policy 下用一个被污染的目标做拟合。

课后练习

1. 与函数逼近相比，表格法最根本的局限是什么？

  1. 每个状态动作对都要独立估计，没访问过的状态无法泛化
  2. 它无法处理随机性的环境，只能用于确定性的状态转移过程
  3. 它必须使用完整回合的数据，因此不能做单步的增量式更新
  4. 它的存储开销随动作数线性增长，动作一多就会耗尽内存

为什么：表格法把每个 (s,a) 当作互不相干的参数， 学到的东西不会迁移到别的状态上。状态连续或者维度一高，需要访问的格子数就爆炸， 而没被访问过的格子永远是初始值。函数逼近用共享参数解决的就是这一点。

B 与随机性无关，表格法处理随机环境毫无问题。C 说反了：TD 类方法用的就是单步增量更新， 表格法完全可以。D 是真实存在的代价，但存储通常不是先崩的那一环，泛化能力才是。

2. 半梯度 TD 与"真正的梯度下降"差在哪里？

  1. 它不调整学习率，而是固定用访问次数的倒数来做加权平均
  2. 它把自举目标当成常数，忽略了目标里对参数的那一部分梯度
  3. 它每次只用一条样本来更新，而真梯度每步要用一整个批次
  4. 它对奖励做了归一化处理，因此不再是无偏的参数更新规则

为什么：式 (12.1) 里目标 Rt+1 + γv̂(St+1;w) 也依赖 w，真梯度会多出一项 −γ∇wv̂(St+1;w)。 半梯度直接把它丢掉了，而 TD 不需要环境模型就能工作，靠的就是这份"不完整"。

A 说的是一种步长调度，与梯度定义无关。C 说的是批量大小，不是梯度的差别。 D 与奖励归一化无关，而且半梯度并不是无偏的，这就是它的代价。

3. 致命三元组指的是哪三件事同时出现？

  1. 探索策略、利用策略与折扣因子这三者同时出现在一次决策里
  2. 策略评估、策略改进与策略迭代这三步循环同时被反复调用
  3. 函数逼近、自举与 off-policy 训练三者同时被使用
  4. 经验回放、目标网络与 ε（探索率）衰减这三个工程技巧同时被启用

为什么：单独任意两项都有收敛结论，三项凑齐后现有的理论保证就消失了。 这也是为什么"用神经网络 + Q-learning + 回放缓冲区"必须额外加防护， 而表格 Q-learning 却可以放心用。

A 是 MDP（马尔可夫决策过程，就是"下一个状态只看现在、跟更早的历史无关"的那类问题设定）的基本要素，B 是动态规划的算法骨架，两者都不是危险性来源。 D 恰好相反：那三个技巧是缓解三元组后果的工程手段，不是问题本身。

4. 为什么 off-policy 与函数逼近放在一起会放大误差？

  1. 因为 off-policy 必须做重要性采样，而它会放大估计方差
  2. 因为 off-policy 不能自举，只能等回合结束再更新
  3. 因为目标策略是随机的，而随机策略的参数梯度本身就是有偏的
  4. 行为策略访问到的状态分布与目标策略要评估的分布并不一致

为什么：你在用一批来自行为策略的状态去拟合目标策略的价值， 两个分布不同；函数逼近又把这个状态上的误差扩散到整个邻域。 于是错误分布上的误差会被反复投影、放大，再通过自举循环回自己身上。

A 只在某些 off-policy 方法里成立，Q-learning 并不需要重要性采样。 B 说反了：off-policy 的自举是 Q-learning 的特点。 C 与目标策略是否随机无关，这里的关键是状态分布不匹配。

5. 参数化的价值函数在训练区间之外，通常表现为哪种行为？

  1. 平滑地延伸到无穷远处，单调逼近真实的长期价值
  2. 给出与最近训练数据接近的常数，或者毫无规律的乱跳值
  3. 自动回落到零，因为参数在没有数据的地方不会被更新
  4. 保持训练区间内的最大值，直到状态重新回到训练区间内

为什么：参数只被训练数据约束过，区间之外是什么样完全由函数形式决定。 线性或粗编码在远处通常给出一个常数（最后一个被激活的权重）， 多项式则会迅速发散，而取模哈希的 tile coding 会直接"绕回"训练过的区域。

A 是一种常见的错觉：没有任何机制保证单调外推。C 错，参数不会因为"没有数据"就自动归零。 D 也没有依据，超出区间时的输出与区间内的最大值之间没有必然关系。

代码题 1 · 用线性特征实现半梯度 TD(0)

背景从本课起价值函数不再是一张表格，而是由一套参数 w 和特征 φ(s) 算出来的函数。 半梯度 TD(0) 把式 (12.1) 的更新搬到参数空间，是函数逼近下做策略评估的最小单元。 这个函数对一条已经采好的轨迹扫一遍，被训练循环调用一次就更新一次 w； 输入是这条轨迹每一步的状态特征与奖励，输出是更新后的权重，拿它可以接着算 v̂(s;w)。 这里补 numpy 的基础：phi 是形状 (T+1, d) 的二维数组， 可以看成 T+1 行、每行 d 个数的一个表格， phi[t] 是第 t 行，也就是第 t 步状态的那组特征；下标从 0 开始。 w @ phi[t] 是两个一维数组的内积：每个位置各乘各的，再把所有乘积加起来，结果是一个数。

请实现 semi_gradient_td(phi, rewards, gamma, alpha, w)。

w ← w + α [ rt + γ w·φt+1 − w·φt ] φt (12.2)

输入

  • phi：形状 (T+1, d) 的二维 numpy 数组，phi[t] 是第 t 步状态的特征向量； phi[T] 是最后一步之后那个状态的特征，终止时传全 0 行，d 是特征维数；
  • rewards：长度 T 的一维奖励序列，rewards[t] 是从第 t 步转移拿到的即时奖励；
  • gamma：折扣因子 γ，标量；
  • alpha：学习率 α，标量；
  • w：长度 d 的一维权重数组，是这次更新前对 v̂ 的估计。

输出

  • 返回 np.ndarray，形状 (d,)：走完整条轨迹之后的权重， 用它就能算任意状态的值 v̂(s;w) = w·φ(s)。不就地修改传入的 w。

会被检验传入的 w 调用后保持原值，返回的是新数组； 返回形状必须是 (d,)；奖励全为 0 且初始 w 为 0 时返回仍全为 0； γ=0 时只学即时奖励，单状态、每步奖励 1 时收敛到 1.0；γ=0.9 且每步奖励 1 时收敛到 1/(1−0.9)=10； 更新只沿 phi[t] 做，测试里 delta=1、w=[2,3] 时应得 [3,3]， 把 phi[t+1] 那一侧的梯度也算进去则会得 [3,2]。只许标准库加 numpy。

卡住了？看提示
  • 第一步，复制一份可写的权重：w = np.array(w, dtype=float)。 它返回一个新数组，改起来不会影响调用方传进来的那个。
  • 第二步，用 for t in range(len(rewards)) 扫过每一步。 rewards 的长度是 T，所以 t 依次取 0 到 T−1。
  • 第三步，取出这一步和下一步的特征： f = np.asarray(phi[t], dtype=float)、 f_next = np.asarray(phi[t + 1], dtype=float)。
  • 第四步，算 TD 误差： delta = rewards[t] + gamma * float(w @ f_next) - float(w @ f)。 w @ f 返回内积，是一个数。
  • 第五步，只沿 f 的方向更新：w = w + alpha * delta * f。 这里 alpha * delta 是一个数，乘到数组上时 numpy 会把每个元素各乘一遍。 半梯度的关键就在这一步：不要再减掉 gamma * f_next。

代码题 2 · 用粗编码特征观察外推失效

背景表格法不会泛化，粗编码用多组互相重叠的格子共享权重来补这个短板， 代价是把同一套 w 用到训练区间之外时输出会失真。 这题的两个函数是线性函数逼近的最小闭环：coarse_code 把连续标量状态编码成 0/1 特征向量， linear_value 用这组特征和权重算出这一点的估计值。 式 (12.3) 里的 idx 是这一组格子里的第几格，⌊ ⌋ 读作向下取整， offset 是这一组格子相对数轴的错位量，mod 是取余数。 训练时先调前者拿特征、再调后者求值，这题看的就是这套特征在训练区间外的表现。

请实现 coarse_code(x, n_tilings=4, n_tiles=8, width=1.0) 与 linear_value(w, x, n_tilings=4, n_tiles=8, width=1.0)。

idxi = ⌊(x − offseti) / width⌋ mod n_tiles (12.3)

输入

  • coarse_code 的 x：标量 float，状态在某一维上的取值；
  • coarse_code 的 n_tilings / n_tiles / width：tiling 个数（默认 4）、 每个 tiling 的格子数（默认 8）、格宽（默认 1.0），第 i 个 tiling 的偏移是 i / n_tilings；
  • linear_value 的 w：长度 n_tilings*n_tiles 的一维数组，与特征向量每个位置一一对应；
  • linear_value 的 x / n_tilings / n_tiles / width： 与前者同义，用来生成同一个特征向量。

输出

  • coarse_code 返回 np.ndarray，形状 (n_tilings*n_tiles,)，默认 (32,)： 每个 tiling 恰好一个位置是 1，占用下标 i*n_tiles 到 (i+1)*n_tiles-1，其余位置是 0；
  • linear_value 返回 Python float：w 与 coarse_code(x, n_tilings, n_tiles, width) 的内积，也就是 v̂(x;w)；不修改传入的 w。

会被检验默认参数下形状是 (32,)、恰好 4 个 1、取值只有 0 和 1； x=1.0 与 1.3 的特征共享 1 到 3 个位置，相邻输入部分重叠，这是泛化的来源； x=1.0 与 4.0 的特征不相等； x=100.0 与 4.0 的特征完全相同，两者的预测值因此相等，外推失效； 用 linspace(0, 4, 41) 的特征最小二乘拟合出的 w，对 x=2.0 的预测与 2 相差不超过 0.5， 对 x=100.0 则退化回区间内的水平（小于 20）。只许标准库加 numpy。

卡住了？看提示
  • 先写 coarse_code。第一步造一个全零数组： f = np.zeros(n_tilings * n_tiles)，默认就是长度 32 的一排 0。
  • 第二步，对每一组格子循环：for i in range(n_tilings):。 第 i 组占用的下标区间是 i*n_tiles 到 (i+1)*n_tiles-1。
  • 第三步，算这一组里落在哪一格：offset = i / n_tilings， idx = int(np.floor((x - offset) / width)) % n_tiles。 np.floor(...) 返回向下取整之后的浮点数，int(...) 再把它变成整数； % 是取余数，Python 对负数也返回非负结果，所以编号总能落在 0 到 n_tiles-1 之间。
  • 第四步，把这一格点亮：f[i * n_tiles + idx] = 1.0。循环结束后返回 f。
  • 再写 linear_value，一行就够： return float(np.dot(np.asarray(w, dtype=float), coarse_code(x, n_tilings, n_tiles, width)))。 np.dot 返回两个一维数组的内积，也就是"逐项相乘再求和"的结果，是一个数。
